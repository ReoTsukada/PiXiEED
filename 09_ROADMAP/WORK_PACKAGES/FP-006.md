## Objective

FP-006は、Core完了後のDraw2実証前に、入力経路、復旧、端末適応、操作説明を閉じる。既存の現行PiXiEEDrawを改変せず、Draw2のPresentation/Adapterだけを対象にする。

## Canonical inputs

- `03_PRODUCTS/PIXIEEDRAW2_SPEC.md`、`03_PRODUCTS/PIXIEEDRAW2_UX_SPEC.md`
- `02_ARCHITECTURE/CROSS_TOOL_LIVE_EDIT.md` と CORE-120のProject/Command/Revision契約
- `05_PERFORMANCE/PERFORMANCE_BUDGETS.md`、`DRAW2_DEVICE_AND_WORKLOAD_MATRIX.md`
- 現行PiXiEEDrawのCanvas-first縦画面をREUSE/ADAPT判定した監査記録

## Deliverable

- Canvas/Input hot path、pointer capture、cancel/lost-capture、stroke recoveryの実装とテスト
- Desktop/Tablet/MobileのPresentation Profile、safe-area、IME、touch/stylus capability境界
- icon-first UI、accessible name、tooltip、shortcut hint、Help/Q&A、shortcut一覧、初回作成guide
- page-level scrollを持たないWorkspace。許可されるscrollはPanel/Sheet内部のbounded listだけ
- `UNTESTED`を含む端末・実機の資格状態と、引き継ぎ可能なCheckpoint

## Non-scope

- 現行`pixiedraw/`、既存PXD、PiXiSYNC、Market、公開URL、Production DB/Storageの変更
- Draw/Audio/Gameの機能追加、Store配布、Native署名、Deploy、Commit、Push
- 実機未接続のMobile/Safari/Firefox/Stylus/30分MemoryをPASS扱いすること

## Workflows

1. Pen/Eraserで水平・垂直・斜め・高速・逆方向を描き、Canvas外へ出てrelease/cancelしても1 Stroke=1 Undoを保つ。
2. TouchでDraw、Pan、Pinch Zoom、Panel scrollを切り替え、Page scrollが発生せずCanvasとPanelのgesture ownershipが競合しないことを確認する。
3. 390×844、430×932、1280×900、1366×768、1920×1080で、全critical controlを画面内に収める。長い一覧は内部だけでスクロールする。
4. icon actionをTooltip/Help/shortcut/creation guideから同定し、input/modal/disabled状態でも誤発火しないことを確認する。

## Failure / attack tests

- pointerup、pointercancel、lostpointercapture、browser interruption、Canvas外releaseでstuck strokeを拒否
- Panel操作中のCanvas mutation、Canvas操作中のPage scroll、IME表示中のhidden critical actionを検出
- forced narrow width、text scaling、safe-area、reduced-motion、unknown profileをfail-closedで診断
- global shortcutのinput/Modal中暴発、high-risk icon-only確定、disabled reason欠落を拒否

## Performance / device / accessibility

- pointer sampleごとにTimeline/Layer/Palette/Inspector/Workspace全体をrerenderしない。hot path traceで更新境界を記録する。
- Desktop 512×512/20 layers/120 frames、Mobile 256×256/12 layers/60 framesを測定対象にする。未測定はUNTESTED。
- Keyboard/focus order/focus restore、screen-reader name、touch target、contrast、reduced motionを確認する。
- Browser/NativeのHost差はAdapter内に閉じ、CoreのProject/PXD/PiXiSYNC semanticsを分岐させない。
