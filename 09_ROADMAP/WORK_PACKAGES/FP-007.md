## Objective

Make the isolated Core reproducible from a clean checkout. Every schema and contract has an exact
version and digest; every dependency is pinned and reviewed; every generated browser artifact has
a deterministic source-to-dist manifest; and a second clean build can prove identical outputs.
`latest`, ambient local packages, unrecorded environment variables, and mutable generated output
are not accepted as inputs.

## Prerequisites and canonical inputs

- FP-005 is independently approved and its accepted storage/input policy is versioned.
- Read `02_ARCHITECTURE/BUILD_EXPORT_PIPELINE.md`, Core Completion Blueprint, existing lockfiles,
  package manifests, generated artifact paths, and all contracts consumed by Core.
- Treat `schema registry`, lockfile, toolchain version, build command, source manifest, and
  artifact manifest as canonical inputs. Do not modify Registry/Queue/State in this package.

## Deliverables

- `pixiedraw2/src/fp-007/**`: schema registry/compatibility checker, lockfile and toolchain
  inspection, deterministic build manifest, source-to-dist hash checker, and provenance result.
- A versioned schema record containing name, exact version, digest, owner, status, compatibility
  mode (`backward`, `forward`, or `full`), migration/adapter id, and fixture set.
- Dependency inventory with exact resolved versions, lockfile hash, direct/transitive origin,
  license classification, vulnerability review status, and an explicit `latest`/floating-range
  failure list.
- Clean-build and repeat-build evidence under the allowed FP-007 docs/inventory/ADR scope. A
  failed clean build is a blocker, not a warning.

## Non-scope

No feature implementation, schema migration, dependency upgrade performed merely to obtain PASS,
production build/deploy, store submission, current-route change, runtime provider connection, or
Registry/Queue/State edit. Findings in existing manifests are recorded and fail the gate until an
authorized later change resolves them.

## Invariants

1. A schema is addressed by `(name, exactVersion, digest)`; unknown version/digest and unregistered
   fields fail closed. Compatibility is checked against the declared mode, never guessed.
2. No dependency is resolved from `latest`, `*`, an unbounded range, an uncommitted local path, or
   an undeclared registry. Exact lockfile resolution is required for every build input.
3. Build manifest includes source file paths/hashes, lockfile hash, schema registry hash, toolchain
   versions, build command, allowlisted environment inputs, and generated artifact hashes/sizes.
4. Two builds with the same manifest produce byte-identical artifacts and identical manifest hash.
   Timestamp, absolute path, host name, random id, locale, and user-specific path cannot affect it.
5. Every browser entry and lazy chunk is mapped to its source; source map inclusion/exclusion and
   initial/lazy boundaries are recorded explicitly. Missing mapping fails.
6. License/vulnerability status is evidence, not an implicit approval. Unknown license, critical
   unresolved vulnerability, lockfile drift, or unreviewed transitive dependency blocks acceptance.

## Attack and failure matrix

| Fixture / injection | Required assertion | Evidence |
|---|---|---|
| Unknown schema/version/digest or incompatible fixture | Reject before decode/use; migration id required | `FP007-SCHEMA-001` |
| Added/removed/renamed field against each compatibility mode | Correct accept/reject result recorded | `FP007-SCHEMA-001` |
| `latest`, `*`, floating range, lockfile mismatch, undeclared package | Clean validation fails with exact dependency identity | `FP007-DEP-001` |
| Changed source, lockfile, toolchain, env, or schema | Manifest/hash changes deterministically | `FP007-PROVENANCE-001` |
| Repeated clean builds | Same artifact bytes/hash; no host timestamp/random drift | `FP007-BUILD-001` |
| Missing source-to-dist/lazy chunk mapping or unexpected initial import | Fail build evidence; no silent bundle expansion | `FP007-DIST-001` |
| Unknown license or critical/high vulnerability without disposition | Block; never mark reviewed by absence | `FP007-DEP-001` |
| Dirty workspace / undeclared generated file / network-only dependency | Clean checkout fails and records the missing input | `FP007-BUILD-001`, `FP007-PROVENANCE-001` |

## Performance, security, privacy, and compatibility

- Record clean-build wall time, peak memory if available, artifact sizes, raw/minified/gzip/Brotli
