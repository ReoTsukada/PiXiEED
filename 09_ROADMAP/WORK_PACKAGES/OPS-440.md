## Objective

Admin、Moderation、Analytics、Ads、Revenueのserver-permissioned projectionを接続する。Studio、Checkout、Entitlement、Commission、Account-private、Project-privateには広告枠を置かず、Telemetry/Analyticsはprivacy-safeで、Revenueはshadow projectionに限定する。

## Canonical inputs

- `docs/contracts/WP-240-ADMIN-ANALYTICS-ADS-REVENUE.md`
- `docs/contracts/WP-250-POLICY-ECONOMICS.md`
- AuthorizationProof、Policy Decision、Event/Activity、Search、Notificationの境界
- 現行Admin RPC、Moderation、Ads、Revenue、ad-free policyとMarket baseline

## User journeys

- Admin/Moderatorが許可されたScopeを開く → Server decision済みのbounded projectionだけを見る。
- 公開面のAd slot → consent/region/eligibilityを確認し、label付きの広告枠を表示する。
- Studio、Checkout、Entitlement、Commission、private Project → Ad-freeを維持し、SDK/slotをロードしない。
- Analyticsを送る → allowlisted event/route/component/state/diagnosticだけを送信し、個人・作品・取引本文を送らない。
- Revenue/Policyを確認 → shadow-onlyで表示し、Ledger/Payout/Market/Royaltyを変更しない。

## Server authority

Admin actor、moderation actor、consent、region、age、ad eligibility、analytics consent、revenue visibilityはServer-resolved Policy/Authorization decisionから導出する。Client role、capability、consent checkbox、ad flag、DOM stateを信頼しない。Unknown/OFF/Kill Switchはfail closedする。

## Durable event

Admin/Moderation/Analytics/Ad/Revenue projectionはtrusted eventを独立Inboxで受け、idempotency、bounded retry、DLQ、replay-no-side-effectを持つ。Analytics再送は課金・権利・Ledgerを変えず、Ad eventはOrganic rankingやContributor allocationを変更しない。

## Privacy and non-intrusion

JWT、Email、Secret、IPなどの不要な個人情報、Project本文、Pixel、Audio、Game Build、Commission本文、Payment、Entitlement、License、Royalty、Ledger詳細をTelemetry/Analytics/Ad payloadへ入れない。Admin projectionもprivate creative bodyを持たない。Production Ads/Analytics/Admin RPC/Revenueへ接続しない。

## Failure and attack tests

- client role/capability/consent/region/age/ad flagでAdmin・Moderation・Revenue権限を得られないこと
- private Studio、Checkout、Entitlement、CommissionへAd SDK/slotが出ないこと
- Consent撤回、region不一致、age不明、unknown policy、offline、provider failureをfail closed
- analytics payloadのJWT/Email/Secret/Project/Commission/Payment漏洩検査
- duplicate/out-of-order/replay Ad/Analytics/Revenue event、DLQ、shadow rollback
- Admin/Moderation操作のcross-tenant、resource mismatch、stale decisionを拒否
- AdsがSearch ranking、Market price、Royalty、Ledger、Purchase/Entitlementへ影響しないこと

## Evidence

permission matrix、ad-free surface matrix、privacy allowlist/redaction、policy decision fixture、event idempotency、shadow revenue result、SDK/load trace、current baseline/non-intrusion、独立レビューを保存する。実Provider、Production RLS、法的consent、実ユーザーAnalytics、Revenue/PayoutはUNTESTEDとする。
