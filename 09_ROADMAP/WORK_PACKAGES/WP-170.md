## Product goal

Move the isolated PiXiEEDraw2 from a Reference Pixel Editor toward a Professional Pixel
Art / Animation / Game Asset Editor. Aseprite is the minimum interaction reference for
pixel-art efficiency; PiXiEED adds Core, realtime, mobile, Game/Audio, Asset Graph, and
package boundaries without copying Aseprite or importing its code.

Desktop uses an Aseprite-efficient pixel workflow with a professional dockable workspace.
Mobile remains Canvas-first and portrait-friendly, exposing Tool Options, Layers, Timeline,
Palette, and Inspector through adaptive panels and bottom sheets when needed.

## Canonical feature scope

- Tile Asset and Tile Map placement

- Mirror / Symmetry
- Versioned deterministic Dither
- Indexed Palette advanced operations
- Animation Tags
- Slice metadata
- Game Asset Metadata

Voxel, Bone/Physics, and AI processing are out of scope.

## Architecture and safety gates

All raster-producing tools use `Input → Tool Session → deterministic pixel operation →
Canonical Command → raster mutation → dirty tiles/regions → projection`. UI owns no
canonical state. Preview/cancel never mutates the raster, Journal, or PiXiSYNC candidate;
each committed tool action is one atomic undo boundary.

Grid, Ruler, Guide, Reference Image, Slice, and tool previews are separate Projection /
Overlay domains. Personal visual preferences are local; shared structural guide/asset state
requires an explicit typed operation. Theme and overlay toggles must not change canonical
raster hashes.

Keep indexed/sparse/COW storage. Do not clone full frames/canvases, flatten large tile maps,
convert to RGBA unnecessarily, or allocate empty cels. Advanced code is DOM/Canvas/network/
storage independent; Editor integration is a lazy adapter.

Only committed shared structural operations may cross the PiXiSYNC boundary. Pointer samples,
hover, zoom, panel state, temporary preview, local guide visibility, and ruler hover remain
LOCAL_ONLY. Asset Revision / Package events are PLATFORM_EVENT; discovery/Market work stays
ASYNC_ON_DEMAND. No price, fee, royalty, purchase, or publish behavior is introduced here.
