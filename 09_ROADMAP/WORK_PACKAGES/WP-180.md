# WP-180 — Draw2 Professional Workspace / Device UX / Performance Integration

Status: `complete pending external audit`
Depends on: `WP-170` (approved; WP-000〜WP-170は再実行しない)

## Canonical scope

PiXiEEDraw2をProfessional Pixel Creation Applicationとして成立させるため、既存の隔離Coreと
WP-160 Runtime、WP-170 Advanced Coreの境界を保ったまま、Production-oriented Workspace Layerを
構築する。`pixiedraw2/index.html`の現Reference UIは完成形ではなく、Workspaceの検証用入口とする。

### Workspace

- Desktop: Global menu/Project/Save/Export/Undo/Redo/Workspace/Preview、左Tool、中央Canvas、右
  Layer/Palette/Inspector/Assets、下TimelineをCanvas中心の高密度UIで表現する。
- Tablet: Canvasを維持し、persistent panel一つと折り畳みTimelineを組み合わせる。
- Mobile: 現行PiXiEEDraw縦向きCanvas-firstをPrimary Referenceにし、Essential Toolbar以外は
  Bottom Sheet/Drawer/Context Panelへ必要時だけ表示する。PC UIを縮小しない。
- Workspace/Dock Region/Panel/Panel Group/Toolbar/Inspector/Canvas Region/Timeline Region/
  Drawer/Bottom Sheet/Overlay/Command Paletteを契約上分離し、将来のresize/collapse/hide/tab/preset
  に対応可能にする。

### Canonical and performance guardrails

- Desktop/Tablet/Mobileは同じProject/Raster/Command/Layer/Frame/Cel/Timeline/Selection/Undo/PXD Coreを
  使用し、Presentation/WorkspaceだけをCapability Profileで変える。
- Panel arrangement、sizes、preset、sheet、timeline scroll、tab、hover、local zoom/tool/historyは
  Project State/PiXiSYNC/PXDから分離する。
- Pointer Stroke hot pathはCanvas/InputとWorkspace projectionを分離し、sampleごとの全UI再描画を
  禁止する。Pointer Capture/cancel/lostpointercapture、入力所有権、Touch conflictを契約化する。
- Timeline/Layerは1000 Frame/100 Layerでbounded virtualizationし、total/visible/overscan/mountedを
  記録する。非表示Panelはlazy mountし、EditorCoreを再生成しない。
- WP-170 Advanced Core/Lazy boundary、WP-160 Runtime、Market Package準備のみの境界を維持する。

### UX / quality guardrails

- AsepriteはPixel Art操作の最低UX基準、Unity系は密度・Dock・Inspector・Asset Browserの参照とし、
  コピーはしない。実操作Auditでshortcut、temporary tool、feedback、cancel、undo粒度まで確認する。
- Light/Dark/System、Semantic Design Token、Keyboard/Focus/ARIA/Screen Reader/Touch/Safe Area/
  Reduced Motion/Text Scalingを実装・検証する。CanvasのCanonical Pixel ColorにThemeを混入しない。
- Feature Flag既定OFF、隔離Route/Entry、Kill Switch/Rollbackを維持する。現行Route、現行Draw、PXD、
  PiXiSYNC、Market、既存Project/Asset/Package、Production DB/Storageを変更しない。
- Audit/TelemetryへJWT/Email/Secret/Project内容/個人依頼内容を記録しない。

### Evidence required

- Current mobile inventory: `docs/inventory/wp180-current-pixiedraw-mobile.md`。現行側はread-only。
- Workspace contract/UI, tests, bundle/performance harness, ADR, inventory, visual manifest。
- Initial/lazy/runtime/CSSのraw/minified/gzip/Brotli、requests、source-map境界。WP-170の initial
  raw 158269 / Advanced raw 31086 / Adapter raw 1490を比較基準にする。
- Long Taskの原因分類、Memoryカテゴリ計測可能性、Desktop/Mobile reference workload、A11y、Visual
  Regression、interaction/failure、runtime non-intrusion、14件Baseline identity（再実行せず既存証拠と比較）。
- 実機Mobile、Stylus、30分Memory、Safari/Firefox、Full compositor E2E、Production/Cloud/Legacy
  user dataは未実測なら`UNTESTED`を維持する。
