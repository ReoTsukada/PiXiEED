# WP-190 — PiXiAudio Core Bridge / Draw2 Final Integration Gate

Status: `complete pending external audit`
Depends on: `WP-099`, `WP-094`, and approved WP-180

## Canonical implementation scope

Implement the isolated, DOM-free PiXiAudio Core Bridge for Audio Project/Revision mapping,
BGM/SFX event binding, Package/License compatibility, local preview/export planning, unsupported
format diagnostics, and cost-aware revision/event boundaries. Audio content is represented by
immutable Asset Revision metadata and storage locators; raw Audio Blob bytes do not enter the
Core contract.

The implementation must use the existing Asset Graph, Revision, Package, License Snapshot,
Storage Placement, Event, Feature Flag, and Runtime boundaries. It must not connect current Audio,
Market, PXD, PiXiSYNC, Project/Asset data, Production DB/Storage, or existing Routes.

  require explicit compatibility and PINNED/REVIEW policy.

  metadata-only boundaries and are not mutated.
