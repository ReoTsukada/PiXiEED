## Acceptance and evidence

- `WP920-FUNCTIONAL-001`: On physical or explicitly identified unavailable devices, test Desktop 1280x900/1366x768/1920x1080, Tablet split view, and Mobile 390x844. Record page overflow=0, Canvas bounds, safe area, panel-local scroll only, text scaling, reduced motion, offline/loading/error/permission states, screenshots, and status.
- `WP920-CROSSFLOW-001`: Audit Aseprite baseline operations (Pencil/Eraser/Fill/Selection/Transform/Palette/Layer/Frame/Cel/Timeline/Onion/Copy-Paste/Undo/Redo/Zoom/Pan) for steps, discoverability, shortcut, temporary tool, feedback, cancel, and undo granularity. Compare current PiXiEEDraw portrait layout for Canvas share and touch reachability; record REUSE/ADAPT/REPLACE decisions.
- `WP920-FAILURE-001`: Test pointer capture outside Canvas, cancel/lost capture, touch draw/pan/pinch, panel/timeline scroll conflict, stylus pressure fallback, keyboard-in-input suppression, modal shortcut suppression, dialog/sheet focus trap/restore, screen-reader name/state, and drag-only alternatives. No required action may rely on hover or right-click.
- `WP920-ACCESSIBILITY-001`: Verify compact icon-first presentation, short labels, tooltip/help entry, shortcut hint, guided creation step, keyboard order, visible focus, semantic role/name/state, touch target, error/loading/disabled reason, Escape/cancel, and reduced motion with a recorded tool/browser/device matrix. Unavailable real screen reader, stylus, Safari, or Firefox runs remain `UNTESTED`.
- `WP920-NONINTRUSION-001`: Feature Flag OFF leaves current routes, Draw, PXD, PiXiSYNC, Market, and data unchanged; UI exception cannot corrupt canonical Project state.

## Evidence contract

Each result contains device/browser/assistive technology, viewport, fixture, protocol, screenshot/video or raw measurement, pass/fail reason, reviewer, timestamp, and status. Browser emulation is not physical-device evidence. `UNTESTED` and `PARTIAL` never become PASS by inference; baseline failure identity must match and new failures must be zero.
