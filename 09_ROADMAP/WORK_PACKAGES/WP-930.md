- `WP930-DESKTOP-001`: On an identified desktop device, measure full-compositor input-to-visible p50/p95/max with 512x512, 20 layers, 120 frames. Record raw traces, frame budget, input path, visible update, and comparison to the approved budget; synthetic reference is not a production PASS.
- `WP930-MOBILE-001`: On an identified physical mobile device, measure 256x256, 12 layers, 60 frames for draw, erase, zoom, pan, timeline, and panel transitions. Record p50/p95/max, dropped frames, thermal/session context, and device/browser. Unavailable physical evidence remains `UNTESTED`.
- `WP930-TABLET-001`: Measure split view, stylus candidate, Canvas minimum area, one persistent panel, collapsible Timeline, and page overflow=0 across tablet orientations. Record panel-local virtualization and layout/reflow timings.
- `WP930-A11Y-001`: Run long-session and memory observations for raster/tile, metadata, undo/history, timeline projection, panel state, thumbnails, asset cache, advanced tools, and renderer resources. Record 30-minute result when available; otherwise each category is `UNTESTED`.
- `WP930-BUNDLE-001`: Record initial/lazy raw, minified, gzip, Brotli, CSS, request count, source-map inclusion/exclusion, and unauthorized lazy-chunk requests. Advanced Draw/Audio/Game/Market code must not enter the initial bundle without evidence.
- `WP930-LONGTASK-001`: Classify Long Task cause as raster/tile/pattern/UI/list/serialization/hash/layout/GC/other before proposing Worker use. Measure a same-fixture change; Worker adoption requires a measured win and fallback.
