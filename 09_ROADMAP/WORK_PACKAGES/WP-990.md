## Canonical role

Prepare and record an explicit Owner decision request; never grant approval or rollout. This definition is subordinate to `00_START_HERE/WORK_PACKAGE_REGISTRY.json`; the Registry owns status, dependencies, routes, write scope, and handoff truth.

## Owner boundary

WP-990 only prepares and records a decision request. It may summarize evidence and recommend a state, but it never grants approval, changes flags, performs rollout, or unblocks `CUT-001`. The only valid Owner decision values are `READY_FOR_LIMITED_ROLLOUT`, `NOT_READY`, and `BLOCKED`.

## Acceptance and evidence

- `WP990-COHORT-001`: Produce the final cohort/eligibility/exclusion/flag/fallback/kill-switch packet from WP-980. Verify server authority, deterministic assignment, privacy-safe telemetry, named rollback operator, and no current-route replacement.
- `WP990-THRESHOLD-001`: Attach the measured threshold table for correctness, security, performance, memory, event backlog, reconciliation, support, and accessibility. Each threshold links to raw evidence; unavailable values remain `UNTESTED` and cannot support a PASS recommendation.
- `WP990-ROLLBACK-001`: Attach rollback artifact hash, dry-run/rehearsal result, trigger, operator, communication, observation window, restore/reconcile procedure, and expected user-visible fallback. No production rollback is executed here.
- `WP990-OWNER-001`: Generate a non-automatic Owner request containing scope, evidence index, unresolved items, risks, legal/accounting dependencies, proposed decision values, and explicit prohibited actions. Record Owner response separately; absence of response is `BLOCKED`, not approval.
- `WP990-INDEPENDENT-001`: An independent reviewer verifies source links, status preservation, baseline failure identity, no new failures, no secret/PII leakage, and no production action. Reviewer cannot silently amend the decision.

## Evidence contract

The packet must include immutable evidence manifest, source/artifact hashes, gate statuses G0-G9, baseline identity, known `UNTESTED` list, unresolved P0/P1 list, rollback/reconcile/observe references, reviewer signatures/identities appropriate to the environment, and Owner request/response record. A generated packet is not approval; synthetic, isolated, or unavailable evidence remains explicitly labeled.
