# LUNA AI DEV HARNESS v3.2 — DISCOVERY FIRST / MACHINE FIRST

人間が基本的に行うのは2つです。

1. `GOAL.md` に「作りたいもの」を1文でもよいので書く。
2. 開始時にAIから出る、先に決めておく価値の高い質問へまとめて回答する。

その質問フェーズが終わると `discovery_lock=true` になり、以降の通常開発ではAIが細かな確認を繰り返さず、自動で調査・設計・実装・テスト・修正・比較・レビュー・記録を進めます。

## v3.2の考え方

- **質問は先に終わらせる**
- **後から細かく聞かない**
- AIが調べれば分かることは質問しない
- 可逆なことはAIが仮定して進む
- 迷ったらReference Scout / Cache / 比較 / Prototypeを使う
- 実装方法はEvidenceに応じて更新する
- PRODUCT_BLUEPRINTのNorth Starと完成条件は守る
- 高コストな確認・A/B・レビューは毎回行わず、Expected Valueが高い場合だけ行う
- 本番公開、決済、破壊的Migrationなどの不可逆な操作だけは最後の安全な地点で承認を求める場合がある

## 例

`GOAL.md`:
```text
地球のシミュレーションゲームを作りたい
```

AIは最初に、ゲームの方向性・対象・プラットフォーム・絶対条件など、後から間違えると大きな手戻りになる事項だけをまとめて質問します。
回答後は、人気事例や技術資料を必要に応じて調査し、Blueprintを作り、Work Packageへ分解して自動進行します。

開始:
`START.md` をCodex/AIへ渡してください。
