# 能力設計 v0.3

正本はsrc/catalog.mjs。以下はコモン・個体値100%・1経路・増幅前。

|コア|分類|能力|
|---|---|---|
|弾丸生成|射撃|頂点に装着すると自動射撃。威力 +2%。下段では威力だけを加える。|
|高密度弾|射撃|弾丸の基礎威力 +4%。すべての直接弾に適用。|
|加速装填|射撃|射撃頻度 +1.2%。|
|並列銃身|弾道|追加弾数 +0.025。端数は射撃ごとに蓄積され、1で追加弾。|
|貫通針|弾道|貫通回数 +0.06。端数は弾丸生成時の追加貫通確率になる。|
|反射晶|弾道|壁反射 +0.08回。|
|裂弾|弾道|初回命中だけで子弾 +0.025発。威力45%。再分裂せず、生成元の敵には当たらない。|
|炸裂核|追加効果|直接命中時、別の周辺敵へ非会心威力×合計強度×75%の爆発。基準強度+1.2%。|
|放電路|追加効果|直接命中時、別の敵へ非会心威力×合計強度×40%の放電。基準強度+1.2%。|
|腐食弾|追加効果|直接命中時、非会心威力×合計強度の毎秒ダメージを3秒。強い値を保持し時間更新。基準+1.5%。|
|凍結触媒|追加効果|2秒間、敵速度を1÷(1+合計強度)に。基準強度+1%。|
|追尾レンズ|弾道|追尾強度+0.025。旋回速度は合計強度×2ラジアン/秒。|
|精密照準|射撃|会心率+0.25ポイント。100%超過分は会心倍率へ加算。|
|吸収回路|持久|直接弾の実ダメージの0.01%を吸収。PvE吸収回復は最大HPの8%/秒、未処理回復は1秒分まで。|
|防護殻|持久|最大HP+2。|
|自己修復|持久|毎秒HP+0.025。吸収回復の上限とは別。|
|機動補助|持久|移動速度+0.25px/秒。|
|回収磁場|持久|戦利品回収半径 +1.5px。|
|重砲化|取引条件|威力+8.5%、射撃頻度-0.6%。高レアは代償軽減、局所増幅は代償も増やす。|
|散弾化|取引条件|追加弾数+0.04、威力-2.5%。|
|追い撃ち|条件|HP35%未満の敵への命中威力+1%。|
|遠距離増幅|条件|累積飛行距離500pxで命中威力最大+0.5%。|
|静止砲台|条件|0.7秒以上静止すると命中威力+0.35%。移動で解除。|
|回復装填|条件|実回復10HPごとに合計強度ぶんの追加弾を蓄積。追加弾は回復を起こさない。|
|接続増幅|増幅|上に直接つながるコア自身の数値を強化。基準×1.10。継承済みの効果は再増幅しない。複数は乗算。増幅コアが対象なら増加分だけを強化。|
