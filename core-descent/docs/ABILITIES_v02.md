# 能力設計 — 実装済み25種と追加候補

数字は能力とは独立。以下はコモン・個体値100%・増幅なしの基準値。レア度、能力ごとの個体差、直接接続した増幅、頂点への経路数によって実際の寄与が変わります。詳細はRARITY_AMPLIFIERS.md。全数値は試作用で、最終バランスではありません。正本はsrc/catalog.mjsです。

## 面白さの狙い

威力・連射・弾数は同種内では加算、種類同士では実質的に掛け算になります。そこへ貫通・爆発・放電が複数の敵への命中機会を増やすため、単純な攻撃力順ではコアを評価できません。

吸収と回復装填は耐久と火力をつなぎますが、実際に回復した量だけを使うため満タンでは追加弾を作れません。静止砲台は強いものの、移動を止めるリスクがあります。反射と遠距離増幅は通路や壁を資源に変えます。

## 新能力の実装手順

1. コアの数字は変更せず、能力定義に安定したidとmodキーを追加。
2. 小数・重複・上限/下限・負の効果・対象イベントを先に決める。
3. compileBoardの最終変換とGameEngineの挙動を実装。単に図鑑に名前を追加して実装済みとしない。
4. 単体・経路重複・既存効果との相互作用・無限循環防止をテスト。
5. 図鑑文言と計算式を一致させ、3/6/9段でプレイと負荷を確認。
6. 定義バージョンを更新し、オンライン版では探索中のバージョンを固定。

コアの上下を変えるだけで別の能力へ上書きする方式は現在のモデルではありません。追加案を採用する際も、元の合成ルールを黙って変更しないでください。
