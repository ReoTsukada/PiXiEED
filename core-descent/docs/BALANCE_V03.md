# CORE DESCENT v0.3 — ダメージと数値の検証仕様

これは数値検証用の候補版です。PvEゲームの係数・命中処理を更新しました。PvPは数値変換とプレビューだけで、対戦・通信・マッチングは未実装です。計算の整合性を検証したことと、全編成のゲームバランスが取れていることは別です。

## 1. 今回の範囲

v0.2の元ファイルは変更せず、別フォルダーのv0.3へ更新。数字のルール、経路重複、個体値固定、増幅が直属の上コア自身に届くルールは維持しました。

調整の中心は連射・弾数・条件倍率・吸収です。v0.2雷撃弾幕の全legendaryは直接弾の全弾命中理論DPSが48,678.24、HP100でした。v0.3では14,140.27です。これはPvP係数をPvEへ適用したのではなく、PvEの役割分担を作る候補調整です。強い相乗効果そのものは禁止していません。

## 2. 基礎値と計算順序

素の弾丸威力12、射撃3回/秒、HP100、移動165px/秒、基本会心率5%、基本会心倍率2倍。基礎値と、コアを装着した後の初期編成の値を混同しません。初期編成は威力12.72・射撃3.072回/秒です。

1. コア自身の値をレア度・個体値から計算。
2. 直属の下2個の増幅倍率を乗算して、自身の値だけを強化。
3. 下2出力と自身の強化後の値を加算。
4. 頂点の合計ベクトルを、弾丸威力・射撃間隔などに変換。
5. 命中時に一時レベル・対象HP・距離・静止条件を適用。
6. 直接弾の会心を1回抽選。追加効果は非会心値から計算。

```text
通常弾の基本威力 = 12 × max(0.05, 1 + 合計威力ボーナス)
射撃回数/秒 = 3 × max(0.05, 1 + 合計射撃頻度ボーナス)
平均弾数/射撃 = 1 + 合計追加弾数

命中時の非会心威力 = 基本威力
 × (1 + 0.1 × [探索レベル-1])
 × (1 + 遠距離強度 × min(1, 累積飛行距離/500))
 × (静止0.7秒以上なら 1+静止強度、ほかは1)
 × (対象HP35%未満なら 1+追い撃ち強度、ほかは1)

会心率 = min(1, max(0, 0.05 + 合計会心率加算))
会心倍率 = 2 + max(0, 0.05 + 合計会心率加算 - 1)
会心込み平均1発 = 非会心威力 × [1 + 会心率 × (会心倍率-1)]
直接弾DPS = 会心込み平均1発 × 射撃回数/秒 × 実際に当たる平均弾数/射撃
```

防御・属性耐性は現在未実装です。数値表は防御0の相手を前提とします。探索レベルは21まで、与ダメージ倍率は最大3倍。PvP案では探索レベルを使いません。

「1発命中DPS」は毎射撃1発だけ命中。「全弾命中DPS」は拡散した全弾が命中する参考上限。いずれも、追加効果・移動による命中率・回復装填・過剰ダメージを除いた値です。1発命中値は下限保証ではなく、実際には全て外すこともあります。

## 3. レア度と個体差

プラス効果の倍率はC=1、U=1.5、R=2、E=2.5、L=3。各数値に95〜105%の独立ロール。マイナス効果は倍率で割り、個体値を掛けます。高密度弾はC+3.80〜4.20%、U+5.70〜6.30%、R+7.60〜8.40%、E+9.50〜10.50%、L+11.40〜12.60%。

同じ構成でも威力×速度×弾数が相乗するので、レア度の効果3倍はDPS3倍ではありません。雷撃弾幕の全弾命中値は全Cが1,129.15、全Lが14,140.27で約12.52倍です。全Lの全数値95%なら12,408.99、105%なら16,025.21。ただし全数値が同時に端値になる極端な比較で、普通のドロップの分布ではありません。

### 追加効果の明確な扱い

爆発は直接命中した敵以外の周辺敵へ `非会心命中威力 × 爆発強度 × 0.75`。半径は `18 + sqrt(爆発強度)×33px`。
放電も直接対象を除き、各対象へ `非会心命中威力 × 放電強度 × 0.4`。対象数は `1+floor(sqrt(強度))`、探索距離は `100+sqrt(強度)×35px`。
単体だけならこの2種の追加ダメージは0です。周囲に敵がいる時に価値が出ます。これを単体DPSへ水増ししません。
腐食は3秒、同一対象の強い値を保持して時間更新。重ねて無限スタックしません。
子弾は親の基本威力45%から命中時補正を計算し直します。子弾自身の飛行距離・命中時の条件で判定。発生元の敵には当たらず、再分裂しません。爆発/放電/腐食は直接命中イベントを再帰発火させません。

## 5. 接続増幅の具体例

8段目の35経路の位置にレア高密度弾（+8%）、その真下2枠にレア増幅（各×1.20）を置くと、その高密度弾の寄与は `8%×1.20×1.20×35=403.2%`。増幅なしは280%。
トップもレア弾丸生成（+4%）、他は攻撃を変えないコアとすると、通常弾は増幅なし46.08、増幅あり60.864ダメージ。コア自身が1.44倍でも、基礎威力を含む完成弾が一律1.44倍になるわけではありません。

この比較は「増幅枠が攻撃以外のコアだった場合」との比較です。その枠に直接火力コアを置く機会費用は別途比較する必要があります。増幅を置けば必ず得とはしません。

## 6. 回復と被ダメージ

吸収は敵の残HPを実際に削った直接弾ダメージだけが対象。吸収回復を最大HP8%/秒で時間をかけて処理し、未処理分は1秒ぶんまで。満タン時に吸収を貯めません。自己修復は別枠。回復装填は実際に増えたHPだけを数え、そこから作る弾とその子弾は吸収しません。

全L吸収機関はHP454、吸収率3%、自己修復4.425HP/秒。吸収は36.32HP/秒までなので、連続して被弾し回復源がある場合も、吸収+修復は40.745HP/秒まで。毎射撃1発命中の1,694.47DPSでも理論吸収50.83HP/秒となるため、上限で制御します。実際には敵HPの不足や回避で低下します。

通常敵HP = `20×[1+0.16×(階層-1)]^1.65`。
接触ダメージ = `7+2.5×(階層-1)^0.65`。
速い敵のHPは通常×0.7、エリートは×3。現PvEは被弾後0.55秒の無敵時間があります。これはPvPへ流用禁止です。

100階の通常敵はHP2,111.03、接触56.56。HP100なら全快から2発、HP454なら9発で倒れます（回復なし）。200階はHP6,354.70、接触85.02。ボスは未実装で、存在するものとして撃破時間を提示しません。

## 7. 比較結果と再現

`qa/BALANCE_REPORT.md` と `qa/balance-report.json` に21条件の計算結果を収録。5構成×20乱数シード、各120秒の固定命中イベント再生も記録しました。移動・壁・回避・実機負荷・PvP勝率の試験ではありません。単にHP/DPSで出す撃破時間も、初弾までの待ちや離散的な弾数を含む実際の撃破時間とは異なります。

```sh
npm run build
npm test
npm run balance
```

`src/catalog.mjs` がPvE係数、`src/combat-math.mjs` が共通試算とPvP候補、`src/engine.mjs` が実際のPvE命中・回復処理です。PvPは同じエンジンへ未接続です。

## 8. 未解決・公開前の条件
