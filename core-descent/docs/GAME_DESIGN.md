# ゲーム設計 v0.2

## 作品の核

「数字パズルを解くことで、常識外れの銃を作り、その銃でどこまで潜れるかを試す」。強いコアを買うことと、強い編成を完成させることは別。強さの幅を極端に平準化せず、敵群・地形・生存・帰還という複数の課題を残す。

構想段階のキャラクター45体方式は採用しない。操作キャラクターは1人であり、45枠はパワーコアの装着基盤である。

## ユーザーの意図として保持するもの

数字0〜9、数字変更不可、下2数字の和の1の位、同段の重複禁止、9段45枠。各コアは下2出力に自身の能力を加え、頂点の弾丸生成へ集約する。頂点直下の2枠に固有の役割は付けない。

プレイはリアルタイムの自動照準・自動射撃。操作は移動中心。ランダムマップの階層を進むと難しくなる。帰還魔法陣で拾った物を持ち帰り、階段で先へ進む。市場は全アイテムの出品・入札・即決購入を対象とする。

ユーザー指定として5段階のレア度、レア度内の数値幅、×1.2などで次のコアを強化する増幅を保持する。具体的な倍率幅、増幅の範囲、負数の扱いは本試作の仮仕様であり、ユーザーによる個別承認を得た確定値とはしない。

## 試作用に仮決定したもの

以下はユーザーの確定指示ではなく、今回遊べる形にするための初期値。プレイテスト後に調整する。

| 項目 | v0.2の仮仕様 |
|---|---|
| 初期所持 | 0〜9のコア各1個。数字9が弾丸生成 |
| 初期基盤 | 3段6枠。数字配列は9 / 3,6 / 1,2,4 |
| 段数 | 通常でも3〜9を編集可。全枠が成立しないと出発不可 |
| 同じ現物 | 1編成内の二重装着不可。別個体なら同じ数字を別段で使用可 |
| 仮置き | 不成立配置も編集途中として保持可。赤表示・出発禁止 |
| 入手コア | 帰還まで使用不可。出発時の編成固定 |
| 装備喪失 | 未確保戦利品だけ失う。持込みコアは残る |
| 階層出口 | 20秒生存＋6+2×階層の撃破、必要撃破数は試作で最大30 |
| 開通後 | 帰還陣または階段に触れると移行。帰還は即時 |
| 一時成長 | 12体撃破ごとに探索レベル+1、直接弾威力+10%・HP7回復 |
| 再挑戦 | 1階から開始。中断再開・階層スキップ未実装 |
| レア度・個体値 | 5段階、効果ごとの95〜105%。深い階層ほど高レアの出現率が改善 |
| 増幅 | 直属の上側コア自身の数値を強化。子から継承した合計は再増幅しない |
| 取引通貨 | ゲーム内G。現金売買・課金・暗号資産を含めない |

この固定ルールはパズル完成の達成感を優先する。3段と9段の戦力を同等にするための補正は現段階では付けない。9段の構築を長期目標にする。

## ゲームループ

拠点で仮説を立てる → 数字と能力を両立した基盤を組む → 探索で自動射撃の挙動を観察 → コアを拾う → 帰還か続行を選ぶ → 持ち帰ったコアで配置を改善する。

市場が接続されると、不要品を売って不足する「数字×能力×レア度×個体値」を調達する循環が加わる。ただし完成ビルドそのものを購入するだけでパズルを飛ばせる自動編成機能は入れない。

## 4つの実験ビルド

雷撃弾幕は連射・並列銃身・貫通で命中数を増やし、炸裂と放電を乗せる。敵群処理が強いが、狭い通路や耐久力不足の課題が残る。

重砲狙撃は威力・会心・貫通・静止砲台・飛行距離を重ねる。単発火力が強い一方、停止と移動の判断、連射減少の代償がある。

吸収機関は直接弾での実ダメージから回復し、回復装填で追加弾を作る。HPが満タンだと回復装填は蓄積しない。追加弾は回復を起こさず、無限循環にしない。高い持久力は許すが、瞬間的な大ダメージには別の対策が要る。

増幅回路は最下段に複数のレア増幅を置き、上側の個体値が×1.44になる局所接続を比較する。これは操作確認用の編成であり、最強編成として最適化したものではない。

## 無限階層の意味

コード上は最終階を設けず次の階層を生成する。試作の敵HPは `20×(1+0.16×(階層-1))^1.65` を基準にする。速い敵、通常敵、3階以降の高HP個体を使用。敵数は負荷対策で最大90、発生間隔は最低0.15秒。無限回の実行や全階層のバランスを検証したという意味ではない。

次段階では部屋構成、敵の狙い、障害物、射線、エリートの組み合わせを増やす。吸血無効・弾丸無効など、ビルドを説明なしで全面否定する敵を安易に追加しない。階層へ進む前に次の特徴を予告し、帰還判断の材料にする。

## 現在の意図的な省略

絵は手続き描画の仮素材。音楽・効果音・ストーリー・ボス・装備品・素材・消耗品・実プレイヤー市場は未実装。スマホの基盤は横スクロールで編集する。9段全体の概観と大きなタップ領域を両立する専用UIはP1で改善する。

## 主要なリスク

パズルは数字だけなら有限で、9段は反転込み160通り。長期的な奥行きは同じ数字に入る能力、効果の相乗、レア度・個体値・隣接増幅、敵と地形で作る。大量の解があるかのように説明しない。

初期コアも市場に出せる方針なら、複数アカウントによる初期品供給、全売却後の再開方法を本番前に設計する。解決のためにユーザーの全アイテム取引方針を黙って永久バインドへ変更しない。

攻撃力だけで順位を決めず、到達階層、生存時間、回収品、帰還成功率、単体・群体処理を別々に測る。試作の理論DPS表示は直接弾が全弾命中する期待値であり、実戦DPSではない。
