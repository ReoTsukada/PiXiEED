# レア度・個体差・接続増幅 — v0.2.0

## 今回追加した仕様

コアは「固定数字0〜9」「能力の種類」「レア度」「能力ごとの個体値」を持ちます。レア度はコモン、アンコモン、レア、エピック、レジェンダリーの5段階。数字は変わりません。

各能力の数値は生成時に一度だけ決定し、帰還、保存、読み込み、出品、購入、装着で再抽選しません。数値幅・出現率は調整用の仮設定です。

## 1. レア度と個体値

| レア度 | 基準倍率 | 高密度弾の威力ボーナス範囲 | 接続増幅の倍率範囲 |
|---|---:|---:|---:|
| コモン | 1.0 | +3.80〜4.20% | ×1.095〜1.105 |
| アンコモン | 1.5 | +5.70〜6.30% | ×1.1425〜1.1575 |
| レア | 2.0 | +7.60〜8.40% | ×1.190〜1.210 |
| エピック | 2.5 | +9.50〜10.50% | ×1.2375〜1.2625 |
| レジェンダリー | 3.0 | +11.40〜12.60% | ×1.285〜1.315 |

各能力に95〜105%の独立したロールを掛けます。内部では9500〜10500の整数で保存します。例えば「重砲化」は威力と射撃頻度の代償を別々に抽選するため、威力は上振れ・代償は下振れという個体を入手できます。レア度が上がるとプラス効果は基準倍率倍、マイナス効果の絶対量は基準倍率で割ります。

```text
プラス効果 = 基準値 × レア度倍率 × 能力ごとの個体値
マイナス効果 = 基準値 ÷ レア度倍率 × 能力ごとの個体値
増幅倍率 = 1 + 基準増加分0.10 × レア度倍率 × 個体値
```

条件のHP35%、持続3秒、静止0.7秒などは発動仕様であり、今回のロール対象ではありません。数字0〜9も対象外です。これらを可変にする場合は別能力として契約を定義します。

初期10個はコモン・個体値100%で全プレイヤー共通。実験室の貸出コアも比較しやすいよう各レア度の個体値100%。ランダムな個体差は探索ドロップとテスト市場のサンプルで確認できます。

## 2. 「次のコア」は上に直接つながるコア

接続増幅は、上側へ1段だけ届きます。内側なら上2個、端なら上1個を強化します。対象は、そのコア自身のロール済み能力です。下段から受け継いだ合計値を丸ごと掛け直す効果ではありません。

例：威力+10%のコアの直下に×1.20を置くと、そのコアは+12%になります。銃全体の最終威力を一律20%増やす意味ではありません。下から別途継承した+30%は増幅されず、出力は+30%+12%=+42%です。

```text
接続先の増幅率 = 左下の増幅倍率 × 右下の増幅倍率
自分の数値 = ロール済みの数値 × 接続先の増幅率
上へ渡す出力 = 左下の出力 + 右下の出力 + 強化後の自分の数値
```

増幅コア自身にも下段の通常効果は流れます。通常効果の経路重複を削除しません。ただし増幅指示そのものは効果量ベクトルへ足し込まず、各直属の接続先で1回だけ使います。

## 3. 複数接続と増幅の連結

同じ対象コアの直下2枠に×1.20を置けば、対象は×1.44。+10%は+14.4%になります。×1.20と×1.30なら×1.56です。

一方、増幅コアが別の増幅コアを強化するときは、×1.20の「+0.20」部分を強化します。

```text
下の×1.20 → 上の×1.20を強化
上の新倍率 = 1 + 0.20 × 1.20 = ×1.24
```

基準の1.00まで能力として増やさないためです。並列の2増幅と、縦につないだ2増幅を混同しないようUIとテストで分けています。倍率の継承と通常の数値加算は別チャンネルとして実装しました。

局所増幅では対象コアのマイナス効果も同じ倍率で大きくなります。高レアによる代償軽減と、接続増幅による代償増加は別ルールです。

## 4. 9段・70経路との関係

増幅コアを9段中央に置いたからといって、その倍率を70乗しません。上側の2コアを1回ずつ強化し、その強化された通常効果が既存の経路ルールに従って頂点へ届きます。

例えば8段目の中央付近のコアは頂点へ35経路あります。そこにある+4%が直属の増幅により+4.8%になれば、最終寄与は4.8%×35=+168%。単純に倍率の70乗を追加する実装は禁止です。

同じ経路数でも、接続先が威力か回復か増幅かによって結果が変わるため、純加算のみのv0.1よりも隣接配置に意味が加わります。ただし、×1.2コアを入れると必ず強くなるわけではありません。直接能力コア1枠を増幅に替える機会損失があり、実用性の調整はP1の比較テストで続けます。

## 5. 個体データと互換性

```json
{
  "id": "unique-item-id",
  "digit": 7,
  "type": "overdrive",
  "rarity": "rare",
  "rolls": {"damage": 10321, "rate": 9728}
}
```

セーブ形式はversion 2。v0.1の品質値を持つコアはコモン・個体値100%に旧品質補正を付け、元の性能を維持して取り込みます。旧品質補正は画面に表示します。これは互換用の例外で、新規ドロップには付きません。本番オンライン市場へローカル資産を移行する仕組みではありません。

ブラウザー保存先はcore-descent-v2。旧core-descent-v1は読み込み元として使いますが、上書きしません。ファイル書き出しによるバックアップを推奨します。

## 6. 画面と試し方

HTMLを開き「9段実験室」→「増幅回路 ×1.2」を選択します。最下段中央の増幅を選ぶと上側2枠が黄色になり、詳細で倍率・抽選範囲・対象位置を確認できます。その上の枠を選ぶと「この個体」と「増幅後」を比較できます。

交換候補には数字・レア度・実際の能力値を表示。レア度で絞り込み可能。実験室には25能力×10数字×5レア度の交換用コアを用意しています。テスト市場にも増幅コアと固定した個体値を表示しますが、実プレイヤー取引ではありません。
