# CORE DESCENT 0.5 — PiXiEED公開アルファ版

## 今回の公開範囲

PiXiEEDの `/core-descent/` へ、最大9段45コアの数字パズルと自動射撃を組み合わせたゲームを統合する。一般入口はゲーム一覧・ツール一覧・ホームの遊ぶリンク。プレイヤーを操作する探索、9段ビルド体験、コア編集、帰還、ランダム階層、180秒無限ボス、端末内の自己記録が使用可能。

オンラインの全体順位、アカウント共有保存、プレイヤー間オークションは未実装。公開画面はこの状態を明示し、NPC市場の実装テストは一般ナビへ出さない。本版のローカル所持品は将来のサーバー所有権を保証するデータではない。

## グラフィック

2Dの断面スプライトを高さ方向へ重ねる2.5D。主人公・3種の敵・無限ボス、壁と柱、床、帰還陣・階段を描画する。キャラクターは脚・胴・肩・頭・銃を含む層を合成し、床と別の高さに表示する。手前と奥の重なりは足元の世界Yで決め、主人公を隠す手前壁は透過する。

暗い青緑の石遺跡と、淡い緑の主人公・自弾、朱色の敵、金色の階段を使う。遠景の暗がり、床模様、壁側面、接地影、キャラクター、発光・着弾、UIを分ける。単に一枚の背景へ影を付けた静止画ではなく、移動・照準・敵の追跡に合わせて表示が変わる。

素材は `src/sprites.mjs` のコードから作る独自の小さな2D画像。`src/renderer.mjs` が重ねて描画する。キャッシュした姿勢・壁・床画像を再利用し、大量の自弾は軽い軌跡で表す。既存の制作ツール用プレビュー画像を再利用・公開しない。

## 変えないルール

- 固定数字0〜9、下2個の和の1の位、段内数字重複不可。
- 下2出力＋自身の能力、経路の重複寄与、直属上側への増幅。
- 5レア度と入手時固定の個体値。
- ダメージ、射撃頻度、当たり判定、敵の出現、取得確率、180秒試験条件。
- 既存のv4保存キーと所持品スキーマ。描画更新だけなので記録ルール版0.4.0も維持。
- 通常探索・実験室の資産と記録は分離。

短い横画面のボス戦では主人公とボスの全身が収まるようカメラを引く。通常探索は主人公を追従する。

画面のY方向は0.78倍に投影するが、当たり判定は従来の2D世界座標のまま。入力ベクトルを逆投影し、見えている方向へ移動できるようにする。描画品質でシミュレーションの刻みや火力を変更しない。

## 使い方

ホームの「探索をはじめる」は通常所持品を使う。初期0〜9の各1個と、成立済みの初期3段編成から遊べる。自分で編集中に崩した場合は、接続を直すまで開始できない。

「9段ビルドを体験」は別資産の弾幕ビルド。通常の所持品に強いコアを追加しない。移動はWASD/矢印、スマホはゲーム画面のドラッグ。射撃と照準は自動。Space/Escapeまたはボタンで一時停止。タブを離れると停止する。

帰還陣・階段の開通条件は20秒生存と規定撃破。緑で帰還・金で次の階層へ。画質設定と演出軽減は表示のみを変更。ブラウザーを閉じる前のセーブ書き出しはコア基盤から行う。別ドメインで遊んだ旧HTMLの保存は、ファイル書き出し・読み込みで移す。

## 配信と開発

`node tools/build.mjs` で自己完結型の `index.html` と `dist/index.html` を作成する。`npm test` と `npm run balance` を実施。PiXiEED本体のビルドは `core-descent/index.html` だけを公開対象にし、ゲームのsrc/tests/docs/qa等を除外する。追加の実行時CDNや外部画像依存はない。

PiXiEEDへの配信は既存GitHub Pagesのmain公開手順を使い、別ドメインを作らない。自動挿入される描画CTAの除外表へこのゲームを追加する。制作ツール・広告設定等の既存機能には立ち入らない。

## 本番オンライン版の残作業

1. ゲーム用アカウントとサーバー保存の所有権を実装。セーブ改変を正当な在庫として受け入れない。
2. ラン開始時に編成・個体値・シード・ルールを確定。入力再生またはサーバーシミュレーションで攻略階層とボス実ダメージを検証。
3. 出品物のロック、資産・通貨の原子的な交換、二重購入防止を実装してから実プレイヤー間市場を公開。
4. 実機の長時間負荷、様々なコア組み合わせ、保存の永続性を検証してベータ版の運用条件を確定。

これらはグラフィックの更新やローカル保存だけでは完成しない。全体順位・市場を実装済みと表示しない。
