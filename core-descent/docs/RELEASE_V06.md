# CORE DESCENT 0.6 — 武器核と霧の遺跡

## 現行の目的

主人公・敵・武器の原画を32×32の2Dスプライト層で作り、ファンタジーの立体的な遺跡をリアルタイムで探索する。職業の選択や装備制限は持たない。頂点の武器核と、その下の数字・効果・レア度・個体差の組み合わせで戦い方を作る。

ユーザーの変更依頼により、従来の銃への集約を10系統の武器へ拡張した。自動攻撃と移動操作、9段45枠、下2数字の和の1の位、同段数字の重複禁止、能力の経路合成と局所増幅は継続する。

## 0〜9の武器

保存形式のtypeは互換性のためemitterのまま。頂点に装着したemitterの固定digitが武器種を決める。下段のemitterは自身の威力補正を伝え、独立した武器攻撃を発生させない。通常のコアの数字は武器種を決めない。

以下はコア補正・レア度・会心・探索レベルを加える前の基礎値。1マスは32px。実際に装備した武器核自身の威力補正も、この基礎値へ加算する。

| 0 | 旅人の剣 | 27 | 1.6 | 64 / 2.00 | 前方115°の斬撃 / 巻き込み3体 |
| 1 | 双牙の短剣 | 11 | 3.6 | 43 / 1.34 | 高速3連撃 / 3撃目1.8倍 |
| 2 | 巨人の大剣 | 68 | 0.72 | 87 / 2.72 | 前方140°の重斬撃 / 巻き込み6体 |

| 4 | 月輪の斧 | 43 | 1.05 | 68 / 2.13 | 広い扇形斬撃 / 巻き込み5体 |

全武器が毒・鈍足・吸収・会心・爆発・連鎖などを使用できる。近接は扇形/直線の命中判定、遠隔は実際に飛行する投射物。壁越しの近接、爆発、連鎖、投射物のすり抜けは許可しない。自動標的は現在見える敵のみ。倒れないボスも武器の間合いに入って攻撃する。

### 攻撃形に応じたコア効果

| コア値 | 近接での意味 | 遠隔での意味 |
|---|---|---|
| multi | 追加の攻撃動作。小数は蓄積 | 追加の投射物。小数は蓄積 |
| pierce | 巻き込める敵の上限を増やす | 貫通回数。刃輪では命中時に35%の追加斬撃 |
| bounce | 新しい敵へ45%威力の反響斬 | 壁反射回数 |
| homing | 薙ぐ角度/槍の幅を広げる | 弾の旋回速度を増やす |
| split | 命中から魔力の欠片を発生 | 命中から子弾を発生 |
| longshot | 間合いの先端で威力が増す | 飛行距離に応じて威力が増す |

コア固有値の説明はcatalog.mjsを正本とする。追加攻撃からさらに同じ追加攻撃を無限に再帰生成しない。表示エフェクトの予算と、実際の命中数は分ける。

## 射程と視界

27種のコア。従来25種をファンタジー名へ更新し、以下を追加。

- 伸長の紋章: コモン基準で射程・間合い+0.4%。最終射程=武器基礎射程×(1+reach合計)。
- 灯火の瞳: コモン基準で視界+0.025マス。最終視界=8マス+vision合計。

レア度・個体差・経路数・直属上への増幅は両方に適用する。例として個体値100%、増幅なしの9段中央70経路へコモン伸長を置くと射程+28%、レジェンダリーなら+84%。灯火の瞳は同じ位置でコモン+1.75マス、レジェンダリー+5.25マス。壁の背後は視界を増しても見えない。

## 部屋型ダンジョン

各階は47×35マス、tile32。6〜9室の広い部屋をランダムに配置し、隣接室を短い2マス幅の通路でつなぐ。長方形、角を落とした部屋、柱を持つ部屋がある。全床の接続と少なくとも1つの迂回ループを保証する。

帰還陣は開始室。階段は開始点から歩行距離が遠い別室。階数とシードが同じなら地形を再現する。20秒生存と必要撃破で出口が開き、帰還で未確保品を拠点へ持ち帰る。次階ではHPと未確保品を引き継ぎ、探索の霧を新しく作る。

### 探索の霧

- 未探索: 地形・敵・戦利品・出口を隠す。
- 現在の視界: 明るく描画。壁で遮蔽され、斜めの角抜けを防ぐ。
- 既探索の視界外: 地形を暗く残す。敵・戦利品の現在位置は表示しない。
- ミニマップ: 発見済みの地形だけを表示する。
- ボス試験: 条件比較用の専用アリーナを全表示する。

視界と既探索は別の配列。見える範囲はタイル移動時に更新し、描画側は読み取り専用。カメラ・画質変更で敵の行動やダメージは変わらない。

## 32×32多層スプライト

主人公、スライム、コウモリ、骸骨、呪騎士、石守護者、10武器の原画レイヤーは各32×32。ボスは原画の2.5倍表示。8方向、歩行4姿勢をキャッシュし、高さの異なる層、床影、壁の上面/側面で立体感を作る。拡大は最近傍。

専用の既成ゲーム素材は使用せず、sprites.mjsで独自の小さな原画を生成する。スクリーンショットや制作ツールの試験画像をサイト素材として公開しない。

## 編成と保存

通常モードの武器選択は所持中のemitter個体を頂点へ交換するだけ。数字が合わない場合は不成立として保存し、接続を完成させるまで出発できない。通常の数字を自動変更しない。

初期の0〜9コアは維持し、不足する数字の武器核を補う。新規プレイヤーは計19個。古いセーブは既存ID、レア度、個体値、配置、プリセットを保持したまま不足武器だけ追加する。移行を複数回実行しても増殖しない。

ホームの体験では、10武器のどれでも成立済みの9段ビルドで開始できる。実験室の自動完成と通常所持品は区別する。増幅回路プリセットは9段の完成例へ戻す。

所持品の保存キーはcore-descent-v4を維持。武器・地形・命中ルールが変わるため、自己記録はrules 0.6.0、challenge fantasy-rooms-01、seed 20261119、保存キーcore-descent-records-v6を使う。旧v4記録のキーを削除せず、異なるルールを同じ順位へ混ぜない。

## 数値表示

威力・攻撃動作/秒・射程は実際の合成後の値。参考DPSは威力×攻撃速度×平均追加数×武器固有の連撃数×短剣コンボ平均×会心期待倍率。

魔導書は3連撃、短剣は連撃が継続した平均1.2667倍を含む。刃輪の復路、範囲巻き込み、毒・爆発・連鎖などの追加ダメージは条件依存のため含まない。刃輪はUIに「往路の参考DPS」と明記。実ダメージは180秒ボスで確認する。
