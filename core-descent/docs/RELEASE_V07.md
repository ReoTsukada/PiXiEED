# CORE DESCENT v0.7 — 五つの大地と固有の戦利品

PiXiEED公開アルファ版。主人公を移動させ、数字コアで組んだ武器の自動攻撃で探索する。職業制限はなく、剣・短剣・大剣・槍・斧・槌・弓・刃輪・杖・魔導書の全10系統に、全32種類のコアを使用できる。

## すぐに試す

拠点で「体験する武器」「体験する場所」を選び、「選んだフィールドを体験」を押す。9段45枠の完成ビルドと実験用資産を貸し出す。「ボスのいる階から」を選ぶと各帯の5階目から始まり、最奥の部屋にボスが待つ。ボスの目の前へ自動転送する機能ではない。

通常探索は1階から始め、所持品を使う。武器核を交換しても数字を自動修正しない。数字が成立するよう下のコアを編成する。自動完成は実験室に限定。

移動はWASD・矢印キー、または画面ドラッグ。照準と攻撃は自動。Qで癒しの霊薬、Eで守りの巻物。画面にも使用ボタンを置く。Space/Escapeで一時停止。

## フィールドとボス

|階層帯|フィールド|通常の敵|帯の最終階のボス|
|---|---|---|---|
|1〜5|翠風の草原|草原スライム、草原ゴブリン、野生の狼|草原の古老樹|
|6〜10|砂眠りの遺跡|砂のスカラベ、砂漠の射手、潜砂ワーム|砂丘の大蠍|
|11〜15|熾火の火山|熾火コウモリ、火のインプ、溶岩ゴーレム|熾火の古竜|
|16〜20|瘴気の湿原|毒沼スライム、胞子の呪術師、湿原の追跡者|瘴気のヒュドラ|
|21〜25|白霜の雪原|霜牙の狼、氷の射手、氷壁の守護者|白霜の巨人|

26階で草原へ戻り、25階周期で繰り返す。難度は絶対階層から計算し、周回でリセットしない。深い周回のボスは名前に巡回数を表示する。

47×35、1タイル32px、6〜9部屋のランダムマップ。短い2タイル幅の通路と周回できる接続を組み、すべての床をつなぐ。主人公と敵の原画レイヤーは32×32で、重ねる高さと描画順で奥行きを付ける。ボスは原画を2.5倍表示する。

地形は色だけでなく、草・木、砂紋・サボテン、玄武岩・溶岩、泥・葦、雪・氷松で形も変える。未探索は隠れ、既探索は暗く残り、現在の視界だけ明るくなる。壁で視線を遮り、未発見の敵・戦利品・出口・ミニマップ情報を開示しない。

### 地形の効果

|地形|移動倍率（耐性なし）|継続ダメージ|
|---|---:|---|
|流砂|0.62|なし|
|溶岩|1.00|階層基礎接触ダメージの38%、最短0.6秒間隔|
|毒沼|0.82|階層基礎接触ダメージの18%、最短0.6秒間隔|

入口・帰還陣・階段・ボスの初期位置は危険床から離す。危険床は壁ではなく、経路を完全に遮断しない。状態異常耐性は地形の移動低下も緩和する。氷は現段階では冷気による減速であり、慣性滑走ではない。

## 敵の行動と戦い方

スライムは跳躍と小休止、甲虫やゴブリンは回り込み、狼は方向を固定した予告付き突進。射手は近すぎると退き、横移動して矢を撃つ。砂虫は主人公がいた地点に範囲攻撃を予告し、インプは扇状の火球、ゴーレムは近距離の叩きつけを使う。

通常敵の基礎移動速度は26〜91px/秒。階層補正は `1 + min(0.7, floor × 0.015)`。予告時間は通常攻撃で0.65〜1.0秒、ボスで1.0〜1.25秒。地面・扇形・突進・飛び道具をそれぞれ表示し、発動前に離れる余地を作る。予告元を倒せば、未発動の攻撃は消える。

敵弾と突進は細かい区間で壁を判定する。地面攻撃も発生元から主人公への視線を確認し、壁越しの攻撃を防ぐ。

各ボスは2種類の攻撃を交互に使用。HP50%以下で激昂し、攻撃待ち時間を25%短縮する。予告時間は短縮しない。

|ボス|主な攻撃|
|---|---|
|草原の古老樹|足元の根による範囲攻撃、5方向の棘|
|砂丘の大蠍|長い直線突進、3方向の毒弾|
|熾火の古竜|扇形の炎、7方向の火球|
|瘴気のヒュドラ|5方向の胞子弾、鈍足付きの地面攻撃|
|白霜の巨人|大きな叩きつけ、5方向の氷弾|

槌は通常敵を押し戻すが、ボスは押さない。短剣は接近する危険と高速連撃を交換し、槍は長い直線、大剣・斧は集団処理、弓は距離、刃輪は往復、杖は周囲爆発、魔導書は追尾する3連弾を生かす。武器の基礎威力・速度・射程は `src/weapons.mjs`、継続した数値仕様は [RELEASE_V06.md](RELEASE_V06.md) を参照。

### 全武器共通のコア

数字ピラミッドの合成は「左下の出力＋右下の出力＋自分の能力」を維持。経路が重なれば効果も重なる。最大9段45枠、数字の固定・同段重複禁止・下2数字の和の1の位という条件も維持。

貫通は近接で巻き込み数、刃輪で追加斬撃になる。反射は近接で別の敵への弱い追撃、誘導は近接の攻撃角・槍の幅を広げる。分裂は近接でも魔力片を生み、毒・爆発・放電・吸収も全武器で発動する。回収・視界・移動・防御などは主人公へ適用する。単体の無限ボスでは、別の敵へ飛ぶ効果に対象がいないため追加ダメージは生じない。

## 戦利品と帰還

戦利品はコア、金貨、素材、装備、消耗品の5分類。地面に落ちた段階では加算せず、接触回収して今回の荷物へ入れる。回収も壁を越えない。次の階には拾った品だけを持ち越す。

20秒生存＋規定数撃破でその階を攻略。5階ごとはボス討伐も必要。緑の帰還陣で戦利品を確保し、金色の階段で次の階へ進む。死亡・放棄では今回の未確保品を失い、出発前の資産は保持する。使った消耗品は消費済み。

通常のコアは20,000個、装備は2,000個が所持上限。出発時の残り枠を渡し、枠を超える品は拾わず地面に残して通知する。帰還処理は全項目を検証して一括確定。予期しない確定失敗では復旧用の帰還品を保存し、持ち物画面に再試行・書き出しを出す。

### ドロップ率

通常敵の各判定は独立。固有装備を持たない通常敵も5種いる。

|戦利品|通常敵|階層ボス|
|---|---:|---:|
|金貨|100%、基礎2〜5G|100%、基礎20〜35G|
|その敵だけの素材|45%、1個|100%、1〜2個|
|一般コア|12%|通常枠なし|
|汎用装備3種から1個|4%|なし|
|その敵の限定装備|該当する10種の敵で4%|固有枠の50%|
|そのボスの限定コア|なし|固有枠の50%|
|癒しの霊薬|6%|40%|
|守りの巻物|2.5%|なし|

各階の3体目は一般コア1個を保証し、固有枠とは別に扱う。金貨は基礎額に `min(500, floor(sqrt(階層−1)×2))` を加算し、ボスではこの補正を4倍にする。

ボスの固有枠はコアか装備の**どちらか1個**を保証する。固有枠のレア度はレア75%・エピック22%・レジェンダリー3%。一般品は既存の階層別レア度テーブルを使う。個体値は各能力95〜105%で入手時に決まり、装着・帰還・読み込みで抽選し直さない。

### ボス限定コア5種

次はコモン・個体値100%の定義基準。実際のボスドロップはレア以上なので、レア度補正と個体差を掛ける。

|取得元|コア|基準効果|
|---|---|---|
|草原の古老樹|古樹の心核|HP +1.5、自然回復 +0.02HP/秒|
|砂丘の大蠍|砂蠍の毒針核|毒強度 +1%、貫通 +0.04|
|熾火の古竜|灰竜の焔核|爆発強度 +1%、威力 +2.5%|
|瘴気のヒュドラ|沼蛇竜の血核|吸収 +0.008%、追加攻撃 +0.018|
|白霜の巨人|霜巨人の冠核|鈍足強度 +0.8%、射程・間合い +0.3%|

一般のコア抽選プールから除外し、別の敵からは落ちない。全武器で使え、実験室では全種類を比較できる。

## 装備・素材・工房

装備18種（汎用3、通常敵限定10、ボス限定5）、素材20種（20敵それぞれ固有）、消耗品2種、製作20レシピ。

装備枠は防具・護符・靴の3つ。武器そのものは頂点の武器核が担う。全装備は職業・武器を問わず装着でき、HP・回復・威力・速度・間合い・視界・回収・防御などを補強する。装備補正はコア合成後に1度だけ掛け、ピラミッドの経路数では増幅しない。装備を交換しても前の個体は所持品に残る。

被ダメージ軽減の装備上限35%、状態異常耐性の装備上限60%。結界との軽減は乗算。例えば装備で20%軽減＋結界30%なら、100ダメージは `100×0.8×0.7=56` になる。

癒しの霊薬は40Gで最大HPの35%を回復。守りの巻物は60Gで8秒間、被ダメージ30%減・状態異常50%減。道具は共通1秒の再使用間隔があり、HP満タン・結界の重複時には消費しない。探索中に拾った未確保の道具はまだ使えず、帰還後に在庫へ入る。

通常素材2個＋12Gで霊薬、または2個＋20Gで巻物を製作する。各ボス素材3個＋100Gでそのボスの装備を**レア・全能力100%個体値**として確定製作する。抽選で狙う入手と、素材を集めて確定製作する入手を両立する。

## 保存・記録・実装範囲

所持品キー `core-descent-v4` を維持。既存コアのID・数字・個体値・配置を保ち、装備・素材・道具の追加欄を移行する。道具欄のない旧セーブと新規プレイヤーに霊薬3個を一度だけ配布し、使い切った在庫を再配布しない。

実験室は装備18種のコモン見本、素材各10、道具各10、1,000Gを持つ独立資産。通常品に変換・混入しない。

自己記録はルール0.7.0、チャレンジ`fantasy-worlds-01`、保存キー`core-descent-records-v7`。以前の記録キーを削除せず、別条件を混ぜない。出発時のコア・装備・道具数を複製して記録。固定シードでも探索ごとの個体IDを分け、再挑戦の帰還品と重複しない。

180秒の無限ボス試験は階層ボスと別。レベル1固定・固有の衝撃波・消耗品不可・戦利品なし。装備とコアの性能差は維持し、実際に与えたダメージだけを記録する。

公開はブラウザー内保存のアルファ版。オンライン認証、他プレイヤーとのオークション、サーバー検証済みランキングは未接続。金はゲーム内通貨で、現金取引はない。アイテムに永続的な取引禁止は設定していない。

## 検証と配信

`npm test`、`npm run build`、`npm run balance` を使用する。数値レポートは武器単体の命中仮定と、実際の敵AI・壁・視界を伴う戦闘を区別する。フルブラウザーの画面確認と狭い縦・横幅で確認し、実機スマートフォンでの入力検証とは区別する。

PiXiEEDの静的配信は `core-descent/index.html` だけを公開する。`src/`・`tests/`・`docs/`・`dist/`・`qa/`・プレビュー設定はゲームの公開パスへ配信しない。開発用画像やQA画面はアップロードしない。
