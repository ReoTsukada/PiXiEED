# CORE DESCENT v0.8 — 滑らかな視界と、武器の構え

主人公の周囲から外へ向かって自然に暗くなる視界と、武器ごとの移動・攻撃条件を追加する。5フィールド、敵の行動、固有戦利品、装備・工房の継続仕様は [RELEASE_V07.md](RELEASE_V07.md) を参照。

## 視界の明暗

主人公に近い場所を明るくし、離れるほど滑らかに暗くする。光の中心は主人公の連続した位置に追随する。現在の視界と既探索の薄暗い地形を自然につなぎ、未探索へ向かう境目も柔らかくする。

この変更は描画の明るさに適用する。視界コアによる半径、壁が遮る視線、敵の発見・自動照準、攻撃判定は従来のルールを使う。未発見の敵・戦利品・出口を明暗処理から開示しない。ミニマップは現在視界・既探索・未探索を区別する。

原画の32×32スプライトをぼかさず、光と霧の重なりを滑らかにする。低画質設定でも距離による滑らかな暗転を保つ。

## 移動しながら戦う武器と、足を止めて振る武器

基本は移動しながらの自動照準・自動攻撃。剣、短剣、槍、斧、弓、刃輪、杖、魔導書の8種類は、移動中も攻撃できる。

大剣と槌は、移動入力を離して短く構えたあとに自動攻撃する。構えが必要な分、1撃の基礎威力を引き上げる。

|数字|武器|構えに必要な静止時間|基礎威力|基礎攻撃回数/秒|基礎射程|
|---|---|---:|---:|---:|---:|
|2|巨人の大剣|0.18秒|68 → **90**|0.72|87px|
|5|岩砕きの槌|0.28秒|62 → **88**|0.70|61px|

数値はコア・装備・会心などの補正前。大剣は最大6体を広く薙ぎ、槌は最大3体へ命中して通常敵を24px押し戻す。槌でボスは押せない。ほかの8武器の基礎数値は維持する。武器定義の正本は `src/weapons.mjs`。

### 構えと攻撃間隔

- 移動入力を離すと構えが進む。動き出すと構えは最初に戻る。
- 構えが完了し、攻撃間隔の待ち時間も終わり、射程内に敵がいると自動攻撃する。
- 攻撃後も静止を続ける場合、次の攻撃には通常の攻撃間隔を使う。毎回構え直す待ち時間は追加しない。
- 攻撃直後から自由に移動できる。振り終わるまで主人公の移動を固定する処理は入れない。
- 移動中も攻撃間隔の待ち時間は進む。撃てなかった通常攻撃は蓄積せず、止まった瞬間の追いつき連射は行わない。
- 回復から発生する追加攻撃にも同じ構え条件を適用する。探索階層が変わると構えを初期化する。

戦闘画面には現在の攻撃状態と準備の進み具合を表示する。移動中に攻撃できない理由や、構えが完了する時点を確認できる。キーボードと画面ドラッグで同じ条件を使い、入力の大きさ0.05以下は共通デッドゾーンとして移動させず、構えも解除しない。壁へ向けて移動入力を続けている間は構えない。

これにより、大剣・槌では「敵の攻撃予告を避ける → 安全な場所で止まる → 重い一撃 → また移動する」という間合いの判断が加わる。ほかの武器では、移動しながら距離や角度を調整して攻撃を続けられる。

## コアと数値の見方

全32種類のコアを全10武器で使用できる。最大9段45枠、数字の条件、下2つの出力に自身の能力を足す合成、レア度・個体値・増幅のルールは維持する。武器変更によって職業やコアの装着制限は追加しない。

攻撃速度の強化は攻撃間隔に作用する。大剣・槌の構え時間は武器固有の値を使い、攻撃速度では短縮しない。表示する理論DPSは条件が整った状態での継続命中を想定する。実戦のDPSは移動・構え・射程・壁・命中の機会によって変わる。

## 保存と記録

所持品の保存キー `core-descent-v4` を維持する。コア、装備、素材、消耗品、配置を引き継ぎ、今回の更新による個体値の再抽選は行わない。

武器の威力と攻撃条件が変わるため、自己記録はルール `0.8.0`、チャレンジ `fantasy-stance-01`、保存キー `core-descent-records-v8` とする。以前の記録キーは削除せず、異なる戦闘条件の記録を混ぜない。180秒の無限ボス試験にも同じ構え条件を適用する。

通常探索と実験室の資産は引き続き分離する。オンライン認証、実プレイヤー間オークション、サーバー検証済みランキングは未接続。

## 試す手順

拠点で「体験する武器」と「体験する場所」を選び、「選んだフィールドを体験」で開始する。剣で移動中の攻撃を確認し、大剣または槌へ切り替えて、移動を離したときの構えと一撃を比較できる。体験モードは9段の完成ビルドと貸し出し品を使う。

移動はWASD・矢印キー、または画面ドラッグ。照準と攻撃は自動。Qで癒しの霊薬、Eで守りの巻物。Space/Escapeで一時停止。

## 検証と配信

`npm test`、`npm run build`、`npm run balance` を使用する。確認対象は滑らかな距離減光、未探索情報の非表示、移動中と静止中の攻撃条件、構えのリセット、追加攻撃、ボス試験、画面上の説明と実際の数値の一致。

画面はデスクトップと狭い縦・横幅で確認する。ブラウザーの表示確認と、実機スマートフォンでの入力検証を区別する。配信対象は生成した `core-descent/index.html` のみ。QA画像・プレビュー設定・開発用ページは公開しない。
