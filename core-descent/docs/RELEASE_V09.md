# CORE DESCENT v0.9 — 静止詠唱と移動詠唱、探索する五つの大地

杖と魔導書を異なる立ち回りの魔法武器に分け、主人公・モンスター・地形の原画とフィールドの景観を更新する。職業は追加せず、全32種類のコアを10種類の武器で共通利用する。

## 二系統の魔法

| 項目 | 8・星火の杖 | 9・古代の魔導書 |
|---|---:|---:|
| 攻撃条件 | 0.35秒の静止詠唱 | 移動中も詠唱可能 |
| 基礎威力 | 45（従来25から80%増） | 魔弾1発あたり12 |
| 基礎攻撃速度 | 1.35回/秒 | 1.10回/秒、1回につき3発 |
| 発射間隔 | 約0.741秒 | 約0.909秒、連射内は0.1秒間隔 |
| 基礎射程 | 350px（約10.94マス） | 300px（約9.38マス） |
| 弾速 | 245px/秒 | 300px/秒 |
| 固有効果 | 初回命中時、半径55pxの別の敵へ70%の爆発 | 毎秒1.2radの追尾 |
| コア等の補正前・直撃参考DPS | 60.75 | 39.60（3発とも命中時） |

DPSは会心・コア・装備・レベル・範囲巻き込み・移動・初回の詠唱時間を含まない、継続命中の比較値。杖の初期爆発は別の敵に31.5ダメージを与え、直撃相手に二重加算しない。実際のコモン武器核にも自身の威力補正があるため、基盤画面の表示値は上の武器基礎値と異なる。

杖は安全な位置で足を止め、遅いが強い魔力球で敵群を狙う。魔導書は移動しながら距離を保ち、追尾と3連射で攻撃機会を維持する。射程と視界は独立し、射程が長くても壁や未発見の敵を越えて照準しない。

### 詠唱と移動

- 杖は移動入力を離して0.35秒経過すると発射可能になる。詠唱中に動くと準備を最初からやり直す。
- 発射後はすぐに移動できる。既に放った魔力球は飛び続ける。
- 静止を続けている間は通常の攻撃間隔で連射する。毎回0.35秒の追加待機は入れない。
- 移動中も攻撃の待ち時間は進む。移動中の未発動攻撃は貯め込まない。
- 回復による追加攻撃も同じ詠唱条件に従う。攻撃速度のコアは攻撃間隔を短縮し、0.35秒の詠唱条件は変えない。
- 戦闘HUDに「止まると詠唱」「詠唱中」「次の攻撃まで」を表示する。魔導書は「移動しながら詠唱」と表示する。

大剣0.18秒・基礎威力90、槌0.28秒・基礎威力88の構えは継続。計7武器が移動中に攻撃し、大剣・槌・杖の3武器が静止準備を必要とする。

## 32×32原画と景観

人物・敵・地形はコードで描くオリジナルのドット原画を使用する。人物と敵の原画は32×32の水平層を高さごとに重ね、8方向と歩行フレームを表示する。ボスの表示倍率は原画サイズと分ける。描画の品質は敵の当たり判定・移動速度・攻撃の数値を変えない。

主人公は顔・髪・服・革装具・マントの層を分け、敵は種別ごとの輪郭、体格、装備、材質を描き分ける。部屋の景観はマップのシードから決定し、同じ部屋内のまとまりを優先して配置する。床や既存の壁に装飾を重ね、歩ける場所、敵の攻撃予告、危険床、出口の判別を保つ。

### フィールドごとの景観

| フィールド | 地形と環境の描き分け | 部屋の見どころ |
|---|---|---|
| 翠風の草原 | 房ごとに陰影のある草木、根と枝、苔石、小さな花 | 花咲く旧庭、苔むす星の石畳、白花の回廊 |
| 砂眠りの遺跡 | 風紋、刻まれた砂岩、枝分かれしたサボテン | 砂に眠る太陽紋、青金のモザイク、風紋の中庭 |
| 熾火の火山 | 割れた暗い岩盤、黒曜石、鉱物の粒 | 黒曜石の花、冷えた鉱脈の広場、紫晶の断層 |
| 瘴気の湿原 | 湿った地面、苔、葦、古木と茸 | 蛍苔の庭、古根の紋様、月光茸の群生 |
| 白霜の雪原 | 風で積もった雪、雪をかぶった針葉樹、青氷 | 白霜の風配図、凍った星の庭、青氷の花紋 |

各部屋の景観は低い床模様と環境スプライトで構成する。進入可能な床を新しい壁へ変更しない。危険床や攻撃予告はその上に描き、主人公・戦利品に近い小さな植物などは薄くして視認性を確保する。

光や粒子はフィールドごとに花粉・砂塵・火の粉・胞子・雪を使い分ける。表示数は高品質で最大36、軽量で最大12、演出軽減時は省略する。描画用の原画・地形・部屋景観をキャッシュし、毎フレーム作り直さない。

地形生成は6〜9部屋と短い2マス幅の接続路を継続する。装飾生成はゲームの乱数列を使わず、敵の出現・戦利品・戦闘結果に影響しない。未探索の景観や光を先に見せず、主人公から滑らかに暗くなる視界と既探索の薄暗い地形を維持する。

## 保存と記録

所持品は引き続き `core-descent-v4`。コアの数字・レア度・個体値、装備、素材、消耗品、編成は引き継ぐ。

杖の攻撃条件と威力が変わるため、自己記録はルール `0.9.0`、チャレンジ `fantasy-magic-01`、保存キー `core-descent-records-v9` に分ける。以前の記録キーは削除しない。通常と実験室の記録は混ぜず、無限ボス試験でも同じ武器条件を使う。オンラインランキングと実プレイヤー間オークションは未接続。

## 試遊

拠点の「体験する武器」で「8・星火の杖」か「9・古代の魔導書」を選び、好きなフィールドを指定して「選んだフィールドを体験」を押す。体験は9段の完成ビルドと貸し出し品で始まる。各フィールドの景観と固有の敵をすぐ確認できる。「ボスのいる階から」を選ぶと、そのフィールドのボス階から試せる。

移動はWASD・矢印キー、または画面ドラッグ。Qで回復、Eで結界。Space/Escapeで一時停止。通常探索は所持品を使って1階から始め、帰還すると今回の戦利品を確保する。
