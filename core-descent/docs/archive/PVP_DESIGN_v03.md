# PvPの推奨仕様 — 設計案 / オンライン対戦は未実装

## 結論

通常の無限ダンジョンはソロPvEのまま残す。最初の直接対戦は、任意参加の1対1アリーナにする。次の拡張として、所持装備の価値がそのまま反映される専用PvPvEダンジョンを検討する。両方を同時に公開しない。

「桁違いのPvEビルドを作ること」と「即死だけで終わらない対人戦」を別の係数で扱う。対人用に変更しても、所持品の個体値やPvEでの能力は変えない。

## 1. 最初に作るアリーナ

|項目|提案|
|---|---|
|参加|任意。1対1、装着品も所持品も失わない|
|基本操作|移動のみ。銃は自動照準・自動射撃|
|編成|9段45枠。同じ数字ルールを厳守|
|装備差|全25種類×全数字の貸出コアを用意し、全てレア・個体値100%に標準化|
|戦術差|コアの種類、数字の配置、局所増幅、立ち位置は維持|
|長さ|1ラウンド90秒、2勝先取、最大3ラウンド|
|ステージ|対称形。中央障害物と2本以上の回り込み経路。出現位置をラウンドごとに交代|
|決着|45秒から安全地帯を縮小。90秒で双方生存ならそのラウンドは引分け。最終勝数が同じなら試合も引分け|
|回復対策|45秒以降、回復倍率を1秒につき2ポイント下げ、90秒時に10%まで低下|
|途中編集|マッチ開始から終了まで不可。試合前に編成確定|
|マッチング|勝敗に基づく対戦レート。所持資産額や表示DPSだけで決めない|
|報酬|初期検証は評価・記録のみ。市場へ流せる報酬を付ける段階で共謀・複垢・自動周回対策を検証|

貸出コアは編成用の仮想データであり、所持アイテムとして発行・売却しない。ユーザーの「全アイテム取引可」と、戦闘ルール上の貸出選択肢を混同しない。数字パズルの自動解答はしないが、練習用の既成配置を読み込んで編集できるようにする。

この設計は所持品の数値まで競うPvPではない。収集したレジェンダリーと個体値の価値はPvE進行と市場で残る。収集差もPvPに反映させたい場合には、後述の持ち込みPvPvEが適している。

## 2. 自動射撃で位置取りを成立させる

標的は遮蔽物で遮られていない相手だけ。命中は弾の移動と当たり判定で決め、自動照準だから必中にはしない。弾は発射時の相手位置へ飛ぶ。弾速320px/秒、寿命1.5秒、最大飛距離480pxを初期値とする。基礎移動165px/秒。300pxの距離なら弾の到達は約0.94秒なので、移動方向を変えて避ける余地を作る。

追尾は最大0.8rad/秒の旋回で止め、回避不能にしない。鈍足は最大25%、1秒持続、重ねても持続時間を足し算しない。完全停止・無限ノックバックは初期PvPに入れない。強い弾をかき消すほど派手な演出を重ねず、敵味方と当たり判定を読める表示にする。

PvEの「被弾後0.55秒無敵」は流用しない。そうすると連射や多弾が無意味になるため。全ヒットを判定し、同じ射撃から同じ相手へ当たる追加弾だけ35%威力にする。新しい射撃・別プレイヤーへの命中は通常扱い。子弾は発生元への命中禁止、再分裂禁止。二次効果は新たな直接命中イベントを起こさない。

レイアウト・遮蔽物・射程・一斉射撃IDの挙動は今後の対戦エンジン実装事項であり、現PvEエンジンで検証済みとは扱わない。

## 3. 数値案の正確な契約

同じ数字・コア種類・配置を、全てRare/ロール10000にしたコピーを合成する。その合成ベクトルをvとする。コアのレア度やロールを永久変更しない。

```text
HP = 1000 + min(500, max(0, v.hp))
通常弾威力 = 6 × max(0.05, 1 + 0.30×v.damage)
射撃回数 = min(6, 3×max(0.20, 1 + 0.25×v.rate))
追加弾数 = min(2, max(0, 0.16×v.multi))
会心率 = min(0.50, max(0, 0.05 + 0.32×v.crit))
会心倍率 = 1.5
静止/遠距離/追い撃ち強度 = PvE合成値 × 0.4
遠距離は350pxで最大
爆発/放電/毒強度 = PvE合成値 × 0.35
分裂 = min(3, PvE合成値 × 0.16)
移動 = 165 + min(16.5, max(0, v.move×0.25))
吸収率 = min(0.05, PvE吸収率)
吸収処理速度 = 最大HPの1%/秒まで（対戦実装時に適用）
自己修復 = min(2×PvE修復量, 最大HPの0.5%/秒)
```

追加弾、攻撃速度、会心などの上限はPvP専用。超過で伸びない数値はUIに上限到達と表示する必要がある。PvEにはこの上限を適用しない。調整対象は同一種類を積んだ最大火力だけでなく、補助・耐久・追尾を混ぜた構成との比較。

1対1の相手が1人しかいない場合、別対象へ飛ぶ爆発・放電は追加単体火力を生まない。このためPvE向け雷撃弾幕をそのまま最適な決闘ビルドとは呼ばない。対人専用の編成研究が必要になる。集団攻撃コアを決闘でも活かすための近接不発爆発や設置物破壊は、将来の別機能として仕様を定める。

## 4. 数値例

同じ9段プリセットをRare/100%に標準化。移動中、距離補正0、会心期待値込み、1射撃1発命中、追加効果・回復装填・防御なし。

|構成|HP|通常1発|射撃/秒|直接弾DPS|相手HP1000÷DPS|
|---|---:|---:|---:|---:|---:|
|雷撃弾幕|1000|18.168|4.800|89.38656|11.19秒|
|重砲狙撃|1000|40.038|2.82225|122.42122|8.17秒|
|吸収機関|1236|18.168|4.512|84.02337|11.90秒|
|増幅回路|1000|23.9568|3.504|90.48895|11.05秒|

最後の列は単純な算術比で、試合時間の実測ではない。初弾待ち・弾速・回避・遮蔽物・回復・射撃の離散性を含まない。重砲狙撃は静止+350pxで219.32DPS、HP1000/DPSは約4.56秒となる条件付きの高火力型。

数値の目標は、代表的構成の通常射撃を受け続けた場合に約8〜15秒、実際の回避・遮蔽物込みの1ラウンドは20〜60秒程度。現時点でこの実戦時間を達成したと主張しない。最適化後の全コア構成、相性の勝率、装備差別モードは未検証。

## 5. 拡張案：任意参加の持ち込みPvPvE

通常ダンジョンに強制侵入を足すのではなく、別入口の危険ダンジョンを選ぶ。最大4人、1回8〜10分程度を最初の検証範囲とする。持ってきたコアのレア度・個体値はそのまま使い、他のプレイヤーへ与えるダメージ・回復だけは対人用の係数を別途設計する。標準アリーナの一律Rare化はしない。

死亡で失うのは今回拾った未確保品だけ。装着中の45コアや拠点資産は落とさない。ドロップした未確保品の所有権は一度だけ移転し、複製しない。帰還地点は複数、選択前に危険モードであること・失う範囲を明示。序盤の初心者と熟練9段の無制限混在を避ける。

このモードにはコア収集と市場の価値を反映できる反面、資産差・出口待ち・共謀・プレイヤー人口の問題がある。最初から標準アリーナと複数の持ち込みリーグを同時開設せず、対戦試験と人口を見て導入する。

## 6. オンライン実装・不正対策

移動入力だけをクライアントから受け、HP・発射時刻・命中・編成・勝敗・所持品はサーバーが確定する。ブラウザーのDPS値や勝利申告を信用しない。対戦モード・係数バージョン・確定編成を試合開始時に固定し、同じ試合で更新前後の値を混ぜない。

同時発生するダメージは1tick分をまとめて適用し、プレイヤー配列の先後で勝敗が変わらないようにする。切断は一定の再接続猶予中も無敵にならず、30秒以上で敗北とする案。極端な遅延・入力順序・切断直前射撃・重複報酬を検証。公開前にリプレイ入力と確定結果を照合できるようにする。

現段階ではサーバー・対戦画面・マッチング・PvP報酬を実装または公開していない。`compileStandardPvp` と画面のPvPプレビューは数値設計を比べるためのもの。
