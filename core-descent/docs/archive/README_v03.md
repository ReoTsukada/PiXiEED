# CORE DESCENT — 開発スターター v0.3.0

**数字で組む。弾丸で生き残る。**

9段45枠の数字ピラミッドでパワーコアを合成し、主人公1人が自動射撃でランダムダンジョンを探索するゲームの、実行可能なローカル試作と制作手順です。完成品・公開済みサービスではありません。

## v0.3の更新

PvEの数値を調整し、全弾命中と毎射撃1発命中のDPSを分けました。分裂が貫通のたびに発生していた不整合を修正し、初回のみ・子弾45%にしています。吸収の処理速度、探索レベル上限、階層の接触ダメージも定義しました。

実験室に「全装着品の比較」レア度切替、編成画面に対人用の数値プレビューを追加。PvPはプレビューだけで、実際の対戦は未実装です。

数値の正本: `docs/BALANCE_V03.md`。対戦案: `docs/PVP_DESIGN.md`。検証値: `qa/BALANCE_REPORT.md`。`npm run balance`で再計算できます。元のv0.2ファイルは変更していませんが、v0.3へ読み込んだ個体は新しい能力定義で計算されるためダメージが変わります。

## まず遊ぶ

`dist/index.html` をPCのブラウザーで開きます。追加の画像・CDN・APIキー・npmパッケージは不要です。ファイル直接起動時の保存はブラウザーによって異なるため、「セーブを書き出す」でバックアップしてください。

新機能は「9段実験室」→「増幅回路 ×1.2」で確認できます。最下段の増幅を選ぶと上側の対象を黄色表示。各コアの詳細でレア度・個体値・範囲・強化後を比較できます。

戦闘を試すなら「9段実験室」→「雷撃弾幕」→「探索開始」。コアを触って数字条件、経路数、能力の合成を確認できます。「重砲狙撃」「吸収機関」も比較できます。実験室の所持品は通常探索とは別です。

通常探索では0〜9のコアを各1個所有します。移動はWASD・矢印キー、タッチ画面ではゲーム画面のドラッグ。射撃と照準は自動です。20秒生存と規定数撃破で帰還陣・階段が開きます。緑の陣へ歩くとコアと通貨を確保、金の階段へ歩くとHP・未確保品を引き継いで次層へ進みます。死亡・探索放棄・ページの再読み込みでは未確保品を失います。装着済み・所持済みのコアは失いません。

本番相当のローカルHTTP起動にはNode.js 22以降を使用します。今回の実行環境はNode.js 22.16.0です。

```sh
cd core-descent-v0.3
npm run build
npm test
npm start
```

ブラウザーで `http://localhost:4173` を開きます。依存パッケージがないため `npm install` は不要です。スマホ実機での操作・保存・負荷は未検証です。公開URLは作成していません。

## 制作の入口

Codexにはプロジェクトフォルダーを開かせ、`CODEX_START.md` の指示を使用してください。`AGENTS.md` に変更してはいけないゲームルール、`harness/ROADMAP.md` に次の実装と合格条件を記載しています。指示書を用意しただけでAIが背景で開発を継続するわけではありません。

```text
src/catalog.mjs     コア25種の能力データ
src/core.mjs        数字検証、合成、所持品、帰還処理
src/map.mjs         シード付き連結マップ生成
src/engine.mjs      DOMから分離した戦闘シミュレーション
src/market.mjs      取引の参照状態モデル（ネットワーク未接続）
src/app.mjs         画面操作と描画
src/style.css       PC・モバイル幅の表示
tests/              自動テスト
qa/                 実行結果・画面キャプチャ・数字全探索結果
docs/               企画、計算仕様、能力設計、サーバー設計
backend/schema.sql  本番DBに向けた未適用のDDL案
tools/              ビルド、ローカルサーバー、全探索、画面テスト
```

## 検証

`npm test` はNode標準のテストランナーを利用します。数字検証・70経路合成・45枠の重み総和511・帰還・戦闘・取引の76テストが通過しています。数字パズルの9段全探索は160解、左右反転を同一視して80解です。

```sh
npm run audit:puzzle
python tools/browser-smoke.py
python tools/browser-v02.py
```

画面テストはオプションです。PythonのPlaywrightとChromiumが必要です。生成HTMLを `set_content` で描画し、PC幅・スマホ幅の操作を検証します。HTTP/file URLからの起動や、実ブラウザーのlocalStorage永続化を検証するテストではありません。ゲート遷移・戦利品確保の一部はテスト用に状態を付与して確認しています。詳しくは `qa/TEST_REPORT.md` を参照してください。

## 注意

ローカルのセーブは編集可能です。デバッグフックもあります。**この所持品・通貨・戦利品を本番市場へ接続しないでください。** 本番はサーバーが戦闘結果・所持品・帰還・取引の正本を持つ必要があります。既存のサイト・リポジトリ・データベースには変更を加えていません。
