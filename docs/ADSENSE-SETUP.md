# AdSense 自動広告の設置（2026-09-29）

通常の公開ページでは、Google 公式コードを `<head>` に1回設置する。共通ヘッダーからは読み込まないため、マイページや管理画面へ意図せず広がらない。

通常広告のパブリッシャー：`ca-pub-9801602250480253`。特典用の報酬型広告は別経路で、共通ヘッダーから本人が「広告を見る」を押したとき、同じページ上で Ad Manager の `/23379831154/pixieed_rewarded` を要求する。Google Publisher Tag の `rewardedSlotGranted` 通知を受けた場合だけ1時間付与し、広告がない場合や途中で閉じた場合には付与しない。有効中の時間は加算しない。本日の無料1時間は別の操作として1日1回受け取れる。旧 `/pass/` と AdSense オファーウォールの設定は残っているが、通常の特典導線からは使用しない。通常広告の表示・クリックによってパスを付与しない。

## AdSense 管理画面側

AdSenseの「広告」→pixieed.jpの編集で自動広告を有効にして「サイトに適用」する。既存の「ページ除外」に公開ツールが含まれていれば、そのページにはコードを設置しても配信されない。除外対象のプライバシー・プロフィール・個人記録・管理・開発ページは、コード側でも読み込まない。

配置・形式・広告量はAdSenseのプレビューで管理する。全画面ツールではキャンバス、撮影・再生ボタン、下部ナビを覆わない設定を確認する。広告DOMをCSSで隠したり、通常広告を報酬型の代わりに扱ったりしない。

`ads.txt` はルートに既存の正しいDIRECT行がある。Googleの審査・広告在庫・地域・端末・ブロッカー等により表示されない場合があり、設置は配信保証ではない。AdSense自動広告の追加は、Ad Managerの報酬型在庫がない問題を解消するものではない。
