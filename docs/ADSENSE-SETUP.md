# AdSense 広告運用（2026-10-01）

## 現行方針

PiXiEEDの機能は無料で、Offerwallは使わない。通常広告はAdSenseで運用し、パブリッシャーID `ca-pub-9801602250480253` と手動ディスプレイ広告の既存slot `8825932060`（通常ページ）・`2995020884`（結果画面）、既存配置を維持する。制作・撮影・録音・再生・ゲーム操作中には広告を表示せず、ホーム・一覧・結果画面の広告だけを使う。

Offerwallは利用しない。コード側ではOfferwallだけを抑止し、Consentなどのプライバシーメッセージと通常広告は許可する。Google管理画面でもOfferwallメッセージを非公開にする必要がある。この管理画面操作は未実施。

共通ヘッダーから残り時間ゲージ、広告視聴、日次無料分の操作を外す。機能制限や広告視聴によるロックは設けない。AdSense自動広告は低頻度またはオフとし、制作・撮影・録音・再生・ゲーム操作中に全画面広告が出ないようページ除外を管理画面で設定する。広告供給や表示回数は保証できない。

以下は2026-09-29時点の設置・確認記録であり、Ad Manager/GPTやOfferwallに関する記述は旧方式の記録として読む。手動slot ID、配置、除外、過去の数値は履歴として保持する。

過去構成の参考資料：[Offerwallメッセージの作成](https://support.google.com/adsense/answer/13866332)、[Offerwallの概要](https://support.google.com/adsense/answer/13865318)、[報酬付き広告の選択肢](https://support.google.com/adsense/answer/12726063)、[Funding Choices API](https://developers.google.com/funding-choices/fc-api-docs)。

## Google管理画面での設定手順

1. AdSenseの「プライバシーとメッセージ」→「Offerwall」→「管理」で `pixieed.jp` の既存Offerwallメッセージを非公開にする。
2. 自動広告は低頻度またはオフに設定し、制作・撮影・録音・再生・ゲーム操作の各画面をページ除外に含める。全画面広告などが操作を遮らないことを優先する。
3. ホーム、ツール一覧、店舗一覧、既存の結果枠で通常のディスプレイ広告を確認する。slot ID、位置、レスポンシブ枠は既存のまま使う。

GoogleアカウントとAdSense管理画面は変更していない。Offerwall非公開と自動広告頻度・ページ除外の反映は別途必要。設定後も広告在庫・地域・端末・同意状態等で広告が出ないことがあり、安定した供給は保証できない。
