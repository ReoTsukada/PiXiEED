# PiXiEED 操作の基準

PiXiEEDは「ボタンを押すサイト」ではなく「実際に触って操作するサイト」にする。新しい画面や改修はこの基準に合わせる。

## 原則

1. **対象を直接動かす。** 拡大・縮小はピンチ（PCはホイール）、移動・回転はドラッグ、選択はタップで行う。同じことをする＋/−や矢印ボタンは置かない。
2. **ボタンは「動かせないもの」だけ。** 再生・一時停止、撮影、投稿のように1回押して始まる動作だけをボタンにする。閉じるボタンは残してよい（Escや外側タップでも閉じられるようにする）。
3. **値はつまんで変える。** 時刻や倍率のような連続値は、テープやスライダーをドラッグして変える。「+1時間」のような刻みボタンは作らない。
4. **選択肢は中身そのものを押す。** リストやセレクトボックスではなく、カード・行・切り替えスイッチを直接タップする形にする。
5. **動きには手応えを付ける。** はじいたら慣性で進み、指の下の点は指に付いてくる。`prefers-reduced-motion` のときは慣性やアニメーションを止める。
6. **操作を隠しすぎない。** ボタンがない分、初回だけ短い操作ヒントを出し、触ったら消す。見えない操作（長押しなど）は、パネル内の文言でも案内する。
7. **キーボードでも使える。** ジェスチャーには、矢印キー・+/−・Enter・Escなどの代わりを必ず用意し、`aria-label` に操作方法を書く。

## 適用済み

- 地球儀（`globe-prototype.html`）: ズーム・回転・リセットのボタンを撤去し、ピンチ・ドラッグ・2本指タップ・長押しで操作する。時刻パネルは時間テープ方式。詳細は `docs/globe/DESIGN.md`。
