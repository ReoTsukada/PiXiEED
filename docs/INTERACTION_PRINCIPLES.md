# PiXiEED 操作の基準

PiXiEEDは「ボタンを押すサイト」ではなく「実際に触って操作するサイト」にする。新しい画面や改修はこの基準に合わせる。

## 原則

1. **対象を直接動かす。** 拡大・縮小はピンチ（PCはホイール）、移動・回転はドラッグ、選択はタップで行う。同じことをする＋/−や矢印ボタンは置かない。
2. **ボタンは「動かせないもの」だけ。** 再生・一時停止、撮影、投稿のように1回押して始まる動作だけをボタンにする。閉じるボタンは残してよい（Escや外側タップでも閉じられるようにする）。
3. **値はつまんで変える。** 時刻や倍率のような連続値は、テープやスライダーをドラッグして変える。「+1時間」のような刻みボタンは作らない。
4. **選択肢は中身そのものを押す。** リストやセレクトボックスではなく、カード・行・切り替えスイッチを直接タップする形にする。
5. **動きには手応えを付ける。** はじいたら慣性で進み、指の下の点は指に付いてくる。`prefers-reduced-motion` のときは慣性やアニメーションを止める。
6. **操作を隠しすぎない。** ボタンがない分、初回だけ短い操作ヒントを出し、触ったら消す。見えない操作（長押しなど）は、パネル内の文言でも案内する。
7. **キーボードでも使える。** ジェスチャーには、矢印キー・+/−・Enter・Escなどの代わりを必ず用意し、`aria-label` に操作方法を書く。

8. **パネルより画面。** 見ている対象に関わる情報（天体の位置、倍率、観測地点など）は、パネルに並べず画面上の対象のそばや端に出す。画面外の対象は、端に方向を示すマーカーを出してタップで向かわせる。
9. **普段は小さく畳む。** 常に出すのは最小限（例: 再生と時刻）にし、詳細は触ったときだけ開く。開いたものは外側のタップで閉じる。

## サイズの基準

見た目と押しやすさを同時に揃えるため、操作部品の大きさは次の値だけを使う（`css/globe-prototype.css` の `:root` にトークンとして定義）。

| 部品 | 大きさ | トークン |
|---|---|---|
| ボタン・チップ・タブ・切り替え・スイッチを含む行 | 高さ44px（文字ボタンは角丸の横長、アイコンだけのボタンは44pxの円） | `--control` |
| 1行の入力欄・日時欄・時間テープ | 高さ48px、横幅いっぱい | `--field` |
| 複数行の入力欄 | 最小88px | — |
| ボタンの文字 | 14px | `--control-font` |
| ボタン内のアイコン | 20px | `--control-icon` |
| 補足の小さな文字 | 12px以上 | `--text-small` |

- 入力欄の文字は16px（iPhoneでフォーカス時に拡大されない大きさ）。
- 入力欄は縦に大きくせず、横に広げて整える。並ぶボタン（例: 「地球で選ぶ」「現在地を使う」）は同じ幅に分ける。
- セグメント（速さの切り替え、タブ）は枠全体を44pxにし、中の選択肢は枠いっぱいに広げる。
- これより小さい高さのボタンを追加するとテスト（`tests/globe/tool-shell.test.mjs`）が失敗する。

## 適用済み

- 地球儀（`globe-prototype.html`）: ズーム・回転・リセットのボタンを撤去し、ピンチ・ドラッグ・2本指タップ・長押しで操作する。時刻は左上のカプセル（ドラッグで時間移動、タップで詳細）、太陽・月は画面上のラベルと端のマーカー、望遠鏡は全画面＋薄いHUD。詳細は `docs/globe/DESIGN.md`。
