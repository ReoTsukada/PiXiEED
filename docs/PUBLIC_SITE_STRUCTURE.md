# PiXiEED public site structure

## Primary navigation

The persistent bottom navigation has three positions only:

1. Map — returns to the globe.
2. Context action — performs the most important action on the current page.
3. Tools — opens PiXiEED tools.

## Hamburger menu

The menu contains destinations that should not compete with the primary navigation:

- My page and personal activity
- Official PiXiEED works
- Participating shops
- Posting and shop participation
- About PiXiEED
- Usage guide
- Privacy
- Local display and analytics settings

## Content boundaries

- The map is the only discovery surface for user-submitted pixel art.
- Works contains official PiXiEED works only.
- Collection records official works found by the visitor.
- Stores combines the store layer of the globe with a browsable store list.
- Tools contains only PiXiEED applications and utilities.
- Admin is private and never linked from public navigation.
