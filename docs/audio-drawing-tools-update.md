# ドットで音楽の操作範囲整理（2026-10-04）

> 過去の仕様と検証記録。後続の依頼によりフレーム機能を提供する方針へ変更した。現行仕様は `docs/audio-frames-update.md` を参照。

## 最新の依頼

ユーザーは追加中の描画ツールを撤回し、ドットで音楽を「ペンと消しゴムだけ」にする方針を指定した。レイヤー・フレーム操作も、仕様が固まるまでAudioには不要との指定があった。

## IMPLEMENTED

- 描画は既存のペン・消しゴムだけに戻した。同じボタンを押して切り替える。
- Audioのレイヤー・フレーム操作パネルを取り除いた。ホストがない場合は操作部品を生成しない既存の処理を利用する。
- 共通の色パネル、色／音色切り替え、固定されたパネル配置は保持した。
- 今回追加途中だった図形などの処理・専用メニュー・専用検証ファイルを取り除いた。
- 保存済み作品のアニメーションデータの読み込み・保存・出力処理と、他のツールの機能は保持した。
