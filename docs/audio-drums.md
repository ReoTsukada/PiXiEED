# ドットで音楽：ドラム8音（2026-10-05）

既存の48音色に8種類の合成打楽器を追加し、全56音色にした。保存済みのID・順序・基本4音色を保持し、ドラム専用の新しい画面やレーンは作らず、既存の色と音色の選択に「ドラム」を追加する。

## 使い方と発音

色を選び、設定の「音色」から「ドラム」を開いて打楽器を選ぶ。縦位置によらず同じ音程・同じ長さで鳴る。横に続くマスは毎マス打ち直す。同じ色の同じ時間にある複数の縦マスは、最大のvelocityで1打にまとめる。異なる色の打音は同時に鳴らす。保存ノートと画像の画素は変更せず、再生時の投影だけを調整する。

| 音色ID | 名前 | 基準周波数 | 発音全長 |
| --- | --- | --- | --- |
| drum-kick | キック | 52 Hz | 0.42秒 |
| drum-snare | スネア | 185 Hz | 0.32秒 |
| drum-hat-closed | クローズハイハット | 450 Hz | 0.11秒 |
| drum-hat-open | オープンハイハット | 450 Hz | 0.55秒 |
| drum-tom-low | ロータム | 100 Hz | 0.40秒 |
| drum-tom-high | ハイタム | 160 Hz | 0.31秒 |
| drum-clap | クラップ | 900 Hz | 0.18秒 |
| drum-crash | クラッシュ | 600 Hz | 1.15秒 |

基準周波数は合成モデルの設定値で、ノイズ・金属音の知覚上の音程を示すものではない。キックとタムは発音直後に音程を下げ、スネアは胴の音と帯域を絞ったノイズ、ハイハットとクラッシュは非整数比の成分と高域ノイズを重ねる。クラップは3回の短いノイズ打撃と減衰する本体を重ねる。各音色の音源数は8以内。

両ハイハットは共通のchokeGroupを持つ。次の打刻時刻で前の余韻を8msかけて減衰させる。同時刻の異なる色のハイハットは共存し、その次の打刻で一緒に止まる。予約した未来の音を現在時刻で止めず、元の音量曲線は変更しない。

試聴・再生・WAV・動画は同じ音源を使用する。書き出しとループ終了時の停止は、ドラムの全長を含めて余韻を残す。元のタンバリン、シェイカー、スティールドラム、ロウドラムなどの挙動は変更しない。

## 参考資料

[AbletonのDrumSynth公式資料](https://www.ableton.com/en/live-manual/11/max-for-live-devices/)が説明する、キックの変調正弦波、スネアの発振器とノイズ、ハットの正弦波とノイズ、タムのピッチ変化、クラップの短い遅延とノイズを設計の参考にした。[Learning Musicの打楽器解説](https://learningmusic.ableton.com/make-beats/what-are-these-sounds.html)も参照した。設定値はこのアプリ向けの合成近似で、実録音との一致やAbleton製品の音の再現を保証しない。録音サンプル・外部ライブラリーは追加していない。

## 検証

Chromiumの実際のOfflineAudioContextで全56音色×3音程×3サンプルレート×2音長、計1008条件を検証した。無音・非有限値・出力ピーク1以上は0件。既存の高密度27条件の最大ピークは0.8388。通常音色の試聴と再生の一致、持続ノイズ、4画面サイズの横はみ出しも確認した。

関連するNodeテストは153件成功、失敗0。既存の音色切替・保存ブラウザー検証は398項目成功。320×568、390×844、844×390、1280×800の画面で確認した。ドラム専用のChromium検証は61項目成功。全8音で高さとマス長を変えたPCMの差は最大1 LSB、RMSの相対差は最大1.12×10⁻⁷で、ほぼ同じ発音を確認した。完全なバイト一致ではなく、16-bit量子化の2 LSB以内かつRMS相対差10⁻⁴未満を受入境界にしている。

最終列のクラッシュはループ終了を越えた2.15〜2.35秒にもRMS 0.015959で鳴り、発音終端後はRMS 0。オープンハイハットの余韻RMS 0.001216は、後続クローズハイハットで0になった。4画面サイズで8項目の選択・説明・保存画像の保持を確認した。結果は `/tmp/pixieed-audio-drums-20261005/audio-drums-browser-results.json`、8音を順番に並べた試聴WAVは同フォルダーの `audio-drums-8-voice-preview.wav`（6.17秒）。
