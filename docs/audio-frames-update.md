# ドットで音楽のフレーム編集（2026-10-04）

## 契約

最新の指定に合わせ、Audioはフレームだけを操作できるようにする。各フレームの表示レイヤーだけを1枚へ合成し、表示・編集・音符化する。Audioは1つの作業用レイヤーを使い、非表示レイヤーは含めない。元のDraw作品は変更しない。描画ツールはペン／消しゴムのみ。色／音色共通パネルと固定配置を保持する。

所有: 親が共通フレーム専用UI・説明・版番号・最終受入、実装担当がAudio処理、UI担当がAudio HTML/CSS、検証担当が隔離ブラウザ受入を担当。

変更範囲: Audio page/entry/HTML/CSS、取り込み時の選択フレーム引継ぎとその読み込み版番号、共通animation-controlsの任意frameOnly設定、使い方データと読み込み版番号、関連テストと専用検証記録。PXD schemaと元作品、他ツールの既存操作、関係のない未コミット変更は保持する。コミット・プッシュ・公開はしない。

## IMPLEMENTED

- 各フレームの表示レイヤーを1枚へ合成し、Audioの表示・編集・音符生成に使う。非表示レイヤーの画素は含めない。保存するAudio側は1レイヤーになり、元のDraw側の表示設定・ロック・画素は保持する。
- Drawで選択していたフレームを取り込み後の初期表示へ引き継ぐ。他のフレームも残し、選択・複製・空白追加・並べ替え・削除を提供する。レイヤー操作UIは提供しない。
- ペン／消しゴムで選択フレームを編集する。フレーム変更時に曲を再投影し、静止画由来の重複音符を除外する。画像に紐付かない手動音符を保持する。
- 再生位置に応じてフレームを切り替え、停止すると再生開始前の編集フレームへ戻す。保存・再読み込みでもフレーム選択を保持する。
- 静止画は最初のフレーム追加時に変換する。現在の絵が1コマ目、追加する複製／空白が2コマ目になる。半透明画素など、既存のアニメーション形式で表現できない画像は変換せず、絵と曲を保持して理由を表示する。
- 下の操作列には44pxのフレームボタンを1個置く。縦画面ではパネルを操作列より上に、横画面では右の操作列を避けて左側に表示する。色／音色パネルは同じ固定位置を共有し、フレームパネルと排他にする。
- 動画出力にはフレーム画像列と音楽時間を接続した。使い方説明と読み込み版番号を更新した。
