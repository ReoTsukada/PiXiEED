# ドットで音楽のフレーム切替停止（2026-10-04）

> 過去の仕様と検証記録。後続の指定でフレーム機能を提供する方針に変更した。現行仕様は `docs/audio-frames-update.md` を参照。固定表示の専用ハーネスは現行フレーム受入へ置き換える。

## 契約

Audioのレイヤー・フレームUIを削除した後も、再生時に保存済みアニメーションのフレームへ表示が移る問題を修正する。再生画面と書き出す動画は現在の絵を固定する。曲と保存済みフレーム・レイヤーデータは削除しない。他のツールと既存の未コミット変更は保護し、コミット・プッシュ・公開は行わない。

## 原因

前回は操作パネルを除去したが、`audio-page.mjs` の `startPlayhead()` が再生tickからフレーム番号を算出し、`selectedAudioFrameId` と `pxdImage` を更新する処理を残していた。動画出力にも全フレーム画像を渡す処理が残っていた。

## IMPLEMENTED

- 再生位置から選択フレームと表示画像を変更する処理を取り除いた。再生ヘッドと音は継続する。
- 動画出力では現在の画像snapshotを渡し、フレーム列とフレーム時間の指定を取り除いた。
- Audio入口と内部モジュールの読み込み版番号を `20261004-audio-static-playback-1` に更新した。
- 互換性のため、保存済みアニメーションとその曲の全フレーム分の音符は保持する。今回の変更は表示の固定であり、曲や保存データの単一フレーム化ではない。
