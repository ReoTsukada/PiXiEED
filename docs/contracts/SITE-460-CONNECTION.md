# SITE-460 Browser Connection

SITE-460 adds an additive, local-only smoke seam to the existing Draw2 entry.
`?site460=on` is accepted only on localhost, 127.0.0.1, or ::1. The default and
all non-local hosts remain OFF. The seam uses a fixed server-owned PLATFORM-450
composition and displays `PUBLIC_WORK_SOCIAL · COMPLETED`; it does not replace a
route or access production providers, data, or databases.
