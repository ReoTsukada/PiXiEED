# アニメーション実装の検証ゲート

2026-10-01。アプリ接続とローカルChromiumの描画・保存・復元、4画面寸法を確認しました。共通PXD・モード切り替えの案は撤回し、現在はツール別プロジェクトです。以下は当初の検証候補を含み、全項目の合格を意味しません。実機・公開サイトは未検証。

## 今回の独立試作

```sh
node --test tests/creation-suite/animation-prototype.test.mjs
node --test tests/creation-suite/animation-audio-prototype.test.mjs
node --test tests/creation-suite/animation-tile-prototype.test.mjs
```

これらのfixtureはアプリから読み込まない。PXDの実ファイル往復、ブラウザー操作、音源の再生を証明するものではない。

画素試作の確認対象:

- 256px背景を100コマへ複製しても画素は65,536バイト。
- 小さな画像の透明余白を除去し、座標が違っても同じ画素は共有。
- 複製したコマの編集で元コマは不変。透明と非表示レイヤーの合成。
- 257などの不正インデックスをUint8Array変換前に拒否。
- 容量超過の操作は元の画素・参照を変更しない。

タイル比較試作の確認対象:

- 256pxの非反復背景、原画と99複製に各1画素の変更。画素payloadは矩形6,553,600バイト、タイル166,912バイト。
- 1回の編集で新たに格納する画素は最大1,024バイト。`copiedBytes` はプール追加量であり、作業バッファへのコピー量を含まない。
- 31/32pxのタイル境界、透明への消去、16pxの端タイル、容量超過時の参照・ID・画素・計測値の復旧。
- 単一フレームのメモリ上の更新だけを確認。PXD保存やレイヤー統合、複数操作のトランザクションは未検証。

音楽試作の確認対象:

- 16列32コマ・120 BPMで64秒、64列8コマでも64秒。
- キャンバス幅にかかわらず1セル120 Tick。絵のdurationMsは曲の速さを変更しない。
- 同じ行・色・楽器のロングトーンはコマ境界を通過。空白・無音・色変更で分離。
- 最後→先頭のループ境界を自動結合しない。不正画素・寸法・コマ数を拒否。

## 必須の保存ゲート

- 旧静止画像PXD・既存曲は、アニメーションにしなくても内容を保持して読み書きできる。
- 1枚の画像を1レイヤー1コマへ変換し、合成結果の全画素が一致。
- 半透明、多色、上限超過の旧画像は未確認の変換を行わない。
- 新アニメーションの保存→終了→復元→再保存でID、画素、座標、順番、時間、表紙が一致。
- フレーム/レイヤーの追加、複製、並べ替え、削除、Undo/Redoで参照切れがない。
- 画素プールのoffset/length、整数溢れ、欠落参照、重複ID、不正版、破損を検証。メモリ確保前に容量超過を拒否。
- 未知の旧保存部品・メタデータ・バイナリを保持。未知のアニメーション版は読み込みを止め、原本を変更しない。
- 作品A→B→A、絵→曲→絵で別作品や別部品を上書きしない。
- 別タブの同じアニメーション編集は競合表示してコピー保存。曲のテンポだけの変更と絵の変更は既存の部品分離を維持。
- 最新の絵を曲へ取り込むと全コマが最新になる。既存テンポ・色の音色対応・公開パズルが不変。

## 操作と表示ゲート

320×568、390×844、844×390、1280×720で検証。ページに不要な縦横スクロールなし。コマ帯・レイヤーの内部スクロールだけを許容。

かんたんドットでは、初回表示・作品再読み込みでレイヤー×フレーム表が閉じていること、開閉でキャンバス寸法が変わらないこと、パレットとペン/消しゴムの共通ボタンがパネル表示中も押せることを確認する。44pxの番号・セル、2桁表示、描画済みの印、選択表示、Undo/Redo、閉じる・Escape・外側操作も `scripts/draw-cel-grid-browser-harness.mjs` で検証する。

`scripts/direct-cel-browser-harness.mjs` はマウスとChromiumのタッチ入力で、番号セルの整列、末尾追加、長押し並替、Undo/Redo、キャンセル、メニュー・表示時間・名前、空白コマを含む保存/明示的再読込を確認する。`scripts/smart-editor-browser-harness.mjs` は4画面寸法で、ペン再タップによる消去、色選択による復帰、音の試聴と消去時の無音、GIF保存メニュー、ページのはみ出しを確認する。実機iOSの証明ではない。

- コマ選択・複製・並べ替え・長押しメニュー・削除をタッチとマウスで試す。
- 描画、消しゴム、塗りつぶし、選択、スポイトが選択レイヤー/コマだけを編集。
- ズーム、パン、グリッドの位置は既存の共通操作と一致。コマ選択で移動しない。
- 再生停止で選択コマを取り違えない。オニオンスキンに描いてしまわない。
- 音楽コマの表示はAudioContext時刻と一致。タブ非表示→復帰で遅れを累積しない。
- 再生中の作品/モード変更で旧音・タイマー・イベントが残らない。
- 特典が必要な拡張サイズは、最終開始ボタン時点で権利を検査。開始済み処理は期限後も完了、作品は消さない。
- 実機Safari・Androidの再生開始許可、長押し、ピンチ、横向きも確認。デスクトップの縮小表示だけで実機PASSにしない。

## 性能ゲート

- 256px・100コマの静止背景、1ドット移動、全コマ別画素、8レイヤー合成で計測。
- 合成キャッシュ最大3コマ、表示範囲外のサムネイルを解放。停止中の再生ループなし。
- 1ストローク中の画素編集はバッチ確定。毎点の全面crop/hash/全参照走査を避ける。
- 独立画素32 MiB・メタデータ1 MiB・PXD全体64 MiBを別々に検査。コピー/Undo/エンコード時のピークも計測。
- 音楽のイベント数・同時発音上限を検査。3分以上の曲で開始時に全音源を作らず、先読み範囲のノードだけを作る。
- 長曲の音符重なり検査が全音符同士の二重走査にならない。
- 長いWAV/動画の書き出しは容量見積り、キャンセル、分割処理、失敗復旧を確認。自動的な切捨てや無音化はしない。

## 出力ゲート

- PNGは選択表紙だけ、GIFは全対象コマと指定時間、PXDは全編集情報。
- 画像は整数倍・補間なし。再入力すると等倍の画素を復元できる。
- グリッド・パレット・コマ帯・オニオンスキン・選択枠・音楽再生位置が画像に混ざらない。
- GIFの透明、色、コマ時間と、PNGのRGBAをデコードして画素比較。
- 曲動画はフレーム列と音楽が同じTickで進む。前後の音色releaseを切らない。
- 公開済みパズルの固定画像・正解・revisionをアニメーション編集が更新しない。
