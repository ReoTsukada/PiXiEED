## 統合時の判断と修正

1. **拡大画像の等倍復元**: 見た目だけの推定では単色や繰り返し模様の元寸法を区別できない。PiXiEEDが出すPNGには元寸法と整数倍率を記録し、各ブロックの実際の画素が一致する場合だけ復元する。改変・不正な記録から画素を落とすことは防ぐ。記録のない外部画像については、厳密な繰り返しブロックによる推定が残る。
2. **読み込みの互換性**: 共通画像処理と投稿側の呼び出しをそろえ、JPEGも読み込める形を保持した。JPEGデコーダーがEXIFの向きに従って縦横を交換した場合も受け入れる。ファイル容量と画像寸法はデコード前に確認する。
3. **描画の保存競合**: PNG生成や保存権限確認の途中で作品が切り替わった場合は、別作品を保存しない。クリック時の画素を複製し、作品と入力元が変わっていないことを確認する。
4. **ツール間の絵**: Claudeの独立した絵・保存履歴・持ち込み操作を保持した。描画・ジグソー・間違い探し・もの探しの絵は独立し、取り込み元の絵を編集しても持ち込み先を変更しない。PXDの未対応項目も保持する。
5. **ゲームの移行**: 新しい2つの遊ぶ画面に既存のヒントを組み込み、旧リンクの問題ID・クエリ・ハッシュを引き継ぐ。旧URLの転送判定はアプリ本体を読み込まず行い、初期化の二重実行を避ける。旧ページのフォールバック部分は保持した。
6. **GIFの負荷**: カメラではGIF用のコピーだけを整数間引きし、保持画素数を800万以内に収める。PNGの元画素には適用しない。Worker不可時も処理上限を設け、中断時は保持フレームを解放する。開始時に許可された生成は特典終了後も継続する。
7. **地球儀の描画**: Chromiumの画面画像では、正しい位置にあるiframeの描画が共通ヘッダーまで覆うことがあった。地球儀を含む要素に `contain: paint` と `isolation: isolate` を指定し、領域外の描画を抑えた。ボタン位置の検査に加え、実際の画面画像の画素を調べる回帰検査を追加した。
