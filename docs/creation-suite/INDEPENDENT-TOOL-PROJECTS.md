# ツール別プロジェクト

2026-10-01。ユーザーの指示により、共通プロジェクト・共通PXD・画面内モード切り替えを撤回。

## 操作

- かんたんドット、ドットで音楽、カメラ、各パズルは、それぞれ独立した作品を保存する。
- 通常の入口は新しい作品。保存した作品は、そのツールのプロジェクト一覧から選ぶ。カメラは直接撮影を開始する。
- 作品名のボタンに新規、名前変更、複製、保存、一覧、削除をまとめる。
- 「他のツール・以前の作品から取り込む」で、新しい作品IDのコピーを作る。元作品に変更を返さず、自動同期もしない。
- 音楽内の色・コマ編集は、再生・保存・音声/動画出力時にその曲の音符へ反映する。別ツールの絵を読み直す同期ボタンは置かない。
- PNG/GIF/WAV/動画は各ツールの保存メニューから使う。共通PXDの新規書き出しはUIから外した。

## データの安全性

`tool-project-store.mjs` が所有ツールを検査する。同じ保存基盤を内部で使っても、保存・一覧・削除・復元はそのツールが所有する作品に限定する。取り込みは新ID・新revisionと独立した画素バッファを持つ。

以前のデータは削除しない。旧PXDの読取/内部符号化は互換性のため残すが、全ツールを一つのPXDとして編集する仕様は採用しない。旧データは通常一覧から直接更新せず、コピー取り込み用の一覧から使う。クラウド同期・新しい共通保存形式は追加しない。

作品を切り替える前に保存し、別タブの保存競合は上書きせず止める。取り込み・保存に失敗した場合は元作品を維持する。

## 残した軽量化

疎な32pxタイル、複製時の画素共有、編集した部分だけの独立、差分履歴、描画バッファ再利用、曲の短い先読みを維持。通常は一枚の絵として使い、コマ・レイヤーは必要時に開く。

音声・動画の一回の書き出しは120秒/64MiBの安全上限がある。長い曲の再生・端末内保存は可能だが、長時間の分割書き出しは未実装。音楽の構造編集Undo、実機iOS/Androidの確認は未完了。
