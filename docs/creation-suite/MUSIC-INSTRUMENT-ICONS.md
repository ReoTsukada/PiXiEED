# 音色アイコン

[Figmaの編集可能な原本](https://www.figma.com/design/mWufwVmtFbygxgdxWwJXnT)からSVGを書き出しています。Instrument Iconsページ、一覧フレーム `4:2`。既存Undoを参照し、24 × 24、線幅1.8、丸い端と角に統一しました。新規26種類、比較用Undo 1種類です。

- `assets/icons/instruments/manifest.json`：FigmaコンポーネントIDと出力ファイルの対応。
- `js/creation/audio-instrument-icons.mjs`：既存48音色と楽器の形の対応。似た楽器は形を共有し、正式な音色名は既存の音色定義から取得します。
- パレットは色チップと楽器の形のみを表示。名前と色番号はボタンの読み上げ・ツールチップに残し、設定画面では音色名を選べます。
- チップ上の線は背景色の明るさに応じて黒／白を切り替えます。暗い設定パネル上のアイコンは白固定です。
- SVGは外部フォント、画像、スクリプトを含みません。表示と命名のみを変更し、音色ID、音の生成、PXD、パス判定を変更しません。
- アイコンは装飾用、操作対象は44px以上のボタンです。表示だけのアイコンを読み上げ対象にせず、ボタンに機能名を持たせます。

更新時はFigma原本を編集してSVGを書き出し、manifestの対応を保持してください。同じ音色IDに割り当てることで既存の曲をそのまま読み込めます。
