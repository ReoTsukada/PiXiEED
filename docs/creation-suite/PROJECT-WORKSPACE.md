# 作品単位の描画・音楽

`/draw/` と `/audio/` は同じプロジェクトを編集する二つの入口。端末内のPXDを正本とし、作品IDで分離する。従来の「前回の絵」「前回の曲」は旧下書きの取り込み用として残し、新しい別作品に読み込む。旧データを削除しない。

## 操作

- 上部の作品名からサムネイル一覧を開く。新規・名前変更・複製・保存をまとめる。
- 「描く」「音楽」の切り替えは保存完了後に同じ作品IDと保存版を渡す。音楽から描画へは作業用画像を渡し、原本はPXDに残す。
- 通常の入口は、そのツールで最後に開いた作品の最新版を再開する。URLで指定した作品がある場合はそちらを優先し、他ツールの前回下書きで上書きしない。
- 絵、曲、色と音色の対応、選択・ズームを作品内に保持する。描画のUndo履歴はその画面での編集に限り、再読み込みをまたいでは保持しない。
- 編集後、約1秒の待機で自動保存する。同一内容は保存版を増やさない。保存失敗は表示し、編集内容を維持する。
- PXDのファイル読み込みは新しい作品IDのコピー。書き出しはその作品の絵・曲・未知の部品を一緒に保持する。

## 混同・競合対策

`project-session.mjs` は呼び出し時に編集スナップショットと作品IDを固定する。保存は直列化し、最後に保存できた版へ比較付きで追加する。遅い保存の完了で新しい作品のID・URL・復元先を変更しない。

別タブの更新を検出したら上書きを止める。複製して続けられる。一覧から作品を開く際に競合が起きた場合は、このタブの編集を独立した「別タブの編集」プロジェクトへ保存してから選択作品を開く。退避保存に失敗したら切り替えない。読み込み・描画失敗時は元の作品の内容とIDを復元する。

画像のみのPXDから曲を作る際は、新しい空の曲を基にする。直前の別作品のテンポ・楽器・音符を使わない。サイズ変換は確認を挟み、原本は保持する。

## 検証

`node scripts/creation-suite-harness.mjs --suite pxd` にプロジェクト隔離・競合・複製・破損一覧・未知データ保持を追加。

2026-09-29 の確認結果:

- PXD: 62件、Draw: 30件、Audio: 67件、編集UI: 2件、計161件 PASS。変更したページとプロジェクトUIの構文チェックも PASS。
- ローカルブラウザー: 作品Aの赤い絵とテンポ60、作品Bの青い音符とテンポ180を個別に保存・往復。複製だけの音符削除後も元作品は保持。
- 別タブ競合: 最新版のテンポ60を上書きせず、競合したテンポ179の編集を別作品へ退避し、双方の再オープンを確認。
- 画面幅320px・高さ568px、および横向き844×390px: ページの縦横はみ出しと作品バー・描画領域・操作部・ナビの重なりなし。作品一覧は内部スクロール。
- PNG出力結果: パレット・メニュー・作品バーを退避し、2048×2048pxの保存結果を表示。ページの縦伸びなし。

実機Safariと本番サイトの確認・公開は今回実行していない。撮影の戻り先が一致しない場合は、既存作品の保存に成功してから新しい作品IDへ取り込む。

保存はこのブラウザーの端末内のみ。別端末へはPXDを書き出して移す。クラウド同期はこの変更に含めない。一覧は最新PXDの検証を行うため、大量の大きな作品での性能は別途計測が必要。
