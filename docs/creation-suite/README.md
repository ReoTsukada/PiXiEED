## 共有する体験と境界

入口は地球儀ギャラリーとツールの現行ナビゲーションを維持し、独立した作品一覧は置かない。各制作画面は「素材を選ぶ → 作る/遊ぶ → 保存」の主操作を一つずつ強調する。スマホの下部ナビと中央主操作は画面ごとの意味を持たせ、固定 UI がキャンバスや正解領域を覆わない。詳細設定を初期画面に並べない。HTML が意味と状態、CSS が見た目とレスポンシブ、JavaScript が作品状態と処理を受け持つ。

共有作品は `assetId` / `revisionId` / `contentHash` で版を固定し、`kind`、`source`、`owner`、`reusePermission`、`visibility` を別々に扱う。公開済み作品の表示と、自分の端末内画像を加工する操作は別判定。他人の投稿作品を編集・派生公開へ渡さないが、ジグソーの一時プレイには公開中の画像を使える。公開地図セルだけを他ツールへ渡し、精密な位置と審査前の画像は渡さない。制作途中の端末内データは公開投稿とは別の保存先に置く。各ツールの受け渡しはコピー元の内容を変更しない。
