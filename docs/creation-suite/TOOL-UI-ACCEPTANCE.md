## 作品管理の整理（2026-10-03）

共通の「作品を管理」は、開くたびに「保存した作品」のサムネイル一覧を表示する。「今の作品」に名前変更と他ツールへの送信をまとめ、複製・保存し直しは「その他」、外部ファイルと旧ツールの作品は「取り込む」に収める。空の一覧では検索欄を隠す。カードには作品名・寸法・保存日時を表示し、現在の作品を枠で示す。削除ボタン、長押し、キーボードの削除確認と削除後の復元を維持する。

使用されていない旧モード選択・作品部品一覧・サイズ設定の画面処理を除去する。保存形式、保存先、作品ごとの識別子、更新競合検知は変更しない。読み込んだ旧ファイルの原本がある場合だけ、その保存操作を残す。他ツールへの送信は独立した新しい作品を作り、元作品は変えない。パネルを開いたまま自動保存が完了した場合も一覧を更新する。

独立Chromiumで320×568・390×844・844×390・1280×800、全6ツールの入口を確認した。`scripts/project-cards-browser-harness.mjs` は186/186項目、`scripts/tool-transfer-browser-harness.mjs` は52/52項目が通過した。検索、長い作品名、44px以上の操作領域、入力欄の可読性、画面からのはみ出し、削除・復元、自動保存時の作品保護を含む。関連Nodeテストは39/39件通過。名前変更、旧ファイルの原本保存、独立した複製、編集中の作品削除と復元も追加確認した。実機端末と本番サイトは未検証。

## 状況に応じて変わる主操作（PiXiEED共通ルール・2026-10-03）

同じ場所の主ボタンを、現在の入力内容と作業段階に合わせて切り替える。選択肢ごとに常設ボタンを増やさない。ラベルは次に起こることを示し、操作を終えた結果だけでなく、入力の追加・取消・作品切替の直後にも更新する。処理中は同じボタンを無効にし、進行状況を表示する。ラベル、機能、aria-labelの意味を一致させる。保存や削除などの意味が異なる操作を予告なく同じアイコンへ割り当てない。

間違い探しでは画像枠を2つ先に置き、どちらか1枚で「違いを描く」、2枚で「候補を確認」、未選択では開始できない。もの探しでは画像と保存版の入口を同じ主操作へまとめ、選んだものに応じて「この画像で対象を指定」「保存版で対象を指定」とする。画像を選んだ時点ではプレビューだけを変え、開始操作までは作品を作成しない。保存版などの補助操作は折りたたみに収める。

画像枠そのものをタップ・キーボード・ドロップで操作できるようにする。選択後だけ取消を表示し、別作品・新規へ切り替えたら前の選択を破棄する。失敗した画像への置換は前の有効なプレビューを維持する。読み込み途中で切り替えた処理が、新しい画面のボタンや画像を上書きしてはならない。

このルールは全体の共通方針である。2026-10-03の実装対象は間違い探し・もの探しの作成入口。ほかの全ページのボタンを今回一括変更したとは扱わない。

ジグソーは完成図ボタンで盤面の隅に元絵を表示する。盤面と同じ確認済みRGBAを一度だけ描画し、比率を保つ。閉じるボタンとEscapeに対応し、小窓への操作を盤面のドラッグやズームへ渡さない。新規・再開・PXD読み込み開始時には前の絵を消す。公開作品の保存・書き出し導線は増やさない。

かんたんドットのUndo/Redoは、編集ボタンと同じ24pxの線アイコン・44px操作領域を使う。表示色はボタンから継承する。写真処理、描画履歴、保存契約は変更しない。

共通パスボタンは残時間を数字で主表示し、1時間ごとのバーを補足する。未使用の無料分と広告による追加を文言で区別する。延長時の演出は450ms以内で終了する。1日1回の無料受取、広告完了で1時間を加算、開始済み生成の完了を認める既存仕様を保持する。

ツール一覧とホームのカードは同じ24×24pxの絵・配色・アニメーション・カードの見た目を使う。共通の `js/tool-toys.mjs` から描画し、整数座標と整数倍表示を使い、輪郭を丸く切り抜かない。カードは最大8fpsで可視領域のみ更新する。動きを減らす設定では意味の分かる代表フレームで静止し、ホームカードの既存の手操作は維持する。ツール一覧の主操作は各ツールを開くリンクとする。ホームのヒーローは別の更新頻度を維持する。

月・地球・太陽の外周は、mount時に生成するmidpoint/Bresenhamの整数円マスクを使う。月の法線とクレーター位置も一度だけ計算し、20秒周期の球面照明で月相を表す。初期は明るい凸月、4000msの代表フレームは満月。新月の外周に浮動小数誤差の明るい点を残さず、星と流星は月の周囲から間隔を空ける。「ひらく」の表示は絵の外へ置き、月やほかのモチーフに重ねない。

## 検証

`node scripts/tool-ui-browser-harness.mjs` は外部通信を遮断した独立Chromiumで、320×568・390×844・844×390・1280×800を確認する。WebKitでは `PIXIEED_UI_ENGINE=webkit` と利用可能な既存Playwrightパッケージを指定して同じ確認を行う。

確認対象は整数倍の24pxプレビュー、ヘッダーの重なり、日次無料受取、充填後の静止、Undo/Redoによる画素の復元、完成図の元画素・閉じる・Escape・別画像への切り替え、保存導線の不在、動きを減らす設定。ホームとツール一覧の静止画素の一致、およびホームの鏡描き・音セル・パズル交換の入力座標も確認する。実機タッチ、本番配信、実際の広告配信をこのローカル検証の合格とは扱わない。

2026-09-29の最終確認では、関連Nodeテスト97件と、独立Chromium・WebKit各20項目（計40項目）が通過した。月の6位相、満月の外周、新月の孤立した光点の不在、星との間隔、ラベルとの非重複を含む。両ブラウザーの外部通信は遮断し、既存のログイン済みブラウザーや広告管理画面は使っていない。HTMLの更新番号は共通カードを `20260929-shared-toys-2`、共通ヘッダーを `20260929-tool-ui-1` にそろえた。未公開のローカル確認結果であり、実際のGoogle広告の配信可否を示すものではない。
