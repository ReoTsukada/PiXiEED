# 自分の作品の保存と、公開作品での遊び

PXD・PNGの保存、制作ツールへの受け渡し、制作画像の投稿は自分の作品だけにする。自分で描いた絵・撮った画像・端末から選んだ素材は従来どおり扱う。他の人の投稿は閲覧・いいね・パズルのプレイに使う。

## 判定と保存

- `work-save-policy.mjs` がPXD内の既知パズルの元作品参照を調べる。元の参照も確認し、他人の公開参照と描画画像が混ざったPXDを自分の制作素材へ変換しない。
- 公開作品の所有者は、既存の認証をサーバーで確認したうえで投稿の所有者・公開状態・元画像URLを照合する。ファイルの作者名や自己申告のIDでは許可しない。未ログイン・通信失敗・判定不能は保存を許可しない。
- 共通PXDメニューは所有権を確認するまで保存とツール移動を無効にする。実際の保存直前にも確認する。旧PXD原本の取り出しも同じ扱い。
- Draw・音楽・カメラのPNG保存と制作画像の投稿も共通の確認を通す。カメラを撮り直すと、以前のPXDとの紐付けを外して新しい作品にする。元の保存版は削除しない。
- ジグソーは他の人の作品でもプレイできる。途中の配置の端末内保存は維持するが、これは作品のPXD保存とは分ける。公開参照を持つ旧PXDからのプレイも現在の公開状態を再確認する。

これはサイトの保存機能と制作への受け渡しを制限する仕組み。公開画像のブラウザー標準保存、スクリーンショット、出自の分からない持ち込みファイルの作者判定まで保証するものではない。認証情報・パス期限は作品ファイルへ入れない。

## 検証

```sh
node scripts/creation-suite-harness.mjs --all
node scripts/work-save-browser-harness.mjs
PIXIEED_WORK_ENGINE=webkit node scripts/work-save-browser-harness.mjs
node scripts/pxd-puzzle-camera-browser-harness.mjs
```

所有者と非所有者、ログアウト、公開参照を含む混合PXD、ボタンを強制的に有効化した場合、自分の既存PXDの往復を確認する。ブラウザー検証の認証・投稿・画像取得はローカルの模擬応答であり、本番アカウントや実機の確認ではない。

## 地域に関連しない作品の投稿案（未実装）

プロフィールに任意の「活動拠点」を設定し、自由作品の展示セルの初期値として使う。作品の題材の所在地や撮影場所とは区別して「作者の活動拠点から展示」と表示する。活動拠点は市区町村程度で選び、正確な住所や現在地の入力は求めない。

地域作品では作品個別の場所を選び、自由作品では活動拠点を初期選択する。どちらも投稿前に地球儀で展示セルを確認・変更できる。活動拠点が未設定なら投稿時に展示場所を選ぶ。プロフィールを変更しても既存の投稿セルは自動移動しない。作品一覧ページの新設や架空の撮影地点の設定は不要。
