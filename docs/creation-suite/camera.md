# ドット絵カメラ：新ツールへの素材入口

`pixel-camera.html` と `js/pixel-lens/` は現行の公開ツール。ドット写真は投稿時に手描きドット絵と区別し、入力画像を音・ゲーム・パズルへ渡すときも `source=camera` を保持する。カメラの処理方式、画面、撮影動線を今回の制作ツール設計で変えない。編集した派生作品は別 ID/版で保存し、撮影元と公開済み写真を書き換えない。

**ハーネス設計:** `CAM-01` 撮影・保存・戻る・画面回転で既存 UI の主操作を失わない。`CAM-02` 撮影画像の元寸法/縦横比/画素境界が素材受け渡し後も保たれる。`CAM-03` `post_kind=pixel_camera` が地図上の同じ ID に結びつき、旧 `pixel_art` 行が変わらない。`CAM-04` 自分の画像から音/パズルを作っても元画像ハッシュと公開状態が変わらない。`CAM-05` 他人の公開カメラ作品は許可フラグに関係なく加工できない。撮影速度と端末カメラ権限は実機で別途測る。

**IMPLEMENTED（現行）:** カメラ画面と画像処理。投稿時の `post_kind` 区分はローカル作業ツリーにあり、本番 DB には未適用。**UNIMPLEMENTED:** 共通素材データへの受け渡し。**UNTESTED:** 新ツールとの実機連携。
