# 操作に応えるドットの演出

操作の結果を短く伝える。制作・保存・判定の正本と演出を分離し、音楽、描画、ジグソー、共通の設定と拡張パスで同じ演出基準を使う。

## 表現

- 音楽：試聴したセルと再生で鳴るセルの四隅を約220ms光らせる。再生位置は実際に音を予約したAudioContextの時刻からTickへ投影する。曲のTickや音声のスケジューラーは演出のために変更しない。
- 色選択：選んだ色の小さなドットをペンへ約220ms移動する。選択状態はすぐに確定し、演出の完了を待たない。
- 画像出力：出力できた画像の小さな見本を出力ボタンへ約240ms収める。実際のキャンバスを小さく複写し、演出用のPNGを追加生成しない。ファイル出力に失敗した場合は成功の演出を出さない。
- ジグソー：配置が実際に正しいと判定された場合だけ、置いたピースの角を約220ms光らせる。正誤判定、配置、元画像には変更を加えない。
- 設定：標準のdetailsを使い、開くときは設定ボタンに近い位置を起点に180msで現れる。閉じると内容を直ちに閉じ、元のボタンに140msの反応を出す。フォーカスやEsc・外側タップは既存の操作に従う。
- 拡張パス：期限が延長されたとき、小さな光のドットが240msでゲージへ入り、新しく満ちた行が下から順に短く光る。ボタンを押した瞬間にも反応する。初回表示や時間経過には追加の演出を出さず、450ms以内に静止する。残り時間の積み増しと期限の保存は既存の共通パスに従う。

## 軽さとデータの境界

`js/creation/interaction-effects.mjs` と `css/interaction-effects.css` は、作品のキャンバスへ描画せず、操作を遮らない装飾を上に重ねる。音符の光は最大4つ、色の移動・出力見本・正解の反応はそれぞれ1つの要素を再利用する。見本は最大64pxで、装飾を含めない元キャンバスから作る。

動きはCSSのtransformとopacityを主体とし、新しい連続描画ループや定期監視は追加しない。音楽の再生演出は既存の再生位置更新に合わせ、列が変わったときだけ更新する。画面を離れたときや配置が変わったときは装飾を終了する。OSとサイトの「動きを減らす」設定では動く装飾を出さない。

演出に問題があっても、音符編集、曲の再生、PNG出力、ジグソーの配置を失敗扱いにしない。PNGと端末内保存は作品データから生成し、装飾やカーソルを含めない。
