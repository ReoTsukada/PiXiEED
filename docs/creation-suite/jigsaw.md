# ジグソー：画素から切り出し、自由に組み立てる

2026-09-28更新。画像全体を2×2・3×3・4×4のマスへ分ける初版から、画素数に応じた凹凸付きピースと自由な作業スペースへ変更する。

## 形と操作

ピースの基本サイズをpxで選ぶ。最小3×3pxを基本として、辺の中央へ整数画素の突起・窪みを付ける。余りを極端に細い端ピースにせず、元画像の全画素を重複・欠損なく分配する。隣り合うピースの凸凹は共有した一つの境界から作り、凹凸のために画素を複製しない。透明・半透明画素も元の所属と値を保つ。

新しいパズルごとにピースの順序と90度単位の向きをランダムにして、下部のトレーへ並べる。ピースは空いているマスを探さず、作業スペースの好きな場所に置く。選択後の回転ボタンやキーボードで向きを変える。作業スペースは二本指で拡大・移動できる。大量の手持ちピースは区切って表示し、全ピース分のDOMや描画ループを常駐させない。

**正しい隣接ピースが、同じ向き・正しい相対位置で近付いたときだけ結合する。** 似た模様、単なる重なり、形だけの一致では結合しない。結合したまとまりは一つとして動き、回転できる。チェックや不正解の×は表示しない。全ピースが一つの正しいまとまりになれば完成。完成した絵の作業スペース上の位置や全体の向きは限定しない。

## 元画像・保存の保護

入口は自分の保存絵、PiXiEEDの公開投稿、端末画像の三つ。自分の絵はassetId/revisionId/contentHashの固定版を使い、最新の版へ勝手に差し替えない。公開作品はプレイのための参照と画像指紋だけを保存し、他人の画像を再公開できる制作素材にはしない。端末画像は本人が再開するため端末内へ保持できる。

作業状態はschemaVersion 2として、分割条件・乱数seed・ピース順・まとまりの所属・位置・回転・トレー状態をJSONへ保存する。CSSの座標ではなく論理画素単位で位置を持ち、画面サイズ変更で保存位置を変えない。凹凸マスクや画像描画用のcanvasは元の固定版と分割条件から再生成する。元画像の指紋/寸法が違う場合は復元を止める。

旧schemaVersion 1の下書きは、元の分割数・ピースID・置き場所を保持した移行で読む。新しい3px分割へ勝手に再分割しない。古い保存版は端末内の履歴に残す。安全に移せない小さすぎる旧画像は明示して止め、原本を変更しない。

PXDの共通保存は [INTEROPERABILITY-REVIEW.md](INTEROPERABILITY-REVIEW.md) の別提案で、今回のジグソー改修と混同しない。パズルの公開・ランキング・課金、他人の投稿の派生制作も今回追加しない。

## 改修の検証基準

- 全画素の所属が一意で、凹凸を再組立てしたRGBAが元と一致する。3px、余りのある寸法、非正方形、透明・半透明を含める。
- 位置・向き・隣接が違えば結合しない。正しい辺のみ結合し、結合後の移動/回転でピース同士の関係が変わらない。
- 配置・回転・トレー順・固定画像版が保存→再開で一致する。改変データ・重複ピース・偽の結合・元版欠損は拒否する。
- Chrome/WebKitの縦・短い横画面で、トレーからのドラッグ、自由配置、回転、結合、ピンチ、キー操作と44pxの操作範囲を確認する。
- 大きい画像を最小ピースで分けて上限を超える場合は、より大きいpxサイズを案内する。選択値や元画像を黙って変更しない。

実行面は `node scripts/creation-suite-harness.mjs --suite jigsaw` と、既存Playwrightを指定した `scripts/jigsaw-workspace-browser-harness.mjs`。単体試験、ブラウザー、物理端末、公開環境の証拠を分ける。

## 出典と最小体験

入口は公開中の投稿作品、自分の端末内に保存した絵、端末から選んだ画像の三種類とする。作品選択、2×2・3×3・4×4 のピース数、遊ぶ、の三段階だけ。手でピースを置いたら吸着し、完成時に元作品と作者を表示する。公開作品を選んだ場合、画像をアップロードし直す必要はない。

元画像は変更しない。端末内の保存絵は固定版の `source.assetId`、`revisionId`、`contentHash` を参照する。公開投稿は元投稿ID、公開URL、読み込んだ画像の指紋だけを保持し、画像本体をパズル保存データへ複製しない。端末から選んだ本人の画像は再開のため端末内だけに保存できる。縦横比を維持し、切り分けは画素の整数境界で行う。大きな画像は上限内へ最近傍で縮小し、補間による新しい色を作らない。小さい端末ではトレーをスクロール可能にし、盤面とナビが重ならない。完成の判定は全ピースの正しいセル・向きで行い、見た目の重なりだけでは判定しない。初版は回転なし。

公開作品の利用はジグソーをその端末で遊ぶ用途だけとし、他人の画像から新しい公開作品を作る導線は置かない。非公開・審査中・有料素材は選択肢に出さない。公開、ランキング、課金は初版から外す。

## ハーネス設計

`JIG-01` 透明画素と非正方形の 16×32、64×64、128×256 を切り分け/再組立てしてバイト単位で元画素と一致。`JIG-02` 盤面サイズ変更でもピース ID と解答セルは変わらない。`JIG-03` 端末内保存→再読込で配置を復元し、元画像の版を勝手に差し替えない。`JIG-04` 公開中の通常投稿は作者の許可値にかかわらず一時プレイ可、非公開・参照投稿・有料素材は入力から除外。`JIG-05` 公開画像を保存データへ複製せず、再開時に指紋照合して別画像へ黙って切り替えない。ブラウザーではタッチ操作、縦画面、下部ナビとの重なり、キーボード操作、元画素の表示を実機サイズで確認する。
