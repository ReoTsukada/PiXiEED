# PiXFiND：間違い探し・もの探しを簡単に作る

## 棚卸しと初版 UX

旧 `origin/pixfind-layout-fix:pixfind/app.js` に両モードの画面と差分/領域判定、`pixfind/index.html` と旧公開 SQL がある。現行 HEAD の公開ツールにはない。旧画面・通信・判定が一体の大きな実装は戻さず、判定だけ独立させる。

入口は作品の「遊びにする」。間違い探しは元作品を複製して少数の箇所を描き替えるか、同寸の2枚を指定する。自動検出した変更領域を色付きで見せ、制作者がまとめる/分ける/除外する。もの探しは元作品の上に対象マスクを描いて名前を付ける。元画像から自動で「何の物体か」を推定しない。どちらも最後に制作者自身が遊んで確認する。公開前は下書き、公開後は固定版を使う。

## 判定を分かりやすくする

差分は画像の元画素座標で行う。透明部分の RGB 値だけの違いは無視し、実際に見える色/不透明度の変化を拾う。候補領域は隣接画素から作り、近接候補の結合はプレビューで説明して作者が確定する。難易度によって正解そのものを変えない。線1本、小さい目、離れた点、広い塗り面を別 fixture にし、閾値で勝手に消さない。ゲームのタップ判定は表示倍率ではなく元画素に逆変換し、周囲の許容幅は見た目と一致させる。複数候補に同時に当たる場合は一意に決まるよう作者が確認する。

もの探しは作者が指定した各マスクを正解とし、背景の似た色や別の物体を誤認しない。空マスク・重複マスク・画面外・細すぎて押せない対象は作成時に警告し、明示修正まで公開できない。正解表示とヒントは同じ元画素マスクから作る。色判定や機械学習だけで正解領域を決定しない。

## データと権限

元作品の `assetId/revisionId/contentHash` と、問題に使う複製画像、正解マスク/領域、ラベル、公開状態を別に保存する。旧 `pixfind_puzzles` の `client_id` は所有権の証拠にしない。旧作品は閲覧・プレイの接続を先に行い、編集権限と他ツールでの再利用は本人確認・許可を別途解決する。旧問題の ID と共有 URL は保持する。

## ハーネス設計

`FND-01` 同寸/異寸、透明 RGB、1px の線/点、広い変更面から候補を得る。`FND-02` 4方向で接する差と斜めに接する差、近いが独立した2箇所を作者確認前に誤結合しない。`FND-03` 2倍/端末 DPR 3/レイアウト縮小でもタップが元画素の同じ対象を指す。`FND-04` もの探しの重複・空・画面外マスクを公開不可にする。`FND-05` 不正解の連打で正解状態が増えず、リロード後の進行状態と公開問題の固定版が一致。`FND-06` 旧問題は読み取り専用で遊べ、旧作者不明の編集要求を拒否。ブラウザーでは色以外にも番号/ラベルで候補を区別し、タッチ対象・ズーム・下部ナビの重なりを確認する。

**IMPLEMENTED（履歴のみ）:** 旧 PiXFiND の両モード。**UNIMPLEMENTED（現行）:** 独立判定、新 UI、新しい公開連携。**UNTESTED:** 現行本番の旧問題件数、ブラウザー/実機の再生。
