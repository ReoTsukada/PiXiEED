## 現行UIと投稿の契約

`tools/` の実画面はカメラと望遠鏡の2カード。`works/` と `tools/` の下部アプリナビは、HTML内の古いマークアップではなく `js/app.js` の `renderPublicShell()` が「ホーム・地図・ページ固有の中央操作・ツール・マイページ」に置き換えている。390×844と320×568でツールページの横はみ出しがないことをブラウザーで確認。320×568では初期表示のカード下部に固定ナビが重なるが、スクロールして両カードを操作できる。新画面の受入では静的HTMLではなく実行時のDOMと短い画面の到達性を確認する。

現行 `js/post-composer.js` は8〜128px/512色、作業ツリーの `js/globe/post-image.mjs` と `create-post` は8〜512px/128色。接続先DBの `user_posts` 制約は8〜128px/最大512色で、512pxへ広げる作業ツリーのmigrationと `post_kind` のmigrationは本番に未適用と確認した。現行受付は申告された色数の範囲は調べるが画像を復号して実色数を数えていない。新投稿の経路を実装する前に、画面・受付・DBの同一ルールと実画像検査を決める必要がある。
