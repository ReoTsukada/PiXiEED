# 共通制作ツールの操作欄・サイズ設定（2026-10-11）

## 入口とモード

入口ごとに初期モードを選び、同じPiXiEEDraw制作画面を開く。`/draw/` は描画、`/audio/` は音楽、`/pixel-camera.html` はカメラとして共通 Draw 制作画面を開く。切替中に独立エディターへ遷移せず、同じ作品のレイヤー・フレーム・パレット・保存履歴を使う。音楽モードでは専用レイヤーを表示し、音楽ページと描画コマの長さは独立する。従来の独立作品はコピーとして取り込み、元の保存版は保持する。`standalone=1` の既存単体ページも保持する。

基点は `f39c8ad8`。変更対象は制作画面の操作欄・描画設定・関連テスト。ショップ・ナビ、V2、Offerwall、共通 `/output/work/` の実装・設定は対象外。Electron、配布パッケージ、依存ライブラリの追加もない。

## 実装

- 左3ボタン／中央3行パレット／右3ボタンは維持。共通列を「色調・文字・サイズ・確定／選択解除」の固定4枠にした。通常画面の余白と隙間を削減し、対称中心の操作を既存の全体設定パネルへ移した。対称設定のON/OFFは全体設定に置く。
- サイズは左右入力別の設定。ペン・消しゴム・直線・矩形／楕円輪郭は1〜16px、初期値1px。スプレーは奇数の直径1〜33px、初期値5px（旧半径2px）。塗り図形の領域は従来どおりドラッグで決まる。サイズ設定を開く／閉じる／変更するだけでは画素・Undo履歴を変更しない。
- 整数画素へ描画し、補間、選択マスク、画面端、レイヤーロック、左右入力の所有権を維持。偶数サイズは増分を正方向へ寄せ、対称描画ではブラシ足跡自体も行列変換して正確に反転する。形状輪郭は指定した領域の内側へ太くする。
- 右の2枠は選択中のコピー／カット、コピー後の貼り付け／範囲へ、変形・貼付中の確定／取消を優先する。それ以外の矩形／楕円では「塗り ON/OFF」、塗りつぶしでは「隣接 ON/OFF」を表示する。独立した第2設定のない道具では無効の空き枠を残す。道具を選び直すと設定枠へ戻り、コピー済み画素は保持する。
- 隣接ONは従来の連続塗りつぶし。OFFは離れた同じRGBA色を対象レイヤー内で塗る。重複パレット色と完全透明色を正規化し、選択マスクの外は変更しない。ON/OFFは表示と `aria-pressed` を同期。
- 入力設定v1に後方互換の項目を追加。古いPXD／設定は1px・直径5px・隣接ONに正規化し、未知の拡張設定を保持。新しい左右設定もPXD保存・再読み込みで維持する。
- 矩形・投げ縄・色選択の内側を修飾キーなしでドラッグすると移動する。タッチ／仮想カーソルの追加選択は外から開始し、Shift／Ctrl／Metaの追加・減算は移動ハンドルの重なりでも保持する。移動ハンドルを拡縮用の角から除き、変形中も正確なマスクで内外を判定する。

## 通常描画領域の実測

6画面サイズ×3モードをローカル Chromium で確認。下表は描画／音楽の `.draw-board`。寸法と面積は表示上の丸めた幅・高さで算出する。

| ビューポート | 変更前 | 変更後 | 高さ増分 | 面積増分 |
|---|---:|---:|---:|---:|
| 1280×800 | 876×599 | 882×647 | 48px | 45,930px² |
| 390×844 | 370×427 | 370×479 | 52px | 19,240px² |
| 320×568 | 308×156 | 308×208 | 52px | 16,016px² |
| 844×390 | 562×204 | 563×248 | 44px | 24,976px² |
| 667×375 | 388×189 | 389×233 | 44px | 17,305px² |
| 1024×600 | 683×399 | 689×447 | 48px | 35,466px² |

カメラの高さ増分は45〜54px（390／320幅は52px）。全ケースでページのスクロール寸法がビューポート内に収まり、サイズボタンと追加の設定操作は44px以上。対称中心のスライダーとリセットも44px以上。設定パネルの内部スクロールは維持する。カメラ操作の内部スクロールは一部の短い画面で既存どおり残る。
