# かんたんドットの同じ色選択

この文書のカメラ試験は旧インライン方式での過去の記録です。現在のカメラは専用ページへの受け渡し方式で、最新仕様は `draw-camera-handoff-update-20261007.md`、旧方式の退避と前景合成確認は `draw-camera-inline-retirement-update-20261007.md` に記載しています。選択用のブラウザハーネスはカメラを呼ばない同色選択回帰へ整理しています。

カメラ機能の実装・単独検証を完了した後に追加したローカル実装。コミット・プッシュ・公開は行わない。

## 動作と判断

既存の「選ぶ」グループ内に、四角形選択と同じ色選択を並べる。常設の新しいツールボタンは増やさない。クリックした現在フレーム／現在レイヤーの画素色を、そのcel全体から選ぶ。離れた同色領域も対象で、隣接した領域だけを選ぶ方式ではない。

色はパレット番号ではなく正規化したRGBA値で比較する。大文字小文字、`#RRGGBB` と `#RRGGBBff` の差を吸収し、同じ色の重複パレット項目も選ぶ。編集画素の-1は透明、0は不透明なpalette[0]として区別する。現在レイヤーが透明なら、下のレイヤーが見えていても透明の選択対象になる。空レイヤーでは全セルを選ぶ。

選択時にUint8Array maskを作成する。後で画素やパレットの色が変わっても、選択メンバーは再計算しない。実際に選ばれたセルだけを専用canvasに表示する。描画・保存データにはこの表示を入れない。不透明な選択には変形用の外接枠とハンドルも表示するが、枠内の穴は選択しない。

左／右ボタンの方式は独立して保存する。従来の設定は四角形選択として読み込む。右クリック・長押し・Shift+Enterによる既存の割り当て方法、仮想カーソルを使える。タッチは指を離した時に選択し、二本目の指やpointercancelは未成立のタップを取り消す。選択ツールの二本指操作では作品をUndoしない。

不透明な選択は既存の移動・回転・拡縮・コピー・カット・貼付経路を使用する。変形中の方式変更と通常の同色クリックを拒否し、暗黙の確定や破棄をしない。透明だけの選択もmaskとして保持するが、コピー／カットは何も変更しない。コピーの透明穴は貼付先を消さない。ペン・消しゴム・塗りつぶし・形状等は既存mask制約を使用する。

## 透明選択とカメラ

透明セルを選んでカメラを開始すると、現在レイヤーのそのセルだけを撮影色で置換する。不透明セル、maskの穴、他のフレーム／レイヤーは保持する。mask全体の外接W×Hに一つの中央crop映像を生成し、個別の穴に同じ映像を繰り返さない。撮影色は既存パレットに減色し、新色を追加しない。

カメラのプレビューは保存対象から独立している。取消は元画素を保持し、撮影はUndo一回で戻せる。現在のライフサイクルと色数制約は `draw-camera-handoff-update-20261007.md` に記載。旧 `draw-inline-camera-update-20261007.md` は `/tmp/pixieed-draw-inline-camera-retired-20261007/docs/` に退避済み。
