## IMPLEMENTED：修正

- サイズ設定：pointerdown中の同期が同じボタン文字を再生成し、PCの実クリックを失わせていた。同じ文字のDOM更新を避けた。隔離ブラウザーで旧版は開かず、修正版は開く対照試験を実施。1pxから3pxへ変更した実ストロークの画素増加も確認。
- 選択の数値入力：非表示の設定欄内に残っていた既存detailsをPC左レーンへ移し、通常表示へ戻る際には元の場所へ復帰。実入力で選択幅8→5、コピーの貼り付け位置変更、取消時のRGBA復帰を確認。
- GIF：保存ボタンが非表示の旧ツールバー内に残っていた。既存ボタンをセル表ヘッダーの再生操作の隣へ移動。処理は既存のGIFエンコーダーを使用し、原本表示中は無効とPNGの案内を表示する。
- 原本・再生中：マス目は原本表示中、オニオンは原本表示中・1コマ・再生中に無効化し、理由を表示。表示できないガイドをONと表示しない。内部の表示設定は保持し、再生停止・編集可能な作品への復帰で戻す。
- 色調パネル：閉じるボタンがヘッダーに隠れないよう、既存のヘッダー・下部操作欄の高さを使って位置と最大高さを制限。
- 最小PC高さ：コマ欄の操作とカードが切れていた。コマ欄内のスクロールを有効にし、先頭・中間・末尾のカードを実クリック可能にした。
- 選択3方式のアイコンを区別。Undo/Redoは既存の下部5枠内に維持した。

## SEO変更と根拠

既存 `/draw/` のtitle、description、OG/Twitter、H1、導入、使い方、保存・GIFのFAQを静的HTMLで更新。JS起動後も同じtitle・H1・導入を保持する。ドット絵・ピクセルアート（Pixel Art）を描き、コマを複製して動かす手順、オニオンと再生、PNG/GIF保存を自然な文章で説明した。これは、読み手の言葉・見出し・説明的なリンクを使う [Google SEOスターターガイド](https://developers.google.com/search/docs/fundamentals/seo-starter-guide) と、内容を正確に表すtitleを勧める [タイトルリンクの資料](https://developers.google.com/search/docs/appearance/title-link) に基づく。

canonicalは `https://pixieed.jp/draw/` を維持。sitemapに同URLは1件あり、robots.txtも描画ページを禁止していないため、URLやサイトマップの追加は不要と判断した。[Googleのcanonical資料](https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls) に沿って、作業状態のqueryごとに別の検索ページを作らない。

カメラ・音楽・動画作成への内部リンクを本文に置いた。PNGは現行の下部［出力］、アニメーションGIFはセル表の［GIFを書き出す］という実装に合わせ、集中画面から出力ページへ必ず移動するとは説明しない。PCはダウンロード、対応端末は共有シートを使う。GIFの半透明非対応とPNGの使い分け、端末内の編集データ保存とファイル保存の違いも説明した。描画ツール自体にMP4等の未実装機能を追加したようには案内しない。

隠し文、キーワードの羅列、類似ページの量産は行っていない。[Googleのスパムポリシー](https://developers.google.com/search/docs/essentials/spam-policies) を確認した。検索順位・検索結果での表示は保証しない。

## 左レーン機能確認表

以下は通常224px（1440×900）と最小62px（1100×620）の両方で、実クリック・入力とキャンバスへの効果を確認した。最小欄は欄内スクロールで操作する。ラベルだけのON確認ではない。

| 操作 | 確認した効果・条件 |
| --- | --- |
| ペン | 指定セルの描画、Undoで元のRGBAへ復帰 |

| 塗りつぶし | 連続する透明領域を塗り、Undo/Redoで完全復帰 |
| スポイト | 異なる色を採取し、次のストロークが採取色になる |
| スプレー | 実際の描画画素が増える |
| 直線 | ドラッグした直線の画素が描かれる |
| 四角形 | 輪郭を描き、内部は透明のまま |
| 塗り四角形 | 内部も塗り、輪郭版とは画素数が異なる |
| 楕円 | 楕円の輪郭を描く |
| 塗り楕円 | 楕円の内部を含めて描く |
| 四角形選択 | 選択境界が実座標に一致する |

| 道具の追加設定：連続 | 連続/非連続の切替で離れた領域への塗りが変わる |
| 色調 | プレビューを適用してRGBが変わり、アルファは保持。Undoは完全復帰 |
| 文字 | 合成文字Aのプレビューと適用結果が一致し、Undoは完全復帰 |
| サイズ | 実クリックで開き、1px→3pxのストロークが太くなる |
| 選択解除 | 描画を変えず選択境界を消す |
| コピー | 元の画素を維持し、貼り付けに使える |

| 取消 | 変形前のRGBAへ完全復帰 |
| 数値 | 選択幅・位置の入力が境界と実プレビューに反映される |
| 拡大 / 縮小 / 全体表示 | キャンバスの実座標・大きさが変わり、初期表示へ戻る |
| マス目 | ガイド用canvasの線画素がON→OFFで0、ON復帰で元の数になる |
| オニオン | 3コマの中間で前の赤系・次の青系ガイドを別座標に描画。先頭/末尾も確認 |

1コマのオニオン・再生は理由付きで無効。再生中はオニオンを表示・操作せず、停止すると前後ガイドと設定が復帰する。原本表示中は描画を変えず、マス目・オニオン・サイズ・再生を無効にする。ロック中はキャンバスを変更せず、コピーは可能、切り取りと数値変更は無効。色調は理由を説明する画面を開けるが適用は無効で、閉じる操作は可能。カメラ・音楽では描画用左レーンを表示せず、描画へ戻ると作品と欄幅を保持する。
