# かんたんドットの切り替え設定集約（2026-10-04）

## 作業範囲

ミラー・グリッドなどの有効／無効を切り替える描画設定を、ひとつの設定パネルへ集約する。対象は現在の /draw/。既存の道具追加・共通アイコン・高速ドラッグ修正の未コミット差分を保持した。保存形式、他ツールの設定UI、カメラは変更対象外。コミット・プッシュ・公開は行っていない。

親チャットが設計、差分レビュー、統合、受入を担当。既存の担当へ、HTML/CSS/アイコン、Draw状態同期/共有アニメーション制御、隔離ブラウザー確認をそれぞれ限定委任した。

## IMPLEMENTED

- 常設の描画道具操作を、ペン／消しゴム、道具選択、設定の3ボタンへ整理した。操作領域は44px。選択式の道具と有効／無効式の設定を別の入口にした。
- 設定パネルは「描き方」の左右対称、「表示補助」のマス目・前後のコマの2グループ。各項目にアイコン、短いラベル、オン／オフの文字を表示し、設定ボタンに有効件数を表示する。
- 範囲選択中の左右対称、1コマ時の前後コマ表示は使えない理由を表示する。左右対称の設定は道具切替で保持する。前後コマ表示がオンの状態から1コマへ戻った場合はオフ操作を可能にする。
- パネルはHTMLのdetails/summaryを使用する。道具・出力などのパネルとの排他開閉、外側クリック、Escapeで閉じる操作を既存の共通UIへ接続した。アニメーション作業パネルをキーボードで開いた場合も設定を閉じる。
- キャンバスのレイアウトは変えず、設定パネルだけを重ねて表示する。画面の空きに合わせて上／下へ開き、下に開く場合は取り消し・出力などの操作列の下へ配置する。低い画面ではパネル内部をスクロールできる。
- Drawの前後コマ表示操作は設定パネルへ一本化。共有アニメーション部品には任意指定の onionControlExternal を追加し、Draw以外は従来の既定動作を維持した。
- 道具変更、フレーム／レイヤー変更、取り消し・やり直し、復元時に、ボタン状態と描画状態を同期する。レイヤーごとの表示・ロックは対象を明確にできる既存レイヤーパネルに残し、再生はアニメーション操作に残した。
- グリッドをオフにした後、復元状態にshowGridがないとオンへ戻る不具合も修正。明示されたプロジェクト設定は復元し、未指定なら端末側の設定を維持する。
- 共通アイコンへ設定と前後コマ表示を追加し、使い方パネルも更新した。
