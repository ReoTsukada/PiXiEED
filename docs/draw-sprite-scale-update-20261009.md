# かんたんドット：スプライト倍率変更（2026-10-09）

## 操作と結果

キャンバス設定内の「キャンバス領域変更」は従来どおり、絵の1pxを保った中央基準の余白追加・切り取りです。別項目の「スプライト倍率変更」でキャンバスと全コマ・全レイヤーの絵を一緒に拡大縮小します。表示ズームの変更とは別です。

- 25 / 50 / 100 / 200 / 300 / 1000%のプリセット、または正の小数倍率を入力できます。プリセットを押しただけでは適用しません。
- 現在と適用後の寸法を表示します。幅と高さに同じ倍率を掛け、各寸法を四捨五入して最小1pxにします。整数画素への丸めで、縦横比には最大1px相当の差が生じます。
- 16×16pxの1000%は160×160pxで、元の各1pxが正確な10×10pxになります。17×15pxの50%は9×8pxです。
- 最近傍補間で元の色番号と透明画素をコピーします。追加色・補間色・ぼかしはありません。縮小や整数倍でない拡大では一部の画素が選ばれなくなるため、事前に注意文を表示します。
- 100%と丸め後の寸法が同じ倍率は無変更で、Undo履歴や保存状態を増やしません。
- 隠れている／ロックされたレイヤーも対象です。コマ・レイヤーID、順序、名称、表示・鍵、パレット、コマ時間（FPS）、メタデータは維持します。
- 未確定の選択変形、描画・仮想入力・色編集、再生、カメラ操作がある間は適用を止め、理由を表示します。変形は✓で確定または×で取消してから変更します。
- 1回のUndo/Redoで全コマ・全レイヤーを戻し／再適用します。選択の不規則な穴、回転中心、対称描画原点、仮想カーソルも画像に追従します。適用後は表示を100%に戻し、Undoでは適用前の表示位置も戻します。

透明度が編集可能な既存アニメーションの範囲を越える原本は、従来どおり表示・保存用の原本として保持します。この操作でパレットや原本の編集制限は変えません。

## 上限と原本保護

`draw-sprite-scale.mjs` は適用前に既存上限の各辺256px・128コマ・8レイヤーを検査します。例えば32×32pxの1000%は320×320pxとなるため拒否します。256pxへの暗黙の縮小はしません。

全コマ×全レイヤー×変更後の面積を合計し、空のコマも含め32Mi画素を上限とします。構築中と確定時のタイルプール2コピー、既存Undo、最大の作業用画素配列・合成キャッシュ・メタデータから、一時メモリの保守的な見積もりを計算し、64MiBを超える処理を拒否します。これはエンジン全体の実測メモリ値ではありません。

適用前・候補の保持量（メタデータ＋重複しないプール）が各4MiBのDraw履歴上限に収まることを確認し、直前の1回を必ずUndoできるようにします。候補を作成しても、容量に収まらなければライブ画像・履歴を変更しません。

既存PXDがあるときは通常の不変PXD writerで表紙とアニメーションを試作し、他の画像・音楽を含む合計保存容量も検証してから適用します。容量確認中に作品が切り替わった場合は候補を破棄します。失敗理由は設定欄へ残し、別の倍率・別の作品では再検査できます。通常のdirty/autosave・PXD直接保存・共通出力の経路を使います。

従来の余白変更の画素処理は変更していません。同処理で不規則な選択マスクを矩形へ広げてしまう問題だけを修正し、選択マスクを画素と同じ整数オフセットで移動・切り取りします。

## 再現手順

1. `/draw/` で16pxの絵を描き、コマとレイヤーを追加します。一部に透明画素を残します。
2. キャンバス設定を開き、「スプライト倍率変更」の1000%を押します。「16×16→160×160」を確認して「倍率を適用」を押します。
3. 全コマ・レイヤーで色や透明が10×10の画素ブロックになっていることを確認します。「戻す」1回で16px、「やり直す」1回で160pxに戻ります。
4. 50%または25%を選び、縮小前の寸法と注意文を確認します。100%は適用できず、履歴も増えません。
5. 32pxの作品で1000%を選び、320pxのプレビューと256px上限の理由、適用不可を確認します。元の画素とRedo履歴は保たれます。
6. 同じ絵で「キャンバス領域変更」の32pxを適用すると、元の1pxを保って中央に余白ができます。倍率変更とは異なる結果です。
7. 保存・再読込と共通出力で、新しい寸法・コマ時間・レイヤー情報が保たれることを確認します。狭い画面では設定パネル内をスクロールします。
