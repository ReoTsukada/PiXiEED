# かんたんドットの道具追加と共通アイコン（2026-10-04）

## 作業契約

利用者向けの結果は、かんたんドットの道具を増やしても常設ボタンが増えない切り替えと、描画操作の意味が伝わる共通アイコン。親チャットが設計・統合・受入を担当し、既存の担当エージェントが純粋描画操作、道具ピッカーと共通アイコン、ブラウザー検証を分担した。

変更範囲は Draw の描画ロジック・専用道具ピッカー、共有SVG部品、Audio/Spot/Hiddenの同じ描画操作への接続、使い方説明と読み込み版、限定テスト。プロジェクト形式、レイヤー/コマの編集権限、保存・書き出し、カメラの操作は維持する。開始時のmainは12fb419で差分なし。今回のコミット・プッシュ・公開は行っていない。

## 実装済み

- 道具の常設表示はペン/消しゴム兼用ボタンと、選択中の道具を示すアイコンだけの一覧ボタン。左右対称・マス目は別の表示切り替えとして維持。
- 一覧は9項目: 塗りつぶし、直線、四角形、四角塗り、楕円、楕円塗り、スプレー、範囲選択/移動、スポイト。「塗る」（塗りつぶし・スプレー）、「図形」（直線・四角・楕円）、「選ぶ」（範囲選択・スポイト）に分け、短い見出しを表示する。各グループは3列で約52px角のアイコンを並べる。道具名と説明はツールチップ、読み上げ、使い方パネルで確認する。常設ボタンは44px角に統一し、文字の横幅を使わない。
- 一覧はnative detailsで開閉する幅196pxの固定配置パネル。キャンバスの配置を変更せず、狭い/低い画面では内部をスクロールする。操作領域は44px以上。必要に応じて操作の行を折り返す。確認した4画面サイズでは44px角の道具と表示切り替えが収まる。開く前に配置を計算し、上下の空きに合わせて表示する。
- 図形はドラッグ中の完成形をプレビューし、指を離すと1回の履歴にする。途中の図形を残さない。楕円の奇数/偶数/1〜2px幅もキャンバス座標に合わせる。
- スプレーは半径2pxの点をドラッグ経路に散らす。形状・スプレーは左右対称と透明色に対応する。
- 範囲移動は囲んだ後、枠内をドラッグする。現在のレイヤー/コマのみを対象にし、重なりは開始時の画素から読み、透明画素も移動先を置き換える。枠全体がキャンバス内に収まるよう移動を止める。移動は1回の履歴。左右対称はこの道具では無効にする。
- 範囲は外側のドラッグで選び直し、EscまたはキャンバスにフォーカスしたEnterで解除。pointercancel・二本指操作・Escによる途中の描画中断は変更を戻す。ロックされたレイヤーと表示専用画像は編集しない。
- R/Oは四角/楕円、Shiftを併用すると塗り、Aはスプレー、Vは範囲移動。既存キーとペン/消しゴム切り替えを維持し、色変更後も図形などの道具を保つ。
- バケツの取っ手・傾き・液滴、スポイトのゴム部分・管・液滴、スプレー缶と霧を共有SVGで描画。ペン、消しゴム、図形、範囲、左右対称、マス目も同じ定義を用いる。
- Draw/Audio/Spot inline/Hidden maskの同じ道具に共通部品を適用する。名前・説明・矢印などアイコン以外の要素は保存し、兼用ボタンのSVGを取り込む前に適用する。
- 使い方パネルを新しい道具と操作に合わせ、HTML→entry→page→共通部品、help→dataの読み込み版を更新した。
