# PiXiEED Globe prototype

状態: 経緯度型の球面セルを使う独立プロトタイプ。公開ホームとは未接続。

## 現行精度スライス（2026-09-20）

このスライスでは、従来の0.75度案を置き換え、標準グリッドを緯度0.5度へ更新した。赤道付近の経度分割も720（約0.5度）とし、1度セルを経度・緯度の両軸で概ね2分割する。セルIDは `globe:v11-meridian-parallel-quarter-degree:<band>:<column>` とする。以下の旧0.75度記述は履歴として残しているが、現在の実装仕様はこの節を優先する。

WebGL2では表示範囲をCanvas上の全画面クアッドで再構成し、解析的な正射投影と事前生成ランドマスクを1 draw callで描画する。Canvas 2Dフォールバックでは従来の可視窓・4度先読み・セルキャッシュ経路を使う。

## 現行スライス（2026-09-21）: セルの整列と丸角

- 経度分割数は緯度帯ごとに、緯度128分割以上の帯では24の倍数へ丸める（従来は8の倍数）。隣接する緯度帯の列境界が揃う帯が増え、レンガ状のずれが約半分になる（列数が変わる帯: 182→82）。緯度80度以内のセルは正方形から±7%以内。セルID・地図データは `v11-meridian-parallel-quarter-degree` へ更新した。
- WebGL2はセル単位のランドマスク（x=列、y=緯度帯）を参照する。経度テクセル参照だと、セルの途中で陸と海が切り替わる半セル表示になっていた。
- セルは丸角で描画する。角が丸くなるのは、その角に接する2辺の両方が水に面している海岸線の凸角だけ。陸セル同士の辺は直線のままで、隣り合うタイルが隙間なく組み合わさる。1セルが約6〜10px未満に縮む遠景では丸角を使わず、従来の塗りつぶしに戻す。
- ホイール・ピンチのズームは、1イベントあたりの変化量、蓄積量、1フレームあたりの変化量に上限を設けた（トラックパッドの慣性スクロールでズームが止まらなくなるのを防ぐ）。

## 決定

地球表面は経度線と緯度線で囲まれた球面四辺形セルで構成する。画面向きの正方形を貼り付けたり、三角形・六角形・レンガ状の行列へ変換したりしない。各セルは固定された地理境界を持ち、投影・描画・クリック判定は同じセル定義を使う。

緯度0.5度を基本帯とし、各帯の経度分割数は地理的な幅が極端に細長くならないよう4〜1024の決定的な倍数へ丸める。最北・最南帯は極セル帯とし、経度線は極で自然に収束する。セルIDは `globe:v11-meridian-parallel-quarter-degree:<band>:<column>` で、画面サイズ、DPR、回転、ズームでは変わらない。

## 描画と操作

セルは1枚のCanvasに描画し、セルごとのHTMLボタン・イベントリスナー・アニメーションオブジェクトは作らない。WebGL2は全画面クアッドのフラグメントシェーダーで緯度・経度、可視半球、0.5度セル境界、ランドマスクを解析する。Canvas上の1つのポインター処理は画面座標を球面座標へ逆変換し、既存のセルIDを求め、現在の論理階層へ集約する。

論理階層は `world → country → region → prefecture → cell`。日本の地域と47都道府県は明示データを使い、他国の詳細行政区分は推定しない。遠景では多数のセルが同じ国・地域の操作対象として扱われ、拡大すると都道府県・投稿セルへ意味が細かくなる。

LODにはヒステリシスを持たせ、子セルの準備中は親の描画を保持する。描画セルの形状と行政区分は別管理する。

コンテンツはセルへ関数を埋め込まず、`activeLayer` と `contentCounts` の共有データとして渡す。初期データは空。将来は投稿・イベント・店舗を同じセル集計へ接続し、水色→緑→黄色→赤の密度表現を使う。

## 背景

`spaceTexture` と `--space-texture` のフックを持つ。生成済みの正距円筒宇宙画像が指定された場合に使い、未指定時はCSSの星空グラデーションへ戻る。背景はテクスチャ位置だけを遅く動かし、地球と異なる速度の視差を作る。画像生成・画像ファイルの追加は今回行わない。

## 軽量化の境界

- Canvas 1枚とイベント処理1セット
- WebGL2の回転中はセルオブジェクト・投影を毎フレーム生成せず、uniform更新だけを行う
- `assets/maps/globe-land-mask-v1.json` はGeoJSONからオフライン生成した決定的なu16/u8 TypedArray相当データで、起動時の大量point-in-polygonをなくす
- GeoJSON判定は生成スクリプトでのみ行い、Canvasフォールバック時だけ未生成データ経路を許容する
- セルオブジェクトは上限付きMapで再利用し、上限超過時は古いエントリから破棄
- 計画生成とCanvas再描画を分離し、ホバー・選択では再描画だけ実行
- Canvasの実ピクセルDPRは2を上限とし、CSS上のサイズは変更しない
- WebGL2の標準描画は1 draw call、Canvasフォールバックは色・透明度の小さなバケットへまとめてパス描画する
- 計画生成・再描画・キャッシュヒット／ミス・backend・drawCalls・frameMsはローカルスナップショットへ出す
- クリックは球面逆投影→セルlookupで解決
- HTML要素はCanvas、選択パネル、少数UIだけ
- 公開runtime、投稿保存、サーバー、Supabase、既存データは変更しない

## 確定事項（2026-09-21）

- 地球儀のグリッドは `globe:v11-meridian-parallel-quarter-degree` を現時点の確定版とする。セルIDはこの版に固定し、投稿データはこのIDで保存する。
- 緯度0.25度の帯。列数は赤道1440を基準に、12/24〜24/24倍の13系列を半分ずつにした候補から正方形に近いものを選ぶ（段差を細かくした版）。
- 表示はボタン状の丸角セル、海は黒。配置や版を変える場合は、投稿の緯度経度から再割り当てする移行手順を先に用意する。

## 天体と日食（2026-09-21）

- `js/globe/astronomy.mjs`: 太陽と月の位置（Meeus 簡易式）、日食の幾何、日食一覧。2017〜2035年の既知の日食で、最大食の時刻は約1分、位置は約1度以内に一致する。
- `js/globe/scope.mjs`: 地上の観測地点から見る望遠鏡ビュー（部分・金環・皆既、コロナ、彩層、太陽フィルター）。
- `js/globe/astro-ui.mjs`: 日時・再生・日食プリセット・望遠鏡の操作パネル。
- 地球の表面には昼夜や日食の影を付けない。星空は地球と同じ回転で動く全天とし、星は少数の明るい星と多数の暗い星で構成する。

## 投稿（2026-09-21・試作）

- 導線: 地球のセルをタップ →「ここに置く」、または画面下の「ドット絵を置く」。絵ファイルを地球にドロップしても始まる。ログイン必須（未ログインならその場でログイン画面）。
- 入力は「絵（PNG/WebP・8〜128px・512色・512KB）」「題名（必須・60字）」「ひとこと（任意）」「場所（ピン1つ）」。足りない項目は送信ボタン横に「あと：題名」と表示する。
- ピン: セルから置くとセル中心の座標を保存する（曖昧なセルIDだけにしない）。Googleマップのリンク／座標貼り付け（`geo-input.mjs`、通信なし＝無料）、現在地（約100mに丸め）、地球のタップでも決められる。短縮リンク（maps.app.goo.gl）と地名検索は解決できない（Places/Geocoding API は有料のため使わない）。
- 表示: 地球上にサムネイルのピン（拡大で大きく、近接は「+n」にまとめる）→ タップで作品カード（等倍整数拡大、座標、Googleマップで開く、前後移動、自分の作品は削除）。「作品一覧」で全作品／自分の作品のグリッド。
- 保存は `post-store.mjs` の小さなインターフェース（`list/add/remove/subscribe`、`auth`）。試作は IndexedDB とデモログインで動く。本番は Supabase 実装に差し替える: `posts` に `latitude/longitude/cell_id/title/caption/image/author_id/status`、作成は認証必須の `create-post` を緯度経度対応にする（現行は旧128格子のセル指定・匿名セッション）。承認（moderate-post）後に公開する現行の流れは維持する。

## 操作はジェスチャーで行う（2026-09-26）

PiXiEED全体の基準（`docs/INTERACTION_PRINCIPLES.md`）に合わせ、地球儀のズーム・回転・リセットのボタンを撤去した。

- 1本指ドラッグで回転。離すと短く慣性で回る（`prefers-reduced-motion` では止まる）。
- 2本指ピンチで拡大・縮小。指の中点の地面を指の下に保ったまま拡大し、同時に2本指で移動もできる。マウスのホイール・トラックパッドのピンチはカーソル位置を中心にする。
- 2本指タップで半分に縮小。1本指タップは従来どおりセル選択と段階的な寄り。
- 長押し（約0.5秒）で、その地点から望遠鏡ビューを開く。投稿画面を開いている間は無効。
- キーボード: 矢印で回転、+/−でズーム、0で初期表示、Enterで中央を選択。
- 初回だけ、操作方法の小さな表示を出す。地球に触れると消え、端末に記録して次から出さない。

### 時刻カプセルと画面上の天体表示（同日・第2版）

「パネルに置く必要のないものは画面に出す」「省けるものは省く」方針で、パネルを小さな時刻カプセルに置き換えた。

- **時刻カプセル（左上）**: 再生ボタンと時刻だけの小さな表示。カプセルを左右にドラッグすると、そのまま時間が動く（はじくと惰性あり）。タップで引き出しが開き、外側をタップすると閉じる。望遠鏡の画面でも出たままにして、観測しながら時間を動かせる。
- **引き出しの中身は4つだけ**: 日時（タップで端末の日時ピッカー）、時間テープ（ドラッグで移動、ピンチで目盛り、日食の点をタップでその日へ）、速さの切り替え（×1・1分/秒・1時間/秒・1日/秒。選ぶと再生も始まる）、日食カード（1枚ずつ表示、左右スワイプで切り替え、タップで再現）。
- **太陽と月は画面に出す**: 可視の文字ラベルは置かず、見えている天体には小さな操作マーカーを出す。画面外や地球の裏にあるときは、画面の端にその方向を指すマーカーを出す。マーカーの操作名は支援技術向けに残す。マーカーをタップするとその方向へ地球が回り、画面に見えている天体をタップすると望遠鏡でその天体を追う。土地セルの選択中はマーカーを隠し、配置操作を妨げない。
- **省いたもの**: 太陽・月の表示サイズ切り替え（常に大きく描き、実寸は望遠鏡で見る）、パネル内の望遠鏡ボタン（長押しと画面上の天体タップで開く）、速さのスライダー、1時間送り・戻しボタン。
- **望遠鏡は全画面＋薄いHUD**: 下半分を覆っていたパネルを廃止。右上に閉じる、上部中央に視野（倍率を変えている間だけ強調）、下端のグラデーションの上に観測地点・食の状態・「日の出 5:32」「日の入り 17:40」（実際の時刻付き。タップでその数分前から再生）・太陽フィルターのスイッチ・注意書きを置く。太陽と月のマーカーは地球の画面と同じ仕組みで、タップすると追尾する。
- **モーション**: 引き出しはカプセルから伸びるように開く。日食や「いま」への移動は時刻と視点の両方を約0.7〜0.9秒かけて移し、空が動いて見える。再生中は再生ボタンに脈打つ輪、画面端のマーカーの矢印は小さく揺れる。望遠鏡はわずかに寄りながら開く。`prefers-reduced-motion` ではすべて止める。

時刻と天体のパネル（左上の時刻チップから開く）は次の形に作り直した。

## 太陽系（2026-09-26）

- **惑星の位置** (`js/globe/planets.mjs`): JPL「Approximate Positions of the Planets」のケプラー要素（Standish, 表1, 1800〜2050年）。光の到達時間を1回補正し、J2000から日付への歳差を入れて、`astronomy.mjs` の太陽・月と同じ座標系にそろえる。太陽の方向は0.01°以内で一致する。明るさ（等級）、欠け方、見かけの大きさ、自転軸の向き、ガリレオ衛星（Meeus 44章の簡易式）も計算する。衝（木星・土星・天王星・海王星）と金星の最大離角（2025-01-10、47.2°）をテストで確認している。
- **地球儀の空**: 惑星を明るさに応じた色付きの点で描く（6.5等より暗い海王星は描かない）。画面に見えている惑星には名前のラベルを出し、タップするとその惑星を望遠鏡で追う。太陽系の計算は `celestialState(date, { planets: true })` のときだけ行い、日食の探索は軽いまま。
- **望遠鏡**: 低倍率では点、拡大すると光の当たり方（金星・水星の満ち欠け）、木星の縞と大赤斑、火星の模様と極冠、土星の輪（輪の傾き・前後関係・本体の影）を描く。木星の近くにガリレオ衛星が見える。最小視野を0.02°（72″）に広げた。惑星ごとに見やすい視野で開く。
- **太陽系ビュー** (`js/globe/orrery.mjs`): 地球儀をいちばん小さくしてからさらにピンチアウト（またはホイール）すると、地球から引いていく動きで太陽系全体に切り替わる。途中は「さらに縮小で太陽系へ」の表示が進む。
  - 距離と軌道は実際の比率、天体の大きさは強調。惑星は太陽の方向から照らされたピクセルアートで、見る角度に応じて欠けて見える。小惑星帯（カークウッドの間隙つき）、土星の輪、近づくと月の公転とガリレオ衛星を描く。
  - 1本指で回す、ピンチで拡大・縮小、タップで天体へ飛ぶ。下の天体チップからも選べる。選ぶと情報カード（太陽・地球からの距離と光での時間、公転周期、1日の長さ、衛星の数、地球からの明るさ）を出し、「空で見る」で地球儀へ戻って望遠鏡をその惑星へ向ける。
  - 地球を選んでさらにピンチインすると地球儀に戻る。右上の閉じる・Escでも戻る。
  - 時刻カプセルはそのまま使え、速さは「1日/秒・1週/秒・1か月/秒・1年/秒」に切り替わる。時間テープは月・年の目盛りまで広がる。

## 実際の夜空と、ドット絵カメラで描く太陽系（2026-09-26・第2版）

- **実際の夜空** (`js/globe/real-sky.mjs`, `assets/sky/real-sky-v1.bin`): ヒッパルコス星表の7.2等までの19,054星と天の川の輪郭（d3-celestial, BSD-3）を155KBにまとめ、ブラウザ内で正距円筒の星空に描く。星の色はB-V色指数から付ける。地球儀の空、望遠鏡の広い視野（視野10°以上。高倍率では細かい星に切り替え）、太陽系ビューの背景で共有する。1.8MBの宇宙パノラマ画像は削除した。
- **太陽と月は実際の大きさ**: 地球儀のまわりに大きく描いていた月（地球のそばの「変な惑星」に見えていた）と太陽の強調をやめ、実際の見かけの大きさで描く。
- **太陽系ビュー** (`js/globe/orrery.mjs`): 手描きのドット絵スプライトをやめ、毎フレーム「ドット」解像度（2 CSS px）で高精細に描いてから、ドット絵カメラ（PiXiEELENS）の256色変換にそのまま通す。
  - 惑星は光の当たった球体として描く。地球は地球儀と同じ陸地データで実際の大陸を描き、恒星時に合わせて正しく自転する。雲と大気の縁もある。木星は縞と大赤斑、土星は輪（傾き・前後関係・本体の影）、火星は模様と極冠。
  - 遠くでは最小の大きさで見え、近づくと実際の大きさで描く。地球から引いていく開始画面では地球儀と同じくらいの地球が見え、そこから太陽系全体へつながる。
  - 月やガリレオ衛星は、惑星の強調された円から離れて見える距離まで近づいたときだけ描く（遠景で地球に重なる謎の天体は出ない）。
  - 惑星を選ぶと、太陽の側（昼側）が見える向きへカメラが回る。
  - 256色は赤・緑8段階、青4段階なので、暗い灰色はオリーブ色のディザーになる。背景の淡い光は青から先に立ち上げ（紺のドット→明るい所は白へ）、変換前に真っ黒だった所は変換後も黒に保つ。

### フルカラーのドット絵（同日・第3版）

- ドット絵の基準は**フルカラー**。太陽系ビューはドット絵カメラ（PiXiEELENS）のフルカラー設定で変換する（色数を減らさず、2 CSS pxのドット格子で写し取る）。256色のときに必要だった青寄せの補正はやめ、天の川と星は本来の色で描く。
- **地球儀と望遠鏡**も同じ2 CSS pxのドットで描く。WebGLを1/2解像度（`DOT_BACKING_DPR = 0.5`）で描画し、CSSの `image-rendering: pixelated` でくっきり拡大する。描画する画素は以前の約1/7になり、軽くなる。

### 星空は美しさ重視（同日・第4版）

- **星空はドット絵にしない。** 地球儀の後ろに専用の高解像度キャンバス（`#skyCanvas`、DPR最大1.5、なめらか表示）を置き、天の川・暗い星・太陽と月・惑星の光はそこに描く。地球儀のキャンバスは地球だけを2pxドットで描き、周りは透明（シェーダーの `uLayer`: 0=両方、1=地球のみ、2=空のみ）。
- **明るい星（4.6等まで、約1,500個）はGPUの点スプライト**で描く。鋭い芯、星の色の淡い光、1.2等より明るい星にはかすかな回折の十字。空の画像は4.6等より暗い星と天の川だけを持つ（`sharedFaintSky`）。
- **太陽系ビュー**は天体・軌道・小惑星帯だけを透明なドット絵レイヤーに描き（ドット絵カメラのフルカラー変換）、背景は同じ高解像度の星空レイヤーを太陽系カメラの向きに合わせて回して使う（`renderer.setSkyOrientation`）。太陽系ビューの間は恒星時を0に固定し、時間を進めても星がずれない。
- **望遠鏡**は空を見る画面なので、高解像度・なめらか表示に戻した。

## 望遠鏡ツールと「空の予定」（2026-09-27）

- **ツール一覧に「望遠鏡」を追加**（`tools/index.html` → `/telescope/` → `globe-prototype.html?embed=1&tool=telescope`）。開くとすぐ全画面の望遠鏡になり、閉じるとツール一覧に戻る。観測地点は端末に保存した場所（なければ東京）。
- **空の予定** (`js/globe/sky-events.mjs`): 望遠鏡の「空の予定」から、観測地点で見える次の流星群と日食を近い順に並べる。
  - 流星群は国際流星機構（IMO）の主な10個。極大日は太陽黄経から毎年計算する。見ごろは極大の前後20時間のうち、空が暗く（太陽高度−12°以下）、放射点が高い時刻。月が出ていれば数を減らして「1時間に約N個」と「よく見える／見える／少しだけ／見えにくい」を出す。
  - 日食は2036年までの一覧から、その場所で太陽が出ている間に最も欠ける時刻と欠ける割合を出す。
  - カードを押すと、その時刻へ時間が進み、流星群は放射点（印付き）へ、日食は太陽フィルター付きで太陽へ望遠鏡が向く。
  - 「現在地にする」で端末の位置を使う（約10kmに丸めて保存し、正確な位置は残さない）。
  - 7日以内に予定があると「空の予定」ボタンに日数が出る。
