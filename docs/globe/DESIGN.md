# PiXiEED Globe prototype

状態: 経緯度型の球面セルを使う独立プロトタイプ。公開ホームとは未接続。

## 現行精度スライス（2026-09-20）

このスライスでは、従来の0.75度案を置き換え、標準グリッドを緯度0.5度へ更新した。赤道付近の経度分割も720（約0.5度）とし、1度セルを経度・緯度の両軸で概ね2分割する。セルIDは `globe:v11-meridian-parallel-quarter-degree:<band>:<column>` とする。以下の旧0.75度記述は履歴として残しているが、現在の実装仕様はこの節を優先する。

WebGL2では表示範囲をCanvas上の全画面クアッドで再構成し、解析的な正射投影と事前生成ランドマスクを1 draw callで描画する。Canvas 2Dフォールバックでは従来の可視窓・4度先読み・セルキャッシュ経路を使う。

## 現行スライス（2026-09-21）: セルの整列と丸角

- 経度分割数は緯度帯ごとに、緯度128分割以上の帯では24の倍数へ丸める（従来は8の倍数）。隣接する緯度帯の列境界が揃う帯が増え、レンガ状のずれが約半分になる（列数が変わる帯: 182→82）。緯度80度以内のセルは正方形から±7%以内。セルID・地図データは `v11-meridian-parallel-quarter-degree` へ更新した。
- WebGL2はセル単位のランドマスク（x=列、y=緯度帯）を参照する。経度テクセル参照だと、セルの途中で陸と海が切り替わる半セル表示になっていた。
- セルは丸角で描画する。角が丸くなるのは、その角に接する2辺の両方が水に面している海岸線の凸角だけ。陸セル同士の辺は直線のままで、隣り合うタイルが隙間なく組み合わさる。1セルが約6〜10px未満に縮む遠景では丸角を使わず、従来の塗りつぶしに戻す。
- ホイール・ピンチのズームは、1イベントあたりの変化量、蓄積量、1フレームあたりの変化量に上限を設けた（トラックパッドの慣性スクロールでズームが止まらなくなるのを防ぐ）。

## 決定

地球表面は経度線と緯度線で囲まれた球面四辺形セルで構成する。画面向きの正方形を貼り付けたり、三角形・六角形・レンガ状の行列へ変換したりしない。各セルは固定された地理境界を持ち、投影・描画・クリック判定は同じセル定義を使う。

緯度0.5度を基本帯とし、各帯の経度分割数は地理的な幅が極端に細長くならないよう4〜1024の決定的な倍数へ丸める。最北・最南帯は極セル帯とし、経度線は極で自然に収束する。セルIDは `globe:v11-meridian-parallel-quarter-degree:<band>:<column>` で、画面サイズ、DPR、回転、ズームでは変わらない。

## 描画と操作

セルは1枚のCanvasに描画し、セルごとのHTMLボタン・イベントリスナー・アニメーションオブジェクトは作らない。WebGL2は全画面クアッドのフラグメントシェーダーで緯度・経度、可視半球、0.5度セル境界、ランドマスクを解析する。Canvas上の1つのポインター処理は画面座標を球面座標へ逆変換し、既存のセルIDを求め、現在の論理階層へ集約する。

論理階層は `world → country → region → prefecture → cell`。日本の地域と47都道府県は明示データを使い、他国の詳細行政区分は推定しない。遠景では多数のセルが同じ国・地域の操作対象として扱われ、拡大すると都道府県・投稿セルへ意味が細かくなる。

LODにはヒステリシスを持たせ、子セルの準備中は親の描画を保持する。描画セルの形状と行政区分は別管理する。

コンテンツはセルへ関数を埋め込まず、`activeLayer` と `contentCounts` の共有データとして渡す。初期データは空。将来は投稿・イベント・店舗を同じセル集計へ接続し、水色→緑→黄色→赤の密度表現を使う。

## 背景

`spaceTexture` と `--space-texture` のフックを持つ。生成済みの正距円筒宇宙画像が指定された場合に使い、未指定時はCSSの星空グラデーションへ戻る。背景はテクスチャ位置だけを遅く動かし、地球と異なる速度の視差を作る。画像生成・画像ファイルの追加は今回行わない。

## 軽量化の境界

- Canvas 1枚とイベント処理1セット
- WebGL2の回転中はセルオブジェクト・投影を毎フレーム生成せず、uniform更新だけを行う
- `assets/maps/globe-land-mask-v1.json` はGeoJSONからオフライン生成した決定的なu16/u8 TypedArray相当データで、起動時の大量point-in-polygonをなくす
- GeoJSON判定は生成スクリプトでのみ行い、Canvasフォールバック時だけ未生成データ経路を許容する
- セルオブジェクトは上限付きMapで再利用し、上限超過時は古いエントリから破棄
- 計画生成とCanvas再描画を分離し、ホバー・選択では再描画だけ実行
- Canvasの実ピクセルDPRは2を上限とし、CSS上のサイズは変更しない
- WebGL2の標準描画は1 draw call、Canvasフォールバックは色・透明度の小さなバケットへまとめてパス描画する
- 計画生成・再描画・キャッシュヒット／ミス・backend・drawCalls・frameMsはローカルスナップショットへ出す
- クリックは球面逆投影→セルlookupで解決
- HTML要素はCanvas、選択パネル、少数UIだけ
- 公開runtime、投稿保存、サーバー、Supabase、既存データは変更しない

## 確定事項（2026-09-21）

- 地球儀のグリッドは `globe:v11-meridian-parallel-quarter-degree` を現時点の確定版とする。セルIDはこの版に固定し、投稿データはこのIDで保存する。
- 緯度0.25度の帯。列数は赤道1440を基準に、12/24〜24/24倍の13系列を半分ずつにした候補から正方形に近いものを選ぶ（段差を細かくした版）。
- 表示はボタン状の丸角セル、海は黒。配置や版を変える場合は、投稿の緯度経度から再割り当てする移行手順を先に用意する。

## 天体と日食（2026-09-21）

- `js/globe/astronomy.mjs`: 太陽と月の位置（Meeus 簡易式）、日食の幾何、日食一覧。2017〜2035年の既知の日食で、最大食の時刻は約1分、位置は約1度以内に一致する。
- `js/globe/scope.mjs`: 地上の観測地点から見る望遠鏡ビュー（部分・金環・皆既、コロナ、彩層、太陽フィルター）。
- `js/globe/astro-ui.mjs`: 日時・再生・日食プリセット・望遠鏡の操作パネル。
- 地球の表面には昼夜や日食の影を付けない。星空は地球と同じ回転で動く全天とし、星は少数の明るい星と多数の暗い星で構成する。

## 投稿（2026-09-21・試作）

- 導線: 地球のセルをタップ →「ここに置く」、または画面下の「ドット絵を置く」。絵ファイルを地球にドロップしても始まる。ログイン必須（未ログインならその場でログイン画面）。
- 入力は「絵（PNG/WebP・8〜128px・512色・512KB）」「題名（必須・60字）」「ひとこと（任意）」「場所（ピン1つ）」。足りない項目は送信ボタン横に「あと：題名」と表示する。
- ピン: セルから置くとセル中心の座標を保存する（曖昧なセルIDだけにしない）。Googleマップのリンク／座標貼り付け（`geo-input.mjs`、通信なし＝無料）、現在地（約100mに丸め）、地球のタップでも決められる。短縮リンク（maps.app.goo.gl）と地名検索は解決できない（Places/Geocoding API は有料のため使わない）。
- 表示: 地球上にサムネイルのピン（拡大で大きく、近接は「+n」にまとめる）→ タップで作品カード（等倍整数拡大、座標、Googleマップで開く、前後移動、自分の作品は削除）。「作品一覧」で全作品／自分の作品のグリッド。
- 保存は `post-store.mjs` の小さなインターフェース（`list/add/remove/subscribe`、`auth`）。試作は IndexedDB とデモログインで動く。本番は Supabase 実装に差し替える: `posts` に `latitude/longitude/cell_id/title/caption/image/author_id/status`、作成は認証必須の `create-post` を緯度経度対応にする（現行は旧128格子のセル指定・匿名セッション）。承認（moderate-post）後に公開する現行の流れは維持する。

## 写真からPixel Studioへの変換

- 撮影専用ピクセルカメラへ進む。完了した処理画像を順に表示し、撮影で表示中の画像を固定する。写真選択や詳細設定は表示しない。
- 地球投稿への連携は端末内の localStorage handoff を維持する。Pixel Studioから地球へ渡すと、投稿画面に画像が入った状態で開く。
- 旧カメラの専用テストハーネスは撤去済み。新しい変換UIとエンジンの動作・仕様は、この記述では保証しない。

## 操作はジェスチャーで行う（2026-09-26）

PiXiEED全体の基準（`docs/INTERACTION_PRINCIPLES.md`）に合わせ、地球儀のズーム・回転・リセットのボタンを撤去した。

- 1本指ドラッグで回転。離すと短く慣性で回る（`prefers-reduced-motion` では止まる）。
- 2本指ピンチで拡大・縮小。指の中点の地面を指の下に保ったまま拡大し、同時に2本指で移動もできる。マウスのホイール・トラックパッドのピンチはカーソル位置を中心にする。
- 2本指タップで半分に縮小。1本指タップは従来どおりセル選択と段階的な寄り。
- 長押し（約0.5秒）で、その地点から望遠鏡ビューを開く。投稿画面を開いている間は無効。
- キーボード: 矢印で回転、+/−でズーム、0で初期表示、Enterで中央を選択。
- 初回だけ、操作方法の小さな表示を出す。地球に触れると消え、端末に記録して次から出さない。

時刻と天体のパネル（左上の時刻チップから開く）は次の形に作り直した。

- 普通のボタンは再生・一時停止だけ。
- 時刻は「時間テープ」を左右にドラッグして動かす。はじくと慣性で進み、ピンチ・縦ホイールで目盛りの幅（分単位〜数週間）を変える。日食の日はテープ上に点で表示する。
- 日時の数字をタップすると端末の日時ピッカーを開く。「いま」は現在時刻から離れたときだけ出る。
- 速さはスライダー、太陽と月の表示は「隠す・実寸・大きく」の切り替え。
- 太陽・月は行をタップするとそちらを向く。日食は横スクロールのカードで選ぶ。
- 望遠鏡の倍率はビュー上のピンチ・ホイールで変え、スライダーは使わない。太陽・月の追尾、日の出・日の入りは行をタップして使う。Escで閉じる。
