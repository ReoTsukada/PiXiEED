# 地球儀と太陽系の操作

地球儀を最小まで縮小し、さらに縮小すると太陽系の全体が見える。太陽系は眺める表示に絞り、拡大操作をすればそのまま地球儀へ戻る。天体の選択・詳細パネルは設けない。右上にも「地球儀へ」を表示し、望遠鏡から入った場合は「望遠鏡へ」とする。通常の投稿ボタンの役割は維持する。

## 往復と視点

- 太陽系は全体図として表示し、戻る演出は400ms。演出を減らす設定では即時切り替える。
- 戻る間のホイール、ピンチ、重複した戻る要求で完了通知を失わない。非表示になった場合も戻る処理は完了する。
- 手動で入った場合は入る直前の地球儀の中心・倍率を復元する。縮小限界から入った場合は最後の見やすい倍率（1以上）と最新の中心を使う。選択した土地は消さない。
- 戻って900msは縮小限界からの再進入を抑える。明示的に開く操作は妨げない。
- 拡大のホイール・ピンチ・キーボードのプラスで元の画面へ戻る。地球や惑星を選ぶ操作は必要ない。細かい入力も累積して判断し、微小な揺れでの切り替えを避ける。
- 望遠鏡からの往復では観測地点と追跡対象を保つ。太陽系から投稿を始める場合は、地球儀への復帰完了後に投稿操作へ進む。

## 操作と表示

太陽系内の縮小は全体図を維持する。ドラッグで視点を回せるが、惑星をタップして移動する機能は持たせない。戻るボタンは44px以上とし、天体や他のラベルに重なるラベルは省く。操作が止まり、時刻が停止している場合は描画を続けない。

## 検証

既存の地球儀単体検証:

```sh
node scripts/globe-harness.mjs
```

ローカルのブラウザー検証（既存のPlaywright実行環境を使用、外部通信を遮断）:

```sh
node scripts/globe-overview-browser-harness.mjs
PIXIEED_GLOBE_ENGINE=webkit node scripts/globe-overview-browser-harness.mjs
```

320×568、390×844、568×320、1024×768の画面と望遠鏡からの往復、公開ギャラリー（`/globe/`）の接続を確認する。拡大だけで戻れること、連続操作中の戻る完了、倍率・観測地点の復元、静止中の描画停止も確認する。2本指入力と非表示通知は検証用ブラウザーの合成イベントを使う。実機タッチ、OSによる背景移行、本番サイトの確認は別途必要。
