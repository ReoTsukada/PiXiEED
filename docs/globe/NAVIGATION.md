# 地球儀と太陽系の操作

地球儀に作品を置く体験の延長として、星空と太陽系を同じ画面で観察できる。公開ギャラリーには「作品・星空・太陽系」の小さな切り替えを置く。「作品」は常に投稿・閲覧の地球儀へ戻る操作とする。既存の望遠鏡ツール入口も維持し、描画処理を共有する。

## 往復と視点

- 太陽系は全体図から天体の近くまで拡大・縮小できる。地球儀への復帰は400msで地球へ近づき、復帰先と同じ地球半径で短くフェードする。演出を減らす設定では即時切り替える。
- 戻る間のホイール、ピンチ、重複した戻る要求で完了通知を失わない。非表示になった場合も戻る処理は完了する。
- 手動で入った場合は入る直前の地球儀の中心・倍率を復元する。縮小限界から入った場合は最後の見やすい倍率（1以上）と最新の中心を使う。選択した土地は消さない。
- 戻って900msは縮小限界からの再進入を抑える。明示的に開く操作は妨げない。
- ホイールとピンチはカーソルや2本指の中心を基準に拡大する。地球に十分に近づいたときだけ元の画面へ戻る。惑星のタップは近くまで移動するショートカットで、詳細パネルは設けない。
- 望遠鏡から太陽系へ移り「星空」へ戻るときは、観測地点・追跡対象・視野角・手動の向き・フィルター状態を保つ。「作品」では観測開始前の地球儀の中心・倍率へ戻る。
- 中央の投稿ボタンは観察中も使える。星空・太陽系と観測用の案内を閉じ、地球儀への復帰が完了してから投稿画面を開く。投稿画面や作品詳細の上に表示切り替えを重ねない。

## 操作と表示

太陽系内でも拡大・縮小とドラッグができる。縮小限界では太陽系全体に戻り、惑星をタップすると近づく。表示切り替えは44px以上の押せる領域を持ち、選択状態を文字・枠・背景色で示す。時刻が停止し、操作も止まった場合は描画を続けない。

## 検証

既存の地球儀単体検証:

```sh
node scripts/globe-harness.mjs
```

ローカルのブラウザー検証（既存のPlaywright実行環境を使用、外部通信を遮断）:

```sh
node scripts/globe-overview-browser-harness.mjs
PIXIEED_GLOBE_ENGINE=webkit node scripts/globe-overview-browser-harness.mjs
```

320×568、390×844、568×320、1024×768の画面と望遠鏡からの往復、公開ギャラリー（`/globe/`）の接続を確認する。カーソル基準のズーム、表示切り替え、途中で操作を変えた場合の復帰、倍率・観測地点の復元、観察中からの投稿、静止中の描画停止を確認する。2本指入力と非表示通知は検証用ブラウザーの合成イベントを使う。実機タッチ、OSによる背景移行、本番サイトの確認は別途必要。

2026-09-29: Chromium / WebKit 各6ケース、計12ケース PASS。投稿画面の呼び出しは検証用の受け口で確認し、認証・外部への実投稿は実行していない。
