# ホームの遊びと制作ツールの関係を明確にする改善案

2026-10-09。ローカル実装のみ。push・本番公開は行っていない。

## 結果

ホームの遊びを大きく残し、キャンバスに「ホームのミニ体験」を表示。すぐ下に「ホームの体験はお試し。保存・編集は、制作ツールで。」と、実際の描画・音楽ツールに進む大きなプレビューカードを配置した。カメラ・地球儀・パズル・出力の既存デモと作品ギャラリーを維持。架空の実績・未実装の作品転送は宣伝していない。

遊びの工夫は、描いたドットが落ちる→「とめる」でその位置を固定→「聴く」で高さと色に対応する音を鳴らす→「動かす」で再び落ちる、という一続きの体験。色パレットは初期状態では閉じ、現在色だけを見せる。

## 操作

- 指では通常は縦スクロール。「描く」を選ぶと描画モードになる。ボタンはキャンバスの外に置き、同じボタンかEscapeで終了できる。
- 音は明示的に「聴く」を押した後のみ。画面外・非表示時は音を休止し、再読み込みではOFFに戻す。
- パレットは矢印/Home/Endで選択、Escapeで閉じる。キャンバスは矢印/Space/Enterで描画できる。
- 20操作まで戻す。消去は確認ダイアログを経由し、消去自体も戻せる。
- 絵、色、停止状態は同じタブのsessionStorageに保存。resize・同じタブで制作ページから戻る・reloadで復元する。Undo履歴と星のスコア・ロゴの物理状態は永続化しない。縮小時に同じマスへ重なるドットや移動速度は完全再現しない。
- 傾き操作はパレット内の専用ボタンから有効化し、停止操作にセンサー権限要求を混ぜない。
- reduced motionではロゴを直ちに表示して落下・星の点滅・走査光・カーソル点滅を抑え、描画と音の機能は使える。グリッドは最大20,000セル、履歴は20件に制限。
