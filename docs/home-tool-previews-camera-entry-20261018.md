# ホームの実画面プレビューとカメラ作業入口

前段は `218c5bc0b76e059ac88fde00570ea910250f0ea0` からのローカル変更。2026-10-19の最終実装は `99d09c01a1b54f1ba928776903b793f59352e8bc` を基点とし、原色モード・関連プレビュー・既存カメラ作業入口を含む。ユーザーがコミット・通常push・pixieed.jp公開を明示承認した。前段の記録は以下に保持し、最終変更と試験を末尾に記録する。

## 変更

- ホーム上部の制作ツール4枚だけを、実際のツール画面キャプチャに置換した。Drawは新規キャンバス、Audioは空の音楽設定、Outputはファイル未選択、Cameraは写真調に生成した山と湖の風景を画像読込してドット変換した画面。アイコン、リンク先、読み込み優先度、既存の下部コンテンツは維持する。
- 4ツールすべてを1440×810のPC横画面で撮影し、画面全体を切り取らずに960×540のPNGと480/960pxのWebPへ縮小した。Cameraの画面は隔離試験で権限を拒否した実際の代替UIに風景例を読み込んだもので、実映像・録音は含まない。画像には新しい先読みを追加しない。
- カメラの明示的な作業入口で、ビデオだけの開始を一度試す。説明URLだけの閲覧では要求しない。説明復帰や通常の表示復帰で許可要求を重ねず、未完了の要求がある間も追加要求をしない。
- 読み込んだ画像・既存作品・撮影結果を保持し、離脱後に届いたストリームは停止する。拒否・機器なし・使用中は既存の再試行と画像読込を利用する。
- 変更したモジュールとその読み込み元だけを `20261018-camera-work-entry-1` に更新し、共有モジュールの同一性を維持する。

## PC横画面への修正

前回はDraw/Audioを800×600、Cameraを800×430、Outputを800×900で撮影し、432〜560px幅の一部分を16:9へ整形していた。カードの枠は横長でも、PCの操作画面全体が伝わらなかった。今回の1440×810撮影では拡大・局所切り取りを行わず、スマホのカードも同じPC画像を使う。表示は16:9と `object-fit: contain` に揃え、画像を欠けさせない。CSSの版は `20261018-pc-tool-previews-1`。

Cameraカードだけは、カメラ未起動の案内画面に写真調に生成した山と湖の風景画像を読み込み、PiXiEELENSでドット変換した例を表示する。既存の [`assets/pixel-studio/samples/README.md`](../assets/pixel-studio/samples/README.md) に記録されたサンプルにこの風景はない。元画像はimage_genで写真調に生成されたもの。Libraryの正規取得手段でローカルへ取得し、実アプリの画像読込・変換へ通している。生成原本の識別情報とハッシュは非公開の検証記録へ保持した。これは生成した写真調画像をアプリで変換した実画面であり、実写撮影ではない。ページには変換後のキャプチャだけを掲載し、元画像はページに加えず先読みもしない。外部の写真素材や個人作品も使わない。

今回変更したのは画像12点、ホームHTML/CSS、関連するホームテストとこの記録。カメラ自動起動のコード・専用入口・元アイコン・リンク・読み込み優先度は前段と同一であることを確認した。納品用プレビューはPC1280×720のホーム画面とし、Libraryの既存PC画像を更新した。

## 2026-10-19：元写真の色を保つモード

通常カメラの色選択へ「元の色」を追加した。128×72などへの画像集約と、8/16/32/64色への減色を分離する。「元の色」では集約直後のRGBAを保持し、標準彩度・コントラスト・暗部補正、0.45pxぼかし、面整理、パレット量子化、ディザ、ジオラマを適用しない。補正操作も「補正なし」と表示して無効にする。他の色ルックと共有パレット固定は従来の処理を維持する。

共有作品の無料32色・パス64色の制限は維持した。原色画像が上限を超える場合、作品・履歴・撮影結果を変更せず既存の回復操作を示す。独立PNGは原色のまま保存できる。互換の単独画面 `pixel-camera.html?standalone=1` でも原色PNGを保存し、出力画面から設定を復元できる。単独画面の原色撮影結果から、空または以前のPXDを他ツールへ送らない。共有用には色数の少ないルックで撮り直す案内を表示する。画面破棄時は保持したPNGリンク参照から後処理し、DOM撤去後の例外を防ぐ。

同じ生成風景を通常UIで読み込み、「元の色」・128×72・ディザなしのPC1440×810全体を撮影して、Camera用3画像だけを更新した。Draw/Audio/Outputの9画像は前段と同一SHA256。CameraのPNGは960×540、WebPは480×270/960×540（lossless、52,834/118,550バイト）。ホームのaltも原色変換へ更新した。生成原本は公開ファイルへ追加せず、余分な取得・先読みはない。
