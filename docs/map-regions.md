# 地図の行政地域と表示セル

地図は2048 × 2048の均一なメルカトル表示セルを、GPUまたはCanvasで描く。横方向は同じ世界を繰り返す。東京付近の表示セルは約16km四方（従来約25km四方）で、日本の海岸線と県境は実ポリゴンから再計算する。表示セルは投稿の保存単位とは別で、同じ行政地域のセルをまとめて選択・ハイライトする。

- 日本は47都道府県。既存の `japan-prefectures.geojson` をセル内64点で調べ、半分以上が陸のセルを採用して生成した `map-prefectures-v1.json` の境界を使う。北海道本島は北海道として扱い、帰属が争われている北方の島々はどちらの国にも割り当てず選択対象から外す。東京都の離島は東京都に含む。小さな県にも実際の境界と重なる表示セルを最低1つ確保する。
- 海外はNatural Earth 10m Admin-1の州・省・県などを使う。海岸線・国境・行政区の所属を同じ境界ポリゴンから生成し、以前の粗い国別マスクで切り取らない。境界付近はセル内16点の半分以上が陸の場合に採用し、最も多い行政区に割り当てる。名称はデータの日本語名、英語名、原名の順。国名と地域名を合わせて表示する。国ごとに行政区の制度・粒度は異なる。
- 行政区データのない土地は国単位にまとめる。海は選択対象にしない。

境界データは[公式Admin-1配布](https://www.naturalearthdata.com/downloads/10m-cultural-vectors/10m-admin-1-states-provinces/)に由来する。[Natural Earthの利用条件](https://www.naturalearthdata.com/about/terms-of-use/)はpublic domain。取り込み元とそのハッシュ・版は生成JSONに記録する。巨大な元GeoJSONは配信せず、簡略化した境界と事前計算した行ごとのセル割り当てを配信する。

## 判定と集計

`map-cells.mjs` が表示セルの所属と、元の緯度経度による所属を別々に解決する。日本の県IDは `prefecture:01` の形式、海外は `admin1:USA:US-CA` など国コードを含むID、国単位は `country:USA`。日本の既存prefectureフィールドも維持する。海外の地域数が255を超えるため、地域マスクはUint16で保持する。海外データの `landAuthority: "admin1-geometries"` は、行政区マスク自体を陸地と国の所属の基準にする指定で、チェックサムにも含める。旧マスクに陸があっても、新しい境界に陸がなければ海として扱う。

細かい座標を持つ投稿も県・州などの地域単位で集計する。イベントに日本の県が明記されている場合はその県を優先する。公開イベントの座標・元の投稿位置・v11の保存cellIdは変更しない。表示ラベルと一覧の範囲を地域単位にする。

イベントと投稿の色は、その地域の全表示セルへ適用する。今後・開催中を初期表示として、過去への切り替えを残す。色の密度は確認済み開催回の件数による。境界テクスチャは初期化時、コンテンツはデータ変更時に更新し、ズームだけでは再取得・再分類・テクスチャ転送を行わない。

## 精度の境界

表示は行政区の概略をドットで表すもので、測量・法的な境界を保証しない。境界は簡略化しており、セルをまたぐ細い区域や小さな行政区は、単一の表示セルとして確保できない場合がある。座標による所属判定と表示セルの所属はその場合も別に保持し、近隣の地域から所属を推測しない。Natural Earthには未収録地域や更新時期の差がある。

投稿の保存形式や公開APIの書き込み契約は変更しない。ローカルでのファイル変更は公開サイトへの配信を意味しない。

## 再生成

`node scripts/generate-map-prefectures.mjs` で国内の割り当てを生成する。海外は生成JSONの `source.url` が指す元GeoJSONをローカルへ取得し、`MAP_ADMIN1_SOURCE=/path/to/ne_10m_admin_1_states_provinces.geojson node scripts/generate-map-admin1.mjs` を実行する。固定したSHA256と一致しない入力は拒否する。

同じISO行政区コードが別の地域に重複する場合は、Natural Earthの行政区IDを使って区別する。同名の分かれた地形は一つの地域にまとめる。生成時の統計と、読み込み時のチェックサム・国の所属確認で取り違えを検出する。

## ローカル回帰確認

`node --test tests/globe/*.test.mjs` で単体テストを実行する。ブラウザの回帰確認は、リポジトリを配信するローカルHTTPサーバーと既存のPlaywright環境を使う。追加のパッケージを自動インストールしない。

```sh
PIXIEED_BROWSER_BASE_URL=http://127.0.0.1:4176 \
PIXIEED_PLAYWRIGHT_MODULE=/path/to/playwright/index.mjs \
node scripts/globe-prefecture-browser-harness.mjs
```

Playwrightが通常のモジュール解決で利用できる場合、`PIXIEED_PLAYWRIGHT_MODULE` は省略できる。`globe-mercator-browser-harness.mjs` は横方向の繰り返し・海上ズーム・境界の所属・GPU/Canvasを、`globe-prefecture-browser-harness.mjs` は県・州単位のイベント・投稿・操作の回帰を確認する。各スクリプトはローカルホストのみ受け付け、外部への書き込みを行わない。スクリーンショットは一時ディレクトリ `/tmp` に保存し、コミットしない。ブラウザテストの合格は実機や本番公開の確認とは別とする。
