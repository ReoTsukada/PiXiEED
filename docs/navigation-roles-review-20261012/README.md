# ページ移動と制作操作の分離

右上の「ページ」に主要機能の直接入口を集め、制作下部は同じ作品の「描く／カメラ／音楽」と作業操作に分けました。新しいフレームワークや依存は導入していません。

[変更前後の画面](comparison.html) · [リリース前の最終検証](../release-review-20261012/README.md)

- 共通メニューから既存の描画・カメラ・音楽・出力・ゲーム・地図・投稿・イベント・店舗・商品・プロフィール・案内へ進めます。現在地はaria-currentと文字・下線で示します。
- 制作中の3モードは既存コントローラーで切り替え、同じ作品を維持します。320pxでも3候補が同じ行に収まり、描画領域は狭くなっていません。
- 画面内の作業操作とページ移動を分離。地図の「見る／投稿する」、店舗の検索、既存の設定・プライバシーパネルは維持します。
- ヘッダー、メニュー、戻る／ホーム、下部ナビは44px以上・角丸10px・アイコン24px。文字付きは可変幅、長文は折り返し／省略表示を使います。フォーカス、Tab、Escape、閉じた後の焦点復帰も確認しました。
- 広告script・属性、Offerwall設定、投稿DB、端末内の保存仕様は変更していません。キャンバス専用操作やパレットは寸法統一の対象外です。

先行の固定ソース検証は139入口×4幅＝556ケースでした。ナビ528通過、宣言されたリダイレクト24件を遷移先のローカルプレイヤーに対応付けて検証、操作のない読書サンプル4件を明示的に対象外としました。説明のないゼロナビを通過扱いにはしていません。

独立QA56件、作品のモード往復後Undo/Redo・出力・復帰・未保存移動キャンセル4件、カメラ24件、復元後保存4件が通過しました。先行検証の生ログ・中間成果物はローカルに保管しています。最新の全テスト・ビルド・ブラウザ結果はリリース検証報告を参照してください。

実機・Safari・物理カメラ／マイク・本番キャッシュ・広告応答・投稿DBは未検証です。広告側の別差分との競合候補はjs/site-header.mjs、css/site-header.css、js/app.jsとHTMLのナビ／cache参照です。別領域の広告パッチをこの変更へ一括取り込んでいません。
