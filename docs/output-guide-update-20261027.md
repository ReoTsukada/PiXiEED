# 変換ページの案内と表示の更新

## 変更範囲

- `/output/` のタイトル、見出し、用途別ナビゲーションを整理します。
- 公開ページのURLコピーと再利用用の入口を追加します。
- 対応形式の説明後に、通常ディスプレイ広告用の表示枠を準備します。
- `/output/work/`、変換エンジン、対応形式、無料保存、サイト全体の広告設定は変更しません。

## 表示枠の制御

`data/output-guide-ad-config.mjs` の `enabled` は `false` のままです。この更新では新規広告を有効にしません。

有効化時は配信アカウント、自動広告、対象地域の同意設定、実機表示を別途確認します。公開案内のHTTPS URLのみを対象にし、作業画面、iframe、プレビュー、クエリ付きURLは対象外にします。表示付近で一度だけ要求し、自動更新や再試行はしません。利用者の操作や無料保存を広告配信の成否に依存させません。

共有するURLは固定の公開URLです。素材、ファイル名、作品IDは取得・送信しません。イベントは既存の同意境界と許可リストを利用します。

## 検証

追加モジュールのテストは `node --test tests/ads/output-guide-ad.test.mjs` で実行できます。分離したDOM検査は、Python PlaywrightとChromiumがある環境で `python scripts/test-output-guide-isolated.py` を実行します。後者は広告プロバイダー等を模擬し、共通CSSを簡略化した検査です。実広告や全体統合の確認を代替しません。

サイト全体は `npm test` と `npm run build` で確認します。実広告のクリックや、表示回数を増やす目的の再読み込みは行いません。
