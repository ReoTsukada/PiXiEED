# 出力画面と Offerwall の公開ゲート

確認日: 2026-10-09。AdSense 管理画面設定はユーザーが保存・再読込を確認済み。コード変更では設定していない。

## 今回の実装

- ファイルの出力先は `/output/work/` に集約する。作品 Blob は同一オリジンの IndexedDB に一時保管し、URL にはランダム ID だけを含める。`/output/` は案内ページにする。
- PXD バックアップは編集ツール画面から端末へ直接ダウンロードする。共通メディア出力ページには遷移させず、PXD の内容を画像プレビューやメディア変換として扱わない。
- `/output/work/` だけが既存の `adsense-auto.js` と Offerwall ポリシーを読み込む。ポリシーは Offerwall を pathname が `/output/work/` と完全一致した場合にだけ許可し、他のページでは抑止する。`/output/` は案内ページのままで、AdSense ローダーを読み込まない。
- 広告 SDK の読み込み失敗・遮断・未配信でも、IndexedDBの読み込み、プレビュー、形式/名前設定、通常保存は独立して動作する。広告完了コールバックやアンロックAPIは追加していない。
- プレビュー、ファイル名設定、通常保存は広告 SDK や広告通信に依存しない。

## AdSense で確認した現状

- 対象サイトは `pixieed.jp`。
- PiXiEED特典は自動最適化のしきい値で有効。報酬は 1 時間。
- 表示文言は「短い広告を見ると、すべての特典が1時間使えます」。メール収集は無効。
- 「1ページビュー後に閉じる」は無効。
- URL 包含は `pixieed.jp/output/work` の1件で、同セクション内のページを対象とする設定をユーザーが保存・再読込済み。他ページは自動対象外。AdSense 側の反映目安は約10分。
- UUID の `?id=` を付けた実際の `/output/work/` 配信一致は未検証。実広告の表示・視聴・クリックは行わず、管理画面のURL条件とpathnameポリシーの範囲で確認する。

## 公開前の必須ゲート

1. 管理画面の `/output/work` 包含1件と他ページ自動対象外はユーザーが保存・再読込を確認済み。UUID query付きURLの実配信一致は未検証として記録し、実広告の表示・視聴・クリックで確認しない。
2. `/output/work/` で報酬広告が表示されても、閉じる・未配信・ネットワーク遮断のどの場合でも「ファイルを保存」が使えることを実機で確認する。広告視聴を通常保存の条件にしない。
3. AdSense の「特典」表示と PiXiEED 側の利用可能機能との対応を確認する。今回のコードには特典アンロック機能がなく、広告視聴後の権利付与を示す文言を足さない。
4. 親の差分レビューと、ローカルstubによるURL範囲・通常保存の確認前に push・公開しない。実広告配信はこの検証では行わない。

将来、任意の追加特典を提供する場合は、通常保存を遮らない専用サブルート（候補: `/output/work/offer/`）に案内と特典導線を置く。実際の AdSense URL マッチ規則と報酬受け渡し契約を確認してから実装する。現在はサブルート、広告完了コールバック、特典アンロックを実装していない。
