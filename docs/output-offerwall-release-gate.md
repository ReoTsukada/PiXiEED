## SEOと互換

旧URL・静的タイトル/本文を維持します。新しい入口は`noindex,follow`で、元々canonicalを持つ6ツールは旧URLへのcanonicalをそのまま使います。変換作業ページは元からcanonicalがなく、それを捏造しません。新入口をサイトマップへ追加して検索ページを量産しません。

新規開始リンクだけを正規化します。未知のquery、作品ID、PXD/版、hash、共有プレイ、引継ぎを持つURLは書き換えません。公開パズル一覧/選択済みプレイ、旧互換カメラ/描画、保存済み出力のURLは従来どおりです。端末内の元作品・下書きを削除しません。

ホーム/SNS・ツール一覧・ページ移動からの普通の新規開始は新入口へ進みます。`social=1`はSNSへ戻るための既存意図として保持できます。作品添付・転送・共有・再開のパラメータを持つ開始は対象外です。iframe内の利用も対象外です。

## 表示条件と限界

- 同期policyをGoogle SDKより先に置きます。許可される初期URLは新7ページ、通常はqueryなし（`workspace=1`と`social=1`の一意値だけ例外）。全7ページとも最初は保留し、既存の作品/保存確認と実ツールの準備が完了した新規状態だけでSDKを1回読み込みます。
- 前回作品の復元、復元失敗、PXD/出力ID、未知query/hash、作業履歴、共有プレイ、編集中、保存時には新たなOfferwall許可を出しません。内部の起動用mode/runtime/workspaceパラメータは、初期判定が新規であった場合だけ区別します。
- カメラ/音声の権限取得や再生は従来の明示操作のままで、Offerwall許可では開始しません。広告の未配信・遮断・失敗でもサイト独自のロックや待機壁を作りません。
- `controlledMessagingFunction`は表示許可/抑止であり、毎回即時表示するAPIではありません。Googleが受理済みのメッセージはサイトから取り消せず、遅延表示を完全には防げません。
- `MessageTypeEnum.OFFERWALL`が不明な異常時は、同意確認等のCMP全体を止めず通常処理を続けます。この場合のOfferwall抑止は保証しません。架空の数値IDは使いません。
- ドメイン全体包含は不可です。ホーム・フィード・検索には別の通常Display SDK経路があり、全ページでの抑止を保証する設計ではありません。共通パスには対象外ページを今後も混在させません。

## Google側で別途確認する設定

本文: 「全機能を無料でご利用いただけます。」
選択ボタン: 「広告を視聴して、制作をはじめる」（実際の編集欄で設定可能な範囲）。協力/支援目的の視聴誘導、通常広告クリック誘導は使いません。

取得済みアクセス、頻度、最適化、しきい値、在庫により表示されない場合があります。アクセス時間は未確認で「1時間」を約束しません。公開メッセージと包含1条件はサイトの配信確認後に設定担当が保存・公開し、設定後の一覧で照合します。SDKは既存publisher `ca-pub-9801602250480253`の標準AdSenseコードです。

通常Auto Adsの制作領域への配置設定はOfferwallの対象設定とは別です。自動配置・オーバーレイが制作を妨げない管理設定も必要です。
