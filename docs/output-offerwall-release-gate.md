最初の3入口は紹介状態で許可します。追加4入口は未確定の間は抑止し、既存の初期化処理で新規・未作業と確認できた場合だけ許可します。変換ツールはファイル選択前だけが対象で、保存済み出力のプレビュー・ファイル名設定・通常保存を対象にしません。

`workspace=1`、`social=1`、`pxd`、`pxdRevision`、`modePxd`、`resumeLocal`、`id`、共有プレイ・引継ぎ等を含むクエリやhash、作業中の履歴状態、iframeは対象外です。ホームの「使う」直行やホーム埋込はこの候補では対象になりません。既存の1クリック開始・共有リンク・状態保持は変更しません。

`/output/`は案内ページ、`/tools/`は一覧です。公開問題の一覧・選択済みプレイは作品閲覧と作業状態の区別が必要なため、作成入口とは分けて対象外にしています。旧描画・旧カメラは移行先の正規入口へ統合します。`/game/`は一覧では「もうすぐ」でnoindexの未提供入口です（URL自体のアクセス制限を意味しません）。`/telescope/`は非掲載の転送で、今回の対象に追加しません。架空の中継ページは作りません。

## 既存タグの由来と接続

旧`output/work/index.html`は`js/adsense-auto.js`を読み込み、既存publisher `ca-pub-9801602250480253` の標準AdSense SDKをheadへ追加していました。現在の候補は、その無条件ローダーを外し、同期のOfferwallポリシーを先に設置した後、`js/tool-offerwall-entry.mjs`が適格な入口状態だけで同じpublisherのSDKを一度読み込みます。ID・タグURL・広告ユニットは捏造していません。

このローダーはGoogleのOfferwall起動APIではありません。Googleが提供するメッセージの許可・抑止だけを制御します。新規でない場合や編集・ファイル選択等を始めた場合は許可を閉じ、後から届いた初期化通知でも再許可しません。他のCMPメッセージを保留しません。広告SDKの失敗・遮断・未配信でも制作・プレイ・プレビュー・形式設定・通常保存は独立して動作します。

Googleへ許可済みのメッセージを後から取り消すAPIは確認できていません。サイト側で新たな許可を止めても、受理済みメッセージの遅延表示を完全には保証できません。毎回の開始クリックで表示する保証もありません。

## 管理画面と公開前の条件

- 親が確認した最新画像は`pixieed.jp/output/work`のセクション包含1件、除外なしでした。編集画面であり、保存・公開済みかは不明です。上記7ページ単位の包含へ更新する案に置き換えます。
- Google側の公開メッセージ、しきい値・頻度・最適化、取得済み利用資格、広告在庫に表示が依存します。URLのクエリ照合規則は未確認で、サイト側の状態判定も必要です。`fc=alwaysshow`のテストクエリも現在は抑止対象です。
- SDKの追加は通常の自動広告にも影響し得ます。ツールの作業領域へ自動広告が入らない管理設定との照合も必要です。コードだけでGoogle側設定が完了したとは扱いません。
- 全制作機能は料金無料で、個別の機能解放や期限付き特典を設けません。文言案は「全機能を無料でご利用いただけます。広告を視聴して、制作やプレイをはじめる」。支援・協力目的の視聴誘導、未確認のアクセス時間・広告非表示効果は約束しません。
- privacy候補と投稿同意の版・ハッシュは、公開時にフロントと関連Functionで揃える必要があります。先に片側だけ公開しません。
- 実広告の要求・視聴・クリックで検証せず、合成SDK・新規の端末内合成作品だけで試験します。基本機能を広告SDK完了や独自の待機壁で止めません。

PXDバックアップは引き続き編集ツールから端末へ直接保存します。素材BlobはURLへ埋め込みません。公開可否・所有権・投稿同意の制御を変更せず、私用作品を広告のために送信しません。

## 通常のDisplay枠

2026-10-24に管理画面の生成コードと一覧を確認したpublisherは`ca-pub-9801602250480253`です。SNS専用のレスポンシブDisplayは`4842737836`、情報ページのPCサイド候補は既存Displayの`8825932060`を使います。既存結果枠`2995020884`は変更しません。管理画面への掲載確認は、実配信・在庫・収益の保証ではありません。

SNSは通常の公開フィードに24投稿以上ある場合だけ、広告と明示した独立カードを最大1枠表示します。Native In-feedとは別形式です。レスポンシブの画面全幅への展開は`data-full-width-responsive="false"`で抑え、カード内へ収めます。自分の投稿・保存・下書き・検索・作成・詳細・読込中・空・エラー・一部取得失敗・全画面は対象外です。再描画や再訪問なしの更新で広告を追加要求しません。UGCへの広告掲載責任は運営にあり、この設定は全作品を審査済みと扱うものではありません。

情報ページの手動サイド枠は300×600で、安全な余白を実測できる広いPCだけに表示します。モバイルやツール編集領域を狭めず、追従表示せず、当該ページの別Auto Ads起動経路と重ねません。空・失敗時は枠を除去します。適格性が不足する場合は表示も要求も行いません。

Googleの`MessageTypeEnum.OFFERWALL`が取得できる場合はOfferwallだけを抑止します。取得できない異常時には、CMP全体を止めたり未確認の数値を捏造したりせず通常のメッセージ処理を続けるため、異常時のOfferwall抑止まで保証するものではありません。
