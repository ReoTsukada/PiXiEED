# ドット絵カメラ：通知ラベルによるプレビュー移動の修正

2026-10-03。対象は `css/pixel-lens-camera.css` と `pixel-camera.html`。設定レール・撮影ボタン・ナビゲーションの構成を維持する。

## 原因と修正

通知ラベルが下部操作パネルの通常フローに入り、パネルの高さを増やしていた。プレビューの配置計算がその高さを使うため、通知を表示するたびにプレビューが移動した。

390×844の同じlook設定で「16色」を選んだ場合、旧CSSではパネルの高さが70→108→70pxとなり、プレビューの中心が上へ19px動いてから戻った。通知以外の設定文脈とキャンバス128×128は同じ。

通知をCSSのabsolute配置で操作パネルから独立させた。短い通知は内容幅の丸い表示、長い通知は画面幅内で折り返す。tone/lookの補助スライダー・パレットが出る場合は、その上へ配置する。通知はpointer-events:noneで操作を遮らない。

狭い画面では通知が一時的にプレビューへ重なる場合がある。通知のためにプレビューを動かしたり、恒常的に画像を小さくしたりしない。操作レール・補助コントロール・ナビゲーションとの重なりを検証する。

CSS、preload、runtimeのキャッシュ版を `20261003-camera-label-stable-1` へ揃えた。画像処理・撮影保存・色統合や追跡処理は変更しない。
