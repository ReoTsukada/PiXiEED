# 光源と面の陰影（2026-09-24）

## 目的と変更範囲

夜景で光源の周囲に残る淡い光暈を抑え、明るい壁・肌などの緩い陰影を基本色へまとめる。操作や設定項目は追加しない。端末内の既存変換処理を調整するもので、新しいAIの学習・依存・外部画像送信は行わない。

元の処理は入力にある照明勾配を階調と部分ディザとして残していた。新処理は物体の出力グリッド上で照明を簡略化してから配色を取得する。物体ID自体は書き換えない。配色の初回固定・タップ更新、24色上限・明度8段階、不透明な画素は維持する。

検出できた小さな光源本体と、顔・細線の保護セルは残す。補正した光源周辺にはディザを追加しない。小さい顔は面の影を基本色へまとめ、原画と検出位置に根拠のある目・鼻・口は別のストロークとして描画する。

## 適用の限界

RGBの写真だけでは、暗い素材と影、白い物体と光源を完全に区別できない。明暗差、周囲の明るさ、色の方向、面の連続性から確度の高い範囲だけを補正する。強い影、遮蔽、写真にもともと焼き付いた広範囲のレンズフレアは残ることがある。存在しない星形のきらめきや、隠れた輪郭を生成する処理ではない。

ユーザーが撮影した夜景の元ファイルは未提供。再現画像によるハロー・影の検証は、当該写真での改善の証明ではない。スマートフォンの実カメラでの画質・速度は未検証。

## 誤補正を抑える条件

夜景の処理はフレームの60%以上が暗いときだけ有効にし、昼の白い服・カップの局所的に暗い縁を光源と誤認する経路を抑える。同じ物体ID内の実在する色サンプルだけを使い、色相を青などへ機械的に寄せない。背景ID 0も面として扱う。黒い素材、強い境界、保護した顔パーツ・細線は対象外。

肌の広い影を基本色に寄せることは今回の意図した変更。物の滑らかな陰影も減るため、立体感は従来より弱くなる。暗い場面で白い反射物と発光体を完全に見分ける意味認識は追加していない。
