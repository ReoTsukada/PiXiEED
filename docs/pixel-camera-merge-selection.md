# カメラの色統合：選択色と候補の見える化

2026-10-04。既存カメラの色統合の開始・選び直し・候補表示を改善した。色抽出エンジンと領域の判定条件を保持し、追跡の一時失敗と確実な終了を分けた。

## 操作と実装範囲

- 映像の長押し位置は移動させず、元画像で中心に近い色を持つ周囲2ドットから、実際に表示されているパレット色を集める。その中で元画像の中心色に最も近い色を対象にする。ディザの位相だけで対象色が変わりにくく、小さな明るい点を多数決で消さない。透明な中心は拒否する。
- 元の色を色チップで示す。統合先は検知した面の中で使われている量が多い順に並べ、対象色以外の最多色を「候補」として示す。候補は自動適用しない。同数なら対象色との知覚色距離、続いて元のパレット番号で決める。
- パレットの元の番号と全色を保持する。「その他」で残りの色も選べる。候補順は開始時に固定し、映像の更新中にボタンが入れ替わらない。
- 統合先を選ぶ前と「元に戻す」の後に選択範囲の輪郭を表示する。「この色だけ」では、その面内の対象表示色に絞った輪郭を示す。輪郭は別のキャンバスに描くため、写真・共有画像の画素には入らない。
- 統合中でも別の場所を長押しして選び直せる。新しい選択が開始できたときだけ交換し、前の統合先を解除する。失敗した選び直しで既存の選択を壊さない。
- 通常タップの色再抽出・対応端末への独立したピント要求、ズーム、撮影、Esc、Mキーは既存の操作を保つ。

## 短い手ブレと追跡失敗

- 小さな移動の探索範囲を最大8ドットへ広げた。128px入力では従来の4から8ドットへ広がる。照合の信頼度、元の色との距離、マスクの面積・重なり条件は維持する。
- 一時的な照合失敗・遮蔽・処理時間超過は最初の2回を `paused` として扱う。パレットと統合先を保持し、最新の未統合映像を表示して再検知する。前の統合画像や輪郭を使い回さない。
- 3回連続の失敗、または一時停止の開始から500msを超えると解除する。最後に検証できた画像を照合基準として保持し、復帰も照合・範囲の検証に通過した場合のみ行う。
- 寸法変更と強い空間的な場面変更は即解除する。弱い平均変化だけで場面変更と判定する旧分岐は、一時停止へ分離した。
- 強さ・統合先を変えても、同じ失敗画像で再試行回数を増やさない。撮影は常に表示中の画素を使う。

## 検証

- 関連ユニットテスト60件が合格（選択10・追跡13・領域10・カメラページ5・フォーカス7・ズーム9・操作説明6）。構文検査と対象差分の空白検査も合格。
- 既存の色統合ブラウザ検証は80項目が合格。1280×800・390×844・320×568・844×390で、統合強度、境界、元に戻す、解除、キーボード操作、カメラ再起動の防止、共有PXDの画素を確認した。入口を現在の長押し操作に更新した。
- 新しい合成カメラのブラウザ検証は8ケースが合格。320×740・390×844・844×390・1280×800で、選択色、元のパレット番号、候補順、輪郭、選択／取り消し時の配置固定、ボタンの到達性を確認した。390×844では統合中の選び直し、短い遮蔽からの復帰、移動後の選択維持、実際に保存したPNGの画素も確認した。
- 遮蔽中の表示を同じフレームの未統合処理画像と全画素で照合した。選択した統合先を保持して復帰し、同じ停止画像に対する設定操作で再試行回数が増えないことを確認した。
- 合成画像の横6ドット移動では、入力画像の13,372／16,384画素が変わった後も選択と統合先を維持した。範囲外の9,277画素は未統合画像と一致した。この低模様画像で検知位置の移動は3ドットであり、厳密な6ドット追従を証明する結果ではない。
- 輪郭は保存したPNGにも共有PXDにも混入しない。選択後・取り消し後のプレビュー寸法と位置は各画面サイズで維持した。
