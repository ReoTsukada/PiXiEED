# カメラ中央操作と表示更新の改善

2026-09-24。ローカル未公開。

後続の全画面化・サイズ選択・アイコンUIは [pixel-camera-fullscreen.md](pixel-camera-fullscreen.md) を参照。以下の出力128px固定・旧操作欄の記述と50件の結果は、その前段の改善記録。

## 変更した操作

カメラページでは共通ナビの中央を専用アクションとして使う。プレビュー中は撮影、撮影済みなら撮り直し、停止中なら再開へ切り替える。別のシャッター・撮り直し・再開ボタンは置かない。上部は前後カメラ切替と一時停止、撮影後の補助欄は保存と地球へ置く操作のみ。

ナビの固定位置・幅・高さ・5項目構造は共通CSSを維持。自動起動、初回カメラ許可、明示停止後の再開、表示中画像を撮影して固定する動作も維持する。

## 処理構成

従来はSlimSAMの処理完了を毎フレーム待っていた。新しい `preview-worker.mjs` が現在のカメラ画像を減色し、`segmentation-worker.mjs` が独立して物体領域を調べる。AIは常に1件だけ処理し、次の空きにその時点の新しい画像を渡す。フレームを溜めない。

AI未準備・再取得中は現在の画像を通常減色して表示する。使えるマスクがある時だけ物体ごとに色を分ける。マスクの参照画像と現在画像を最大128×128のRGBセルで比較し、局所変化、場面切替、寸法変更、期限超過、カメラセッション変更で全マスクを無効にする。マスク年齢は取得時点から数え、上限15秒。マスク利用中も背景AIを継続するので、静止画で期限切れを待つ空白を作らない。

これは動きの予測や高精度な光学フローではない。検査の閾値より小さな変化は検出しきれず、大きく動く場面では通常減色へ戻る。物体分割が全フレームで最新になるという意味ではない。過去のRGB画像を描画し直す方式でもない。

入力上限640px、出力長辺128px、24色、SlimSAMの点数・解像度・閾値を維持。描画用の一時canvasと転送前の余分な複製を除き、表示を最大10fps目標へ変更。SlimSAMでは低IoU候補の不要な安定度計算と、適格候補がないバッチのマスク後処理だけを省略した。新しい依存・モデル・外部サービスは追加していない。

既存 `worker.mjs` は変更せず保管し、撮影ページからは新しいプレビューWorkerを参照する。

## 実ブラウザーの速度比較

同じ公開coffee写真を640×427へ整え、同じ端末・ブラウザーで旧直列Worker2回と新経路140フレームを比較した。新経路は100ms周期を目標に実行した。

| 項目 | 結果 |
| --- | --- |
| 従来の1フレーム待ち | 5,690ms / 5,364ms |
| 新経路の最初のプレビュー | 51ms |
| 新経路の表示更新 | 9.92fps |
| 新経路の1フレーム時間・中央値 | 14ms |
| 新経路の1フレーム時間・95パーセンタイル | 21ms |
| 最初にAIの境界が反映された時点 | 5,682ms |
| 背景AIの最終処理時間 | 5,373ms |
| 新経路の内訳 | AI待ち56枚、マスク有効84枚 |
| 採用マスク候補 | 従来・新経路とも9領域 |
| 最後の静止画像の連続出力差 | 0セル |

背景AIの推論自体が10fpsになったわけではない。取得時点が古いマスクを検査して使うため、動く映像で同じ品質やちらつきゼロを保証する値ではない。

診断モードで親・子WorkerのResourceTimingをまとめ、取得先は `http://127.0.0.1:4173` のみだった。OS全体の通信キャプチャではない。左右の完成画像を目視比較した。一時比較ページ・変更前Workerコピーは検証後に削除する。

実カメラでも、自動起動から最初の完成プレビューまで504ms、起動後14.022秒で133フレーム、直近の描画処理15msを観測した。カメラの許可は取得済み。初回ダウンロードや未許可状態の速度を表す値ではない。

## 操作とレイアウトの確認

- 中央ボタンから撮影して `captured` へ移り、中央が撮り直しに変わることを確認。撮影後のフレーム数263は別の速度比較中も変化せず、表示を固定した。
- 320×568では保存・地球へ置く欄の下端470px、ナビ上端487.219px。中央ボタンは約58.4px角。横・縦のはみ出しなし。
- 740×390、1280×800でも操作欄とナビの重なり・ページのはみ出しなし。一時的なビューポート指定は解除した。
- PNG実ファイルの保存、地球への投稿、スマートフォン実機、長時間の発熱・電池・メモリは今回未検証。
