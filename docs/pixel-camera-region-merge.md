# ドット絵カメラ：長押しによるリアルタイム色統合

2026-10-03。対象は `pixel-camera.html` → `js/pixel-lens/app.mjs` のカメラ。

## 操作

1. ライブ映像の画像内を約550ms長押しする。映像は止めず、その場所のパレット色を選択して面の追跡を開始する。キーボードではプレビューにフォーカスして `M` でも開始できる。
2. パレットから統合先の色を選ぶ。現在のライブ映像と、後から届くフレームに反映する。
3. 「この色だけ」は推定した面の中の選択色だけを置換する。「面を単色」はその面の複数色を統合する。強さで許容する色差・明度差を調整する。
4. 中央のシャッターで編集結果を撮影し、既存のPNG保存・プロジェクト保存経路へ渡す。
5. 「元に戻す」は現在の未統合フレームを表示し、面の追跡は続ける。別の統合先を選び直せる。「解除」「← 色統合」または `Esc` は追跡と統合を取り消し、現在の通常カメラ映像へ戻る。

## コンパクトな設定UI

- ライブ撮影時は「色・ディザ・ドット・比率・色味・ズーム」を画面下に常時表示する。右下の詳細ボタンを削除した。中央の撮影ボタンと既存の5項目ナビゲーションは維持する。
- 設定を選ぶと、同じ高さ64pxの列を「← 設定名・選択肢・その他」に使い回す。その他で追加の選択肢を開き、横スクロールでアクセスする。「基本」で折りたたみ、左の戻る・Esc・画像のタップで通常の6項目へ戻る。
- 色のパレットと色味スライダーだけ上に1段表示する。個別の色を編集している間はパレット段をスライダーへ切り替え、選択肢の段を色相・彩度・明るさ・完了に使う。編集完了後にマイパレットへ保存できる。
- 色統合の統合先パレットも同じ列に置く。まとめ方・強さ・取消・元に戻すは補助パネルに置く。
- プレビューは下部操作列・パレット・色味スライダー・色統合の補助パネルの実寸に合わせて表示サイズと中心位置を調整する。出力比率・切り抜き・保存画素を変更しない。高さの足りない横画面は補助パネル内を縦スクロールする。
- 2026-10-03の読みやすさ調整で、内部選択肢は48px高・内容幅・13px文字へ変更した。詳細と最終検証（単体69、設定UI108、色統合77）は [設定UIの検証記録](pixel-camera-toolbar-polish.md) を参照。以下の以前の検証件数と実写動画の制限は、その時点の記録として保持する。

## 実装の境界

- 減色前の画像はカメラのセンサー原画像ではなく、既存の切り抜き・色調整・縮小を通ったドット解像度の画像。表示した完成フレームと組にして保持する。
- `region-merge.mjs` はOklabの色差・明度差と4近傍の連結性で領域を推定する。彩度のある面では周囲の色差も測り、なだらかな勾配を通しつつ、屋根などの境界を越えにくくする。起点からの色差にも上限を設け、少しずつ違う色を伝って無制限に範囲が広がることを防ぐ。
- 低彩度の面は色相の差に頼らず明度を重視する。星・窓・建物の保持は色差や境界がある場合に限る。同系色で境界が見えない別物体を意味的に識別する機能はない。
- 対象外の画素と元の入力バッファは保持する。統合先は既存パレットの色なので新しい色を作らない。パレットの並びや通常の色編集は変更しない。
- ディザありの「面を単色」は対象領域の模様も指定色へまとめる。
- `live-region-merge.mjs` は最新の未統合フレームを毎回使う。統合済み画像を次の領域判定へ入力しない。近傍のRGBパッチ、前の領域との重なり、面積、輪郭、起点の色差を合わせて穏やかな移動を追う。低模様の面では、画面端で切れていない安定した領域の矩形内にある起点の相対位置も使い、追跡位置の累積ずれを抑える。
- 選択時のパレットを選択UIとして保持し、統合先をRGBで記憶する。各フレームの現在のパレットから近いRGBを選び直すので、並び順の変更を別の色と取り違えない。現在の減色パレットと色数の制限を維持する。
- 起点や統合先の色が大きく変わる、遮蔽物で追跡が困難になる、画面全体が大きく変わる、出力寸法やカメラが変わる、ページが非表示になる場合は解除する。直近の通常フレームを表示し、場面変化・追跡喪失では長押しをやり直す案内を出す。同じような色と形の物体を完全に識別できる保証はない。
- 追跡は最大256×256画素。処理時間が上限を超えた場合も解除する。上限60msは追跡更新の保守的な中断条件であり、カメラ取り込み・通常減色・表示を含む全処理が60ms以内という保証ではない。
- 一度に一つの領域を追う。空・アスファルトなどの意味認識はない。リアルタイム統合した表示を通常の撮影で保存できる。撮影後の静止画へ新しく統合を適用する操作と、統合中のGIF撮影は未実装。
