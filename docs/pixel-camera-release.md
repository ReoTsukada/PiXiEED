# ドット絵カメラ 完成版確認（2026-09-24）

## 利用導線

`/tools/` → `/pixel-camera.html`。ページ到達でカメラを準備し、中央ボタンで撮影、保存リンクでPNGをダウンロードする。カメラ許可はブラウザー側で必要。撮影後はカメラを停止する。画像のアップロード・外部推論は行わない。

- 全画面プレビュー。縦横比と長辺64 / 128 / 256 / 512pxは小さな設定パネルで変更。
- 全体24色上限・明度8段階、固定パレット、部分的ディザ、境界保護、顔パーツの簡略化、残像抑制を保持。
- パレットは開始時に固定し、プレビューのタップまたはEnter/Spaceで取り直す。
- カメラの一時停止・再開・切り替え、権限エラー・推論停止時の案内を用意。
- PNGは撮影時に準備する。元のRGBAを同寸法で格納し、保存は実際のdownloadリンクの既定動作を使う。非同期準備中の撮り直しや離脱は世代番号で破棄する。
- 開発用比較ページ、学習画面、テストメディア、未公開の地球儀への画像受け渡しは製品導線に含めない。

## リリース境界

カメラ本体、推論モデル・ローカル実行環境・ライセンス、ツール入口、ホームと共通5項目ナビを含む。既存HTMLの共通JS/CSS参照は同じ版に更新。共有JS/CSSは必要なナビ部分のみを選別し、既存の日本地図・データ・管理機能・バックエンドを維持する。

事前学習済みのSlimSAMと顔ランドマーク検出を使用。PiXiEED独自学習モデルではない。出所とライセンスは `vendor/object-camera/PROVENANCE.md`、`vendor/face-camera/PROVENANCE.md`、`vendor/pixel-studio/TFJS-LICENSE`、`assets/object-camera/models/slimsam/PROVENANCE.md` に保存。

## 確認結果

- ステージ済みファイルだけを取り出したクリーンコピーで `node --test tests/pixel-studio/*.test.mjs`：239件成功、失敗・スキップなし。
- ローカル参照58件を監査：欠落なし。モデル、ONNX、WASM、weight shardも同梱。
- IABでカメラ自動起動、サイズ変更、撮影、一時停止・再開、切り替え後の復帰、ツール・ホーム・既存地図のナビを確認。
- 320×568 / 844×390 / 1280×800で横はみ出しなし。設定パネルとナビの重なりなし。64×64は正方形、512×288は16:9のまま表示。
- Chromeで実カメラからPNGを保存。保存されたファイルのPNGヘッダーが64×64、512×288と一致することを確認。
- アプリコードの構文確認と差分空白確認は成功。upstreamから同梱するORTファイルの既存空白は原本維持。

## 検証の限界

スマートフォン実機のSafari/Chrome、長時間連続撮影、公開HTTPS環境でのカメラ許可・保存は未検証。IABでは保存リンクの生成・クリックまで確認したがOSへのダウンロード完了は確認できず、実ファイル保存はChromeで検証した。顔の読み取り品質は顔が画面内で占めるピクセル数と撮影条件に依存し、64pxであらゆる顔を正確に再現する保証はしない。今回のカメラ映像はほぼ単色で、前段の写真・動画評価に代わる画質評価ではない。
