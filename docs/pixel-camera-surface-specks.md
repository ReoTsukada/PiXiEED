# 面内の孤立点の抑制

2026-09-25。スクリーンショットで指摘された、平面に浮く濃い1pxを対象とする追加処理。

## 原因と変更

従来の1点サンプリングは、元画像のごく小さな点がセル中心に当たると、その色で出力1マス全体を描く。既存の除去処理は強い明暗差や材質の違いを細部として保護するため、この増幅された点が残る。これは合成した元画像から実際の描画経路で再現済み。提供されたスクリーンショットには元RGBや物体マスクがないため、その撮影場面の原因を確定したものではない。

`surface-specks.mjs` を線の認識後、材質分類・パレット取得より前に挿入した。描画セルの平均RGBは占有範囲を推定するためだけに使い、描く色には周辺の実サンプルを使う。新しい平均色や半透明色は出力しない。

- 同じ物体IDの8近傍内に、互いにRGB差14以内の6点以上の面が必要。
- 元画像のサンプルが4点以上あり、中心の色の推定占有率が25%以下のときに限定。
- 中心とセル平均の差が8未満なら詳細判定を省略。
- 保護された顔パーツ・線とその隣接セル、物体境界、十分な占有範囲のある細部は維持。
- 2pxの線や対向する線の支持を維持。低占有率の孤立点と非直線の小片を対象にする。
- 明度205以上、RGB最大235以上、暗い背景にある明点は光源として維持。
- 前フレームの修正色を再利用せず、変更前の同一フレームを読んで一括補正する。

24色、8階調、既存のディザ判定・影と光の補正、撮影画面UIは変更していない。追加依存・モデル学習・写真送信はない。`removedSurfaceSpeckCells` はこの段階で置換したセル数であり、最終画像の全ノイズの個数ではない。

## 検証

- `node --test tests/pixel-studio/*.test.mjs`: 262件成功。
- 新規単体・描画経路テスト: 孤立点、非直線3セル片、目、2px線、光源、物体境界、実際に面積を持つ細部、連続フレームの残像、入力非破壊。
- ローカルの人物・猫・カップ・風景写真を64/128/256pxで比較。合成した夜景の光源保持と室内の影抑制も比較。

- ブラウザー: 人物64×64で顔1・顔パーツ7セル、認識反映後の同一入力差0%、24色。
- ブラウザー: 街と歩行者の15.467秒動画を128×72で最後まで処理。約9.5FPS、平均描画27.6ms、配色の自動変更0、非不透明フレーム0、console error/warn 0。この動画結果は全動画のちらつきゼロを保証しない。

## 限界

点が元画像でもセルの大半を占める場合や、物体・線として保護されている場合は残す。スクリーンショットに写る全ての点を無条件に消す処理ではない。顔検出前・未検出の微小なパーツと、本物の小さな材質模様は完全には区別できない。提供された実際の撮影入力での同一場面比較、全端末の速度・画質は未検証。
