# 色の領域ごとの3階調化

2026-09-24の3階調導入時点の記録。この段階では公開・モデルの追加学習・依存追加は行っていない。後続の細部保護・残像修正と顔モデル追加は [pixel-camera-details.md](pixel-camera-details.md) を参照。

## 表現

- カメラの標準出力を長辺128pxから256pxへ変更し、1セルが大きすぎる見た目を軽減。64/128/256/512pxの選択、縦横比、中央撮影、小さな非モーダル設定欄は維持した。通常画面に説明文や数値は追加していない。
- 同じ物体ID内を色相・彩度・暗さの系統と局所的なつながりで分ける。離れた肌と木材、肌と暖色の服が同じパレットを使うのを避ける。小さな断片だけを近傍の同じ色系統へまとめる。
- 各局所色領域の基本色・影色・ハイライトを最大3色に限定する。輝度の15/50/85パーセンタイル付近にある実画素色を採用する。明暗差が小さい領域は1色になる。
- 全体の色数は最大48。領域が多い場合は面積の大きい領域の3階調を優先し、残りの領域は近い1色へ割り当てる。すべての微小領域に固有色を予約するものではない。
- 各セルは同じ所有IDの実画素のうちセル中心に近い色を読む。背景と前景のRGBを平均しない。階調選択用の明るさだけを同じ局所領域内の近傍で整える。強い明暗差は混ぜない。最終出力はパレットの単色、alpha=255、補間なし。
- 同一位置・同一物体のRGB変化が6以下なら、実画素色の参照を保持してパレット候補の入れ替わりを抑える。保持した参照に対する累積変化が閾値を超えれば更新する。影・基本色・ハイライトの切替にも別の明るさ参照を使う。場面切替・サイズ変更・撮り直しでは履歴を捨てる。
- PNGは選択した寸法で保存する。地球の既存投稿入力が長辺128pxまでのため、そちらへ渡すコピーのみ最近傍で縮小する。保存用画像と撮影済みの元データは変更しない。

## 実装範囲

SlimSAMと既存の物体マスク追跡は維持し、その後段の色整理を変更した。肌・髪・服という意味ラベルを新しく学習した処理ではない。「最大3色」は検出した局所色領域の制約で、顔全体・髪全体が必ず3色になる保証ではない。色の似た別物体が接し、物体マスクでも分離されなければ、同じ領域になる可能性がある。元写真の光学的な混色は完全に除けない。

微小ノイズの抑制は動体追跡ではない。動き、照明の大変化、マスク更新や領域の分裂に伴うちらつきは残り得る。保存するパレット色は現在または保持中の過去の実画素色に由来する。

## 検証

`node --test --test-reporter=dot tests/pixel-studio/*.test.mjs tests/globe/tool-shell.test.mjs` は83件成功。変更した6つのJavaScriptモジュールの構文チェックも成功。局所色領域の3色上限、混色しない物体境界、細線、離れた同系色、局所IDの継続、微小ノイズ、累積変化の解放、色数上限、入力不変性、既存カメラのWorker契約を検証する。

端末内の公開写真4枚で、AIマスクを与えない減色単独の比較を行った。入力は長辺512px、出力は256px。従来の24色変換と目視比較し、人物の肌と服の色が混ざる問題、細かな断片が主要領域の陰影色を消費する問題を修正した。一時的な比較ページは検証後に削除した。

| 写真 | 新描画の初回処理 | 同一フレーム再入力の変化セル | RGB各チャンネル±2ノイズの変化セル率 |
| --- | ---: | ---: | ---: |
| astronaut.png | 46ms | 0 | 0.0763% |
| chelsea.png | 24ms | 0 | 0.1074% |
| coffee.png | 20ms | 0 | 0.1165% |
| rocket.jpg | 23ms | 0 | 0.0183% |

変化率は出力RGBの完全一致で数えた。入力ノイズは各チャンネルに決定的な-2〜2の値を加算し、0〜255へ制限した1回の比較。撮影動画や人間による画質評価の統計ではない。4枚とも全体48色以下、局所色領域3色以下。

実カメラを505×962のブラウザー画面で確認。3階調処理、256px、全画面、文字を出さない通常UI、ページの横・縦はみ出しなし、コンソールエラーなし。許可済みカメラの初回プレビュー454ms。28.106秒に271フレームを表示し約9.64fps、観測した描画処理は8〜11ms。これは減色プレビューの速度であり、背景AIの推論速度ではない。観測時のAI状態はprocessing。

スマートフォン実機、長時間の発熱、全撮影条件での物体境界精度、今回の地球への投稿完了は未検証。撮影・PNG保存の幾何の先行検証は[pixel-camera-fullscreen.md](pixel-camera-fullscreen.md)に記録。

## 主なファイル

- `js/pixel-studio/material-groups.mjs`: 色系統、保持用の実色参照、階調選択用の明るさ。
- `js/pixel-studio/material-regions.mjs`: 連結成分と局所IDの対応。
- `js/pixel-studio/three-tone-palette.mjs`: 基本色・影・ハイライトと全体の色予算。
- `js/pixel-studio/object-renderer.mjs`: 物体所有を維持したセル描画と時間安定化。
- `js/pixel-studio/preview-worker.mjs`: カメラで3階調・48色を選択。
- `js/pixel-studio/app.mjs` / `pixel-camera.html`: 256px初期値、表示、投稿用コピー。
