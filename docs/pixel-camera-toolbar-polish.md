# ドット絵カメラ：設定UIの読みやすさ調整

2026-10-03。対象は `pixel-camera.html`、`css/pixel-lens-camera.css`、`js/pixel-lens/app.mjs` の表示部分。

## 問題と変更

常時表示する6項目と、同じ列を設定の選択肢に使い回す構成は維持した。旧UIは選択肢を文字数によらず44px幅に固定し、文字も小さくしていたため、押せる領域があっても内容を読みにくかった。

| 部分 | 今回の調整 |
| --- | --- |
| 操作列 | 高さ52pxから64pxへ。常時表示は6項目の1列 |
| 通常の項目 | アイコン18px、現在値12px、項目名11px。長い現在値は短縮し、完全な意味はtitle/aria-labelで保持 |
| 内部の選択肢 | 高さ48px、最小幅64px、文字13px。内容に応じた幅で全文を表示し、横スクロールで選ぶ |
| 戻る・その他・完了 | 他の選択肢と区別した形と余白。48px以上の操作高さ |
| パレット | 操作領域48px、通常パレットの色の円は30px。色統合は内側の角丸色面。色と操作領域を分離して余白を確保 |
| 選択状態 | 明るい選択面、境界線、フォーカス枠。暗い背景の陰影と控えめな奥行きを整理 |
| 色統合パネル | 見出し14px、説明12px、操作13px・48px以上。「解除」「元に戻す」は1行に収まる幅を確保 |
| 補助スライダー・通知 | 通知をスライダー／パレットの上へ移動し、重なりを解消 |

## プレビューと責任の分離

下部UIの実際の高さと、表示中の補助パレット／スライダーの高さを表示用の予約領域へ反映する。画像のサイズだけでなく中心位置も調整し、下部の操作列と補助パネルに重ならないようにした。

表示サイズと位置だけの変更であり、保存する解像度・切り抜き・比率を変更しない。HTMLが項目の意味、CSSが余白・配色・選択状態・応答するレイアウト、JavaScriptが設定状態とプレビューの寸法計算を担当する。

高さの足りない横画面では、色統合の補助パネル内を縦スクロールして各操作へアクセスする。撮影画面全体へ操作を広げない。通知は一時的にプレビュー上へ表示される。

撮影関数、5項目ナビゲーションのHTML、領域判定・ライブ追跡モジュールのSHA-256は今回の変更開始時と一致した。既存のリアルタイム色統合を維持する。撮影後の画像への新しい色統合操作は、この調整では追加していない。
