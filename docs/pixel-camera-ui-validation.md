# カメラ画面の共通ナビ・操作UI

2026-09-23のUI検証記録。ローカル未公開。

2026-09-24に中央ナビを撮影・撮り直し・再開へ変更した。最新の操作と速度は [中央操作・表示更新の検証](pixel-camera-navigation-performance.md) を参照。以下は変更前の記録。

## 変更

カメラ独自のstickyナビを撤去し、既存サイトの `pixieed-design-system.css` と `app-tabs` を利用する。共有CSSそのものは変更しない。ホーム・地図・投稿・ツール・マイページの5項目とツールの選択表示を維持する。

撮影結果を地球へ引き渡す操作は、ナビから撮影後の操作欄へ移動。「撮り直す」「保存する」「地球に置く」を表示する。ナビ中央は同じサイトの `/?post=1` へ移動する投稿リンクで、撮影結果の引き渡しとは区別する。

白い共通背景、暗い撮影プレビュー、既存アクセントに合わせたボタンへ変更。撮影を丸いシャッターボタンで強調し、補助操作にはアイコンと名前を付ける。画像の外に処理状態・エラーを表示し、幅・高さ・色数などの内部情報は操作画面から除く。待機中・処理中・撮影済みを状態表示で区別する。狭い画面で文字を省いた「ツールへ戻る」も読み上げ名を保つ。

HTMLは意味と操作、CSSは配置・レスポンシブ、JavaScriptは撮影状態とフォーカスを担当する。AIモデル・変換アルゴリズム・保存形式はこの変更の対象外。

## ブラウザー確認

同じ546×962の表示領域で、既存ツールページと変更後カメラのナビはどちらも x=25、y=881.21875、幅496、高さ69.5859375px。下端余白11.2pxで一致した。ページ長に依存せず画面下へ固定される。

| 画面寸法 | 確認した状態 | 結果 |
| --- | --- | --- |
| 320×568 | 待機・プレビュー・撮影済み | 横/縦のはみ出しなし、操作とナビの重なりなし |
| 740×390 | 撮影済み・横向き | プレビューと操作を左右に分け、重なりなし |
| 1280×800 | 撮影済み | 中央配置、ナビ固定、はみ出しなし |

320px幅でシャッター64×64px、補助ボタン64×64px、保存・地球へ置くボタン92×72px。撮影後は保存ボタンへフォーカスした。検証中のカメラ画像は投稿・外部送信していない。一時的な画面サイズ変更は終了時に解除する。

## 判断に使った資料

- [Apple HIG: Buttons](https://developer.apple.com/design/human-interface-guidelines/buttons): 操作の優先順位と押しやすい領域。
- [Apple HIG: Layout](https://developer.apple.com/design/human-interface-guidelines/layout): セーフエリアと操作部が内容を覆わない配置。
- 既存サイトの実行中ナビと共有CSSを直接比較。資料は判断の参考であり、ネイティブアプリ適合や実機検証の代替ではない。

## 自動起動への変更

同日の追加依頼により、ページ到達時にカメラを自動起動する。初回の「カメラを開く」ボタンと案内画面は表示しない。ブラウザーのカメラ許可は引き続き必要で、明示停止・起動失敗後にだけ「再開する」を表示する。

非表示での初回読込は可視化まで起動を保留。撮影プレビュー中の離脱では停止し、復帰時に再開する。明示停止・許可拒否では自動再試行しない。撮影済みの状態は一時的な非表示とBFCache離脱では保持する。未解決のカメラ許可要求は後続起動で待機し、二重に要求しない。

許可済みのブラウザーでは、再読み込みだけで640×480のカメラ入力から128×96の処理済みプレビューへ到達し、開始ボタンがDOMにないことを確認した。明示停止でのみ「再開する」が表示され、その操作で起動へ戻ることも確認した。構文確認と既存ナビ・フレーム制御7件が成功。初回許可ダイアログの端末別挙動、許可拒否とBFCacheの全組み合わせは未検証。
