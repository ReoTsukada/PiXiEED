# 端末内の独自ドット絵AIへ進むための次段階

現在のMagenta試作は画風を転写する既存モデルで、PiXiEED独自のドット絵AIではない。今回確認できたのは、モデルを自己ホストし、写真を外部へ送らず端末内で推論できる構成までである。

## 学習させる内容
写真の色を再配置するだけでなく、顔・髪・服・背景などを、低解像度でも読める形へ省略する。目標は「写真と同じ全画素」ではなく、被写体を保った、意図のある輪郭と色面である。

## 必要な学習素材
使用・学習・配布の権利を明確にした写真と、その写真を元に人が描いたドット絵の対応例を集める。Web上のドット絵を無断で収集して独自学習済みとはしない。人物、動物、食べ物、屋内、街並み、自然、暗所・逆光などで評価用の画像を学習用から分離する。

## 小さく検証する順序
1. まず静止画に限定し、ひとつの画風・解像度で、写真と手描きの対応例を使って小型モデルを試す。
2. 対応する作品を見ながら、輪郭・目鼻・大きな色面が通常変換より改善するかを比較する。写真との差が小さいという数値だけを合格基準にしない。
3. 合格したモデルを量子化し、ブラウザーで使う推論形式へ変換する。今回の端末内アダプターと同様に写真の外部送信を不要にする。
4. 低メモリのスマートフォンを含めて時間・最大メモリ・発熱を確認する。重い端末では撮影後の静止画方式を保つ。
5. ライブ化はフレーム間の形・色の一貫性を別に学習/評価してから行う。

今回、独自モデルの学習、データセットの収集、GPU訓練、モデルの再配布可能性の審査は行っていない。新しい学習環境と学習素材の範囲を決めることが、次の実作業になる。
