# PiXiEED の無料利用方針

PiXiEEDの制作・撮影・録音・再生・ゲーム機能はすべて無料で使える。広告視聴、日次受取、時間制限はなく、開始した作業を広告で中断しない。広告を視聴して機能制限を解除する仕組みは使わない。

共通ヘッダーと `/pass/` からパス残量、広告視聴、日次無料分の操作を外す。`/pass/` は無料利用の案内と戻る導線だけを表示する。通常のAdSense広告はホーム・一覧・完了結果の既存枠で継続する。Google管理画面のOfferwallメッセージは非公開にする必要があるが、AdSenseアカウント設定は未変更。自動広告は低頻度またはオフにし、制作・撮影・録音・再生・ゲーム操作中を除外する。

以下は旧パス実装の設計・検証履歴であり、現行仕様ではない。数値とPASS記録は当時の実装に対する履歴として保持する。

## 旧パス実装の履歴

成立した特典1回で全サイト共通の利用期限に1時間を付与する。有効中は登録された拡張を繰り返し使える。新しいツールは `js/pixieed-pass.mjs` の `PERKS` に登録し、`hasPerk()` で新規拡張操作を判定する。

## 時間の扱い

- Offerwall報酬は推定完了時に残り時間へ1時間を加算し、上限2時間で切り詰める。期限切れなら現在時刻から1時間。有効中でも加算できる。Offerwallの完了はGoogleの公式通知でなく、実装上の推定判定である。
- 毎日ローカル日付ごとに、初回の受取操作で広告なしの1時間を受け取れる。無料受領の権利は過去日に受け取らなかった分を貯めず、ローカル日付の切替時に1回分だけ更新する。
- 無料分はその日の明示的な受取操作で1回だけ付与する。広告が表示されない場合や広告操作が中断した場合に、無料分を自動付与しない。無料分を受け取っていない日は、広告を試さず無料分だけ受け取れる。
- Offerwallの選択や終了だけでは公式に確認された報酬完了を意味しない。実装上、広告完了と推定した場合に限り残り時間へ1時間を加算し、合計2時間を上限とする。
- 無料受領日を旧 `pixieed:pass:no-ad-day:v1` に保存して従来の受取済み状態を保ち、受領時刻を `pixieed:pass:no-ad-at:v1` にも保存する。どちらかの記録が今日の受取を示す場合は無料分を再付与しない。
- 時間はページを閉じている間も進む。利用時間だけを計測して停止する方式ではない。
- 期限は同じブラウザー・同じサイトの端末内保存。別ページ・別タブに共有する。別端末・別ブラウザーへのアカウント同期は未実装。
- 新しい広告報酬で増やす残り時間は最大2時間。既存の旧期限が2時間を超える場合も期限を短縮せず、ゲージは満表示にする。
- 推定広告報酬および無料分の付与は、Web Locks 対応環境で同じロックにより直列化する。無料分はロック内で受取可能か再確認してから、期限の延長と受取記録を行う。非対応環境では同時の付与の完全な原子性は保証しない。

## 共通ヘッダー

公開ページは `css/site-header.css` と `js/site-header.mjs` を読み込む。通常ページ、各全画面ツール、単独の望遠鏡で共通の拡張ボタンを表示する。地球儀をiframeで表示する場合は親ページのヘッダーだけを使う。即時リダイレクトは移動先、管理画面・内部テスト画面は対象外。

ボタンは「残り」と正確な時間を主役にし、1時間単位の横バーで補足する。有効中にも残り時間を確認できる。未使用の無料分がある日は「無料1時間／タップで受取」として直接受け取れる。右上ボタンは広告を強制開始せず、Offerwallがすでに表示されている場合だけ案内から広告を選択できる。Offerwallが未表示なら特典案内へすぐ移動し、5秒待ちのfallbackは設けない。

### ゲージと操作の演出

- 12セル1本で、最大2時間分の残時間を表す。1セルは10分相当で端数を切り上げる。旧期限が2時間を超える場合は期限を維持し、ゲージを満表示にする。
- 操作範囲は高さ44px。狭い音楽画面でも幅96pxに収める。表示する残り時間は正確な時間と読み上げラベルで伝える。
- 新たに有効状態へ変わる付与演出は1,100ms、burstは最大1,300ms。すでに有効な状態への追加は850msの小さなpulse。初回表示、通常の時間経過、同じ期限での画面復帰には付与演出を出さない。
- 12セルを再利用し、変わった値だけ更新する。画面が非表示の間はヘッダーの定期更新を停止し、復帰時に実際の残時間を確認する。ヘッダーを置かないiframeでは更新を予約しない。
- 共通ボタンとナビゲーションは押したときの短い反応、ツールカードは小さな浮き上がりとピクセルの装飾を使う。パスボタンの既存演出を実現するための新しい描画ループや追加ライブラリーは導入しない。
- OSの動きを減らす設定とサイトの表示設定では、新規の動く演出を停止する。カメラや制作キャンバス自体のジェスチャーは各ツールが扱う。

## 期限切れの挙動

期限到達時とバックグラウンドからの復帰時に期限を再確認する。自動で広告を出したり画面遷移したりしない。生成・書き出し・録画は開始ボタンを押した時点で判定し、有効中に開始した処理は途中で期限が切れても最後まで完了・保存できる。次の新規操作は再判定する。

- 音楽：作成済みの32/64/128列や追加音色はデータとして維持する。期限後は拡張を使う曲の編集・試聴・通常再生・新規音声/動画出力を停止し、「続けるには時間を追加してください」と追加ボタンを表示する。有効中に開始した音声/動画生成は、期限後も完了・保存できる。時間を追加すると同じ内容で再開できる。自作のPNG/PXDバックアップは利用できる。自動縮小や音色置換はしない。
- カメラ：開始時に拡張が有効だった録画は、期限後も開始時の10秒・最大20fpsで続ける。次の録画は通常の5秒・最大10fpsに戻る。完成したGIFは期限後も保存できる。
- かんたんドット：有効中に開始した詳しいタイムラプスは期限後も生成・保存を続ける。次の詳細版では時間追加を案内する。描画履歴は残り、無料の3秒版とPNGは引き続き保存できる。
- パズル：表示中のヒントやゲームの進行を取り消さない。無料分を使用済みの場合、次の追加ヒントでパスを再確認する。

## 無料の基本機能と拡張

| ツール | 無料で使える機能 | 共通パスで広がる機能 |
| --- | --- | --- |
| カメラ | 写真、ドットを整数拡大したPNG、5秒・最大10fpsのGIF | 10秒・最大20fpsのGIF |
| かんたんドット | 描画、PNG、短い3秒の描画過程GIF、自作のPXD保存 | 工程を多く収める8秒の描画過程GIF |
| ドットで音楽 | 作曲、PNG、WAV、対応ブラウザーで絵と音の1ループ動画 | 新規32/64/128列、追加音色 |
| ジグソー | 遊ぶ、進行保存、各ゲームで最初のヒント | 2回目以降のヒント |
| 間違い探し・かくれもの | 遊ぶ、各問題で最初のヒント | 2回目以降のヒント |

大きい画像出力は広告を必要としない。PNGは原則長辺2048px、GIF/動画は長辺1024pxを目標に整数拡大する。動画のフレーム数と端末の能力に合わせて上限を調整する。画像の原寸復元用情報とPXDの元の画素・音楽は保持する。

GIF圧縮は専用Workerで行い、画面操作から分離する。録画開始時にフレーム数と寸法を見積もり、GIF用RGBAフレームを合計800万画素（約32MB）以内に整数間引きする。Workerへの複製を含めてもフレーム保持量は約64MB以内で、元の撮影画素は移譲・破壊しない。GIFの整数拡大は従来どおり長辺1024pxを目標にし、全フレームの出力画素数で倍率を抑える。Workerを使えない場合は、さらに拡大後の処理画素を合計800万画素以内に抑えて端末を固めない。取消や画面離脱時は処理を終了する。

無料ヒントの使用は問題ごとにタブ内へ保存する。ヒントが表示された場合だけ使用済みとし、広告のキャンセルや問題切替では消費しない。ヒントは手動操作を補助する表示のみで、答えの自動確定、ピース移動、点数変更は行わない。

長時間の音付き動画、望遠鏡動画、飾りなどは今回の登録特典に含めない。通常の制作・保存・投稿を広告で制限しない。簡易ゲームの公開導線は引き続き非表示。
