# 2026-10-17 release review

The home page now opens with four practical tool cards: Draw, Camera, Audio and Output. Draw, Camera and Audio open the corresponding mode of the retained editor directly. The original tool icons and existing Maou example are retained; the playful mini experience follows the tools. The Draw guide remains available in the main Draw page, while the old guide and camera routes retain compatible canonical/noindex entry behavior.

The world map separates page navigation from map controls. Its usable height includes the actual shared header, generated Draw entry and directory row. Event period, region, query, list position and map position survive reload/back navigation; returning from details restores focus. Short landscape layouts keep the controls reachable, although the event list has a small scrollable body (about 46 px at 844×390); full descriptions remain available in the event directory and detail pages.

Loading changes normalize shared module URLs, use WebP previews with existing PNG fallbacks, defer Output WAV/video dependencies until their actions, and reserve the initial Books/Output/game workspace geometry. Output cancellation retains the previous downloadable result. No speculative, hover or idle tool preload was added. Manual map `.gz` companions were rejected after checking the deployed server's existing HTTP gzip; the original map JSON and ordinary fetch/cache behavior remain in use. Historical manual-gzip measurements are not evidence for this release's performance.

The sitemap and generated event output were refreshed from the existing source catalog: **136 unique sitemap URLs and 114 event pages**. Seven stale generated event pages were removed and four eligible pages generated. Merged legacy entry URLs are absent from the sitemap. No artificial `lastmod` dates or event source-data edits were added.

Validation on 2026-10-17 UTC used a fresh compiled Pages build, isolated Chromium profiles, Maou/synthetic fixtures and blocked external/non-GET/HEAD traffic and device access:

- Entry integration: 12 cases; editor save/reload/fault handling: 9 checks; map navigation: 4 viewports (320×568, 390×844, 844×390, 1280×800); game first use: 6 cases.
- Home cards: 6 viewport/text-size combinations, including 200% root text; actual tool destinations and expand/restore behavior verified.
- Output: two viewports with fresh image/WAV/video and audio-only first-use paths; four deterministic first-WAV delay/cancel/retry cases passed, including old-result preservation and a real 96,044-byte WAV result. These are functional checks, not a before/after performance comparison.
- Local SEO HTTP fixtures: 213 checks passed. The Pages build generated 800 files, including 114 event pages and six existing generated puzzle share pages.
- Relevant unit suites: **1,488 / 1,495 passed**. Seven reproduced preexisting failures remain: two bottom-navigation/logo expectations, one puzzle-card expectation, and four event record/edition/page-count expectations. The release is not represented as an entirely green test suite. A date-dependent event-state fixture was made deterministic; the production date calculation was unchanged.

Physical devices, Safari/WebKit (executable unavailable), real camera/microphone permissions, ads, authentication, public submissions and field performance were not exercised. Local browser timings and prior experimental snapshots do not establish production performance or analytics changes. Raw captures, private machine paths, Library receipts and synthetic project backups remain local and are excluded from Git and the public build. No capacity-cleanup deletion was performed.

## Analytics integrity follow-up

Retained Draw/Audio editors now relay `file_export`, and the embedded camera relays `camera_capture`, through the registered parent frame. Both sides preserve the existing consent and host checks; the parent validates origin, frame source, channel, exact anonymous schema and sequence before using the ordinary analytics sender. Replayed notifications are ignored, while separate save actions remain separate events. Measurement failures do not interrupt a completed file handoff. No filenames, artwork IDs, content or persistent tracking identifiers were added.

Camera, Books and the event hub have explicit page classifications. Output download events use the allowed `downloaded` method and the actual item's format, including mixed-format batches. The globe analytics bridge checks the exact canonical iframe revision. Dependent module references and generator/cache expectations were updated together to avoid mixing old and new analytics boundaries. The sitemap remains unchanged at 136 URLs.

Validation of this follow-up: **106/106 targeted tests passed; 1,517/1,524 broader tests passed**, with the same seven preexisting failures described above. Fresh entry, save, map and game browser regressions passed. Six collector checks used entirely local responses or aborted requests: real PNG downloads, a valid synthetic WAV through the real save helper, repeated actions versus replay, play/stop, a synthetic camera notification and consent denial. No real GA or advertising request was sent. The WAV helper check does not establish the full music-export UI, and physical camera capture and actual GA receipt remain unverified.

The measurement destination, consent defaults, anonymization and global page-view/history behavior were preserved. These changes cannot repair historical missing data and do not identify the cause of the October 10 spike of 1,712 **Views**. After publication, record the release time and compare subsequent event names, page classifications, methods and formats after normal report processing; distinguish `download_started`/`share_handoff` from completed file persistence. GA administration settings require separate read-only confirmation before assessing the history-pageview hypothesis.
