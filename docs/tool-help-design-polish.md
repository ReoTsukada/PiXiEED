# 使い方パネルの使いやすさ・見た目の改善

## 実装

前の説明本文・対象10ガイドを維持し、読む順番と見つけやすさを整えました。各画面は共通メニューの「使い方・操作」、ツール一覧は「ツールの使い方」から開きます。

- 上部に「はじめ方」「操作」「保存・ヒント」の入口を固定。押すと説明パネルの中だけを移動し、選んだ項目にフォーカスします。URLや保存データは変更しません。
- ツールのアイコンと短い用途説明を冒頭に配置。はじめ方は01〜03の番号付きカード、操作は名称と説明を揃えた一覧、保存・ヒントは色を抑えた注意欄に分けました。
- ツール一覧の説明は「つくる・見る」「遊ぶ」「問題を作る」に分類。既存のツールアイコンと進む印を付け、広い画面は2列、スマートフォンは1列にします。
- 温かい白を背景に、濃い文字色・緑の操作色・控えめなコーラルの区切りを統一。細かなピクセル模様と余白で関連する情報をまとめます。
- 本文は15px以上、項目への入口・補足は14px以上、操作領域は44px以上。狭い画面でも文字を省略せず折り返し、閉じる操作を見える位置に保ちます。
- native dialogのEscape・外側クリック・入口へのフォーカス復帰、Tabの折り返し、キーボードでの本文スクロールを維持。パネルからツールへキー入力が伝わらないよう、dialog内のイベントで止めます。

画面内への収まり・読みやすさ・操作領域・関連する内容の並べ方には[AppleのUI設計ガイド](https://developer.apple.com/design/tips/)を参照しています。WebのCSS pxをAppleのptと同一として認定するものではありません。

## 変更境界

`js/tool-help.mjs` と `css/tool-help.css` が表示・操作の改善を担当します。`js/tool-help-bootstrap.mjs` と対象11HTMLは、説明パネルの読み込みrevだけを `20261003-tool-help-3` に更新しました。ガイド本文、各ツールの実装、既存ヘッダーのrevは維持しています。新たな依存や保存・投稿機能は追加していません。

カメラ・音楽・描画・ゲームの既存修正を保護しています。作業開始時に撮影処理・ヘッダー・ガイド本文等とHTMLの本文の20ファイルを記録し、HTMLの説明パネルrevを除いてSHA-256一致を確認しました。
