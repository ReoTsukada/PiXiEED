# ツール・ゲームの使い方パネル

以下は初期導入時の記録です。後続のUI改善と最新の受入結果は[使い方パネルの改善](tool-help-design-polish.md)を参照してください。

## 実装範囲

現在のツール一覧から開くツール・ゲームと、問題を作る画面に共通の使い方パネルを追加しました。各画面では共通メニューから「使い方・操作」を開きます。ツール一覧では「ツールの使い方」から説明を選べます。

| ガイド | 入口 |
| --- | --- |
| かんたんドット | `/draw/` |
| ドット絵カメラ | `/pixel-camera.html` |
| 望遠鏡 | `/telescope/` → `/globe-prototype.html?embed=1&tool=telescope` |
| ドットで音楽 | `/audio/` |
| かんたんジグソー | `/jigsaw/` |
| ドット絵間違い探し | `/play/spot-difference/` |
| ドット絵もの探し | `/play/hidden-object/` |
| 間違い探しを作る | `/spot-difference/` |
| もの探しを作る | `/hidden-object/` |
| かんたんゲーム | `/game/`（直接開いた場合のみ。ツール一覧の準備中カードは維持） |

共通パネルは最初の手順、タップ・マウス・キーボード操作、保存や利用上のメモを表示します。既存の画面内説明も維持しています。使い方一覧に未公開のGameは載せません。旧版や内部専用ページへの追加は今回の対象外です。

## 表示・操作

- 必要なときだけ開くnative dialog。開いたら元のメニューを閉じ、閉じるボタンにフォーカスします。
- 「閉じる」、Esc、パネル外側のクリックで閉じ、入口へフォーカスを戻します。メニュー経由ではハンバーガーボタンに戻します。
- 本文のみスクロールし、タイトル・閉じる操作は上部に維持します。縦長スマートフォン、狭幅、短い横画面に対応します。
- パネルを開いている間は背後の編集・ゲーム画面にキーボード入力を渡しません。Tabはパネル内で一周し、本文にも移動できます。本文のキーボードスクロール、Esc、ボタンのEnter操作はブラウザーの標準動作を使います。
- ガイドの選択や閲覧では保存データを書き換えません。各ツールの保存・撮影・ゲーム処理は既存実装を使います。

読みやすさ、操作領域、スクロールを含む画面内への収まりの判断には [Apple UI Design Dos and Don’ts](https://developer.apple.com/design/tips/) を参照しました。CSS上の44px操作領域を目標とし、Apple認定や実機適合を主張するものではありません。

## ファイルの責任

- `js/tool-help-data.mjs`: DOMを持たない日本語ガイドと既知ルートの解決。
- `js/tool-help.mjs`: パネルと入口、フォーカス・開閉、安全なtextContentでの本文生成。
- `css/tool-help.css`: 専用クラスでの表示とレスポンシブ調整。
- `js/tool-help-bootstrap.mjs`: 既存ヘッダーが作るメニューへ接続。各対象HTMLの追加はscript一行。

共通ヘッダーのモジュール・既存revは変更していません。`app.js`が既に読み込むヘッダーとは別のヘッダーURLを導入せず、メニューの二重登録を避けます。地球儀の通常画面や実際のiframeでは望遠鏡のガイドを誤表示しません。

## 説明内容の根拠

各ページのHTML、`js/creation/*-page.mjs`、`js/creation/pixfind-play.mjs`、`js/pixel-lens/app.mjs`・`zoom.mjs`・`focus.mjs`、`js/globe/prototype.mjs`・`scope.mjs`・`astro-ui.mjs`を確認しています。カメラはダブルタップで色統合、長押しで端末へのピント要求という現在の操作を説明します。問題作成の公開機能は準備中として案内します。
