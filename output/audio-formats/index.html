AIFF・AU・WAVに変換・保存

音声を指定のPCM形式で渡したい方へ。拡張子だけでなく、ビット深度と読み込み条件まで確認できます。

ファイルを選んで変換

登録不要・無料。ファイルは端末内で処理します。保存形式は読み込み後に選びます。

AIFF / AIF / AIFCAU / SNDWAV16・24・32bit音声が変換できないとき

WAV・AIFF・AUへ保存する手順

  1. 音声ファイルを選ぶ

    読み込みに成功すると、サンプルレート・チャンネル数・秒数が表示されます。変換前に確認してください。

  2. 保存形式とビット深度を選ぶ

    WAV・AIFF・AUを選びます。16bitが標準です。必要なときだけ「音声の詳細設定」を開いて24bitまたは32bitを選びます。

  3. 変換して保存する

    完了後に「保存する」を押します。音声ファイルはサーバーへアップロードせず、端末内で処理します。

音声は120秒以内、モノラル/ステレオ、8〜48kHzが対象です。1ファイル64MBまでですが、ブラウザーが読み込む一部の音声は4MBまでです。読み込み時に再サンプリングされる場合があり、元ファイルのタグ・ジャケット画像などは保持しません。

WAVからAIFFへ・AIFFからWAVへ変換

AIFFファイルを作るには、WAVなどの読み込める音声を選び、保存形式に「AIFF」を指定します。出力は非圧縮の整数PCMで、16・24・32bitから選べます。保存ファイルの拡張子は.aiffです。

.aif / .aiffの入力と、対応するPCM方式のAIFCを読み込めます。AIFCという拡張子だけで判断せず、内部が対応するPCMである必要があります。圧縮AIFCをすべて読み込む機能や、AIFCとして書き出す機能ではありません。

変換例：WAV → AIFF、AIFF → WAV、AIF → WAV、対応するPCM AIFC → WAV

WAVからAUへ・AU / SNDからWAVへ変換

AU（Sun / NeXT）形式で音声を保存したい場合は、保存形式に「AU」を指定します。書き出すのは整数PCMのAUで、16・24・32bitを選べます。AUのμ-lawやA-lawを読み込めても、その方式で書き出す機能はありません。

入力はAUヘッダーを持つ.au / .sndで、対応するPCM・浮動小数点・μ-law・A-lawを扱います。.sndという名前でも別の内部形式なら読み込めません。読み込み後に表示されたサンプルレートや秒数を確認してください。

変換例：WAV → AU、AIFF → AU、AU → WAV、AU → AIFF、AU形式のSND → WAV

AIFF・AU・読み込めるMP3からWAVへ変換

保存形式「WAV」は整数PCMで書き出します。対応するAIFFやAUをWAVへ変換できます。MP3などはブラウザーが読み込める場合に利用できますが、同じ拡張子の全ファイルに対応する保証はありません。

MP3などの非可逆圧縮からWAVに変えても、圧縮時に失われた情報は復元されません。出力サイズが大きくなる場合もあります。音声の長さや形式を確認してから利用してください。

変換例：AIFF → WAV、AU → WAV、MP3 → WAV（ブラウザーが読み込める場合）

16bit・24bit・32bit PCMの選び方と制限

16bit PCM
変換画面の標準設定です。受け取り側からビット深度の指定がない場合の初期値です。
24bit / 32bit PCM
受け取り側の仕様に合わせる場合に選択します。この出力の32bitは整数PCMであり、32bit floatではありません。

数値を増やしても元の音声情報は増えません。ブラウザー経由の読み込みでは再サンプリングや精度の変化が起こる場合があるため、元ファイルのビット単位での一致は保証しません。この画面にサンプルレートを自由に指定して変更する機能はありません。

WAV・AIFF・AUのPCM書き出しでは、読み込み後のサンプル数とサンプルレートを使用し、録音方式の圧縮出力のような前後の無音を追加しません。元のファイルを残し、納品先の仕様と変換結果を照合してください。

音声が変換できないとき

AUを選べますが、μ-lawで保存できますか？

できません。μ-law・A-lawは読み込み側の対応で、AUの保存は整数PCMです。必要な符号化方式と拡張子を別々に確認してください。

音声の容量が小さくても読み込めません

120秒、チャンネル数、8〜48kHzの範囲、内部のコーデックを確認してください。容量と長さは別の制限です。ブラウザーによる読み込みにも対応差があります。

M4A・Ogg・WebMはどう違いますか？

対応するブラウザーで作成できるときだけ表示される圧縮出力です。作成には音声の長さ程度の時間がかかり、先頭40ms・末尾80msの無音を加えます。処理中に画面を離れると中止します。このガイドで扱うPCM出力とは動作が異なります。

詳しい作業画面との違いは？

AIFF・AUやPCMビット深度の選択には「ファイルを選んで変換」から簡易変換を利用してください。画像やGIFに音楽を重ねる場合は、詳細ワークスペースを使います。

形式を決めたら、変換へ

元のファイルは変更しません。必要な形式が一覧にあることを確認し、変換後のファイルを保存してください。
