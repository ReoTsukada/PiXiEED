専門的な画像形式に変換・保存

PNGやJPEGからマイナーな画像形式を作りたい方へ。保存できる中身と、読み込める範囲を分けて確認できます。

ファイルを選んで変換

登録不要・無料。ファイルは端末内で処理します。保存形式は読み込み後に選びます。

TGAQOITIFF / TIFBMPICOPBM・PGM・PPM・PAMSVG変換できないとき

画像を別の拡張子に変換する手順

  1. 元の画像を選ぶ

    PNG・JPEGなどの画像を読み込みます。プレビューと大きさを確認してください。

  2. 保存形式を選ぶ

    TGA・QOI・TIFF・ICOなどを選びます。サイズ・背景色・画質は必要なときだけ詳細設定で調整します。

  3. 変換して保存する

    変換後に表示される「保存する」からダウンロードします。拡張子だけを変更するのではなく、選択した形式のデータを作ります。

各辺4096px・画像全体で800万画素・1ファイル64MBまで。画像は8bit/チャンネルの画素として処理し、ICCプロファイル・EXIF・レイヤーは保持しません。画像の形式を変えても、元の解像度や失われた情報は復元されません。

PNGからTGAへ・TGAからPNGへ変換

TGA（Targa）形式で渡したい画像は、PNGなどを読み込み、保存形式に「TGA」を選びます。PiXiEEDは非圧縮32bit RGBAのTGAを書き出すため、元画像の透過を含めて保存できます。

TGAを開いて確認したい場合は、TGAを読み込んでPNGに保存できます。読み込みはRGB24/32bit・グレー8bitの非圧縮またはRLE方式に対応します。カラーマップ方式など、すべてのTGAを読めるわけではありません。

変換例：PNG → TGA、JPEG → TGA、TGA → PNG、TGA → WebP（WebP出力対応時）

PNGからQOIへ・QOIからPNGへ変換

QOIファイル（.qoi）を作るには、画像を読み込んで保存形式「QOI」を選びます。書き出しはRGBAの可逆圧縮で、読み込んだ画像の画素と透過を保存します。元ファイルのメタデータまでそのまま戻す機能ではありません。

QOIを一般的な画像として扱いたい場合は、QOIを読み込んでPNGへ変換します。JPEGに変える場合は透過部分が背景色になり、非可逆圧縮になります。QOIに変換しても、必ずPNGより小さくなるとは限りません。

変換例：PNG → QOI、QOI → PNG、QOI → JPEG

PNGからTIFFへ・TIFFからPNG / JPEGへ変換

PNG・JPEGからTIFFを作る場合は「TIFF」を選びます。保存するTIFFは1ページ・8bit RGBA・非圧縮です。CMYK・16bit・レイヤー付きのTIFFや、複数ページをまとめたTIFFを作成する機能ではありません。

.tif / .tiffの読み込みは8bit RGB・グレー画像の非圧縮、PackBits、LZWに対応し、先頭ページを使用します。CMYK・16bit・JPEG/Deflate圧縮などは対象外です。印刷用の色管理や全ページを保つ用途では、元データを保持してください。

変換例：PNG → TIFF、JPEG → TIFF、TIFF → PNG、TIF → JPEG

PNG / JPEGからBMPへ・BMPからPNGへ変換

BMP出力は非圧縮24bit RGBです。透過部分は詳細設定で選んだ背景色に合成します。透過を保持したい場合はPNG・TGA・QOIなど、透過対応の保存形式を選んでください。

BMPの読み込みは非圧縮24/32bitに対応します。32bit BMPも、この読み込み処理では不透明な画像として扱います。パレット画像やRLE圧縮BMPは対象外です。BMPにするだけで写真の情報量や画質が増えるわけではありません。

変換例：PNG → BMP、JPEG → BMP、BMP → PNG

PNGからICOを作成・ICOからPNGを取り出す

アイコン用のICOファイルを作るには画像を選び、保存形式を「ICO」にします。単一サイズ・最大256×256pxのICOを出力します。256pxを超える場合は縦横比を保って縮小するため、正方形が必要なら元画像を正方形に整えてください。

ICOを読み込む場合は、内部の最大サイズの画像を使います。PNG内包または24/32bit非圧縮の画像に対応します。16px・32px・48pxなど複数サイズを一つにまとめるICO作成や、CURカーソルの出力には対応していません。

変換例：PNG → ICO、JPEG → ICO、ICO → PNG

PNGからPBM・PGM・PPM・PAMへ変換（Netpbm / PNM）

Netpbm系の形式が必要な場合は、色と透過の要否に合わせて保存形式を選びます。PNMはPBM・PGM・PPMをまとめて扱う呼び名として使われます。保存では必要な形式を具体的に選びます。

PBM：白黒2色・P4
白黒の画像を作ります。詳細設定の「白黒のしきい値」で境界を調整できます。グレーの階調は残りません。
PGM：グレースケール・P5
色をグレーの階調に変換します。透過部分は背景色に合成されます。
PPM：RGBカラー・P6
RGBのカラー画像を保存します。透過は保持しません。
PAM：RGBA・P7
RGBとアルファを保存します。透過が必要な場合の選択肢です。

読み込みはPBM・PGM・PPMのASCII/バイナリと、対応するPAMに対応します。高い最大値の入力も8bitの画像へ正規化するため、16bitの測定値・画素値をそのまま保存する用途には向きません。書き出しは上記のバイナリ形式です。

変換例：PNG → PBM、PNG → PGM、PNG → PPM、PNG → PAM、PPM → PNG、PGM → PNG、PBM → PNG

SVGからPNGへ・画像からSVGへの違い

静的SVGはPNGなどの画像へ描画して保存できます。読み込み条件は2MB・5000要素以内、外部参照・スクリプト・埋め込み・アニメーションなしです。文字の見た目は利用端末のフォントに依存します。

反対にPNGなどからSVGへ保存する場合は、画素を四角形として並べたSVGになります。ロゴや写真の輪郭を滑らかなパスに変えるベクター化・自動トレースではありません。高解像度の画像ではSVGの容量が大きくなることがあります。

画像が変換できないとき

拡張子は対応しているのに読み込めません

同じ拡張子でも圧縮方式やビット深度が違います。特にTIFF・BMP・ICOは上記の条件を確認してください。ファイル名だけを変更しても中身の形式は変わりません。

透過やアニメーションを残したいです

JPEG・BMP・PPM・PGM・PBMは透過を保持しません。複数コマの素材を静止画形式で保存すると1コマになります。GIFやAPNGの保存、コマ選択は読み込みに成功した素材で利用してください。

HEIC・PSD・RAWを変換できますか？

この変換ツールの対応対象外です。対応している形式へ別のソフトで書き出した画像は読み込めますが、元のレイヤーやRAW情報を引き継ぐことはできません。

形式を決めたら、変換へ

元のファイルは変更しません。必要な形式が一覧にあることを確認し、変換後のファイルを保存してください。
